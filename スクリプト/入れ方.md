# 日別データを書き出す（Google 広告スクリプト）の入れ方

作成: 2026-11-19（下書き。まだどのアカウントにも入れていない）

## これは何か
- `日別データを書き出す.js` は、Google 広告のアカウントの中で毎日動く小さなプログラムです。
- キャンペーン別・日別の数字を**読むだけ**です。キャンペーン・広告・入札・予算は変えません。変える命令はファイルに 1 つもありません（ads-mcp の `tests/test_ads_script.py` で確かめています）。
- 読んだ数字を、運用シートの「日別データ」タブの A〜I 列に書きます。J 列から右（率と単価の式）と、ほかのタブには触りません。
- 書く列: 日付・媒体（Google 広告）・キャンペーン ID・キャンペーン・表示回数・クリック数・費用（円）・コンバージョン・コンバージョン値（円）。ads-mcp の `report_sheet_plan` が作る列と同じです。

## 先に知っておくこと
- 入れる・認可する・予約するのは、**運用者ご本人**です。アカウントとシートにご本人の権限が要ります。
- Claude はこの手順を代わりにできません。広告アカウントの画面の操作と、Google の認可の画面は、ご本人だけが行います。
- シートは先に用意します。ads-mcp の `report_sheet_plan` で作った運用シートに「日別データ」タブがあることを確かめます。タブが無い、または 1 行目の見出しが違うときは、スクリプトは何も書かずに止まります。

## 手順

### 1. スクリプトを貼る
1. Google 広告の管理画面を開き、対象のアカウントを選びます。
2. 「ツールと設定」→「一括操作」→「スクリプト」を開きます（新しい画面では「ツール」→「一括操作」→「スクリプト」）。
3. 「＋」で新しいスクリプトを作り、名前を「日別データを書き出す」にします。
4. 最初から入っている文を全部消し、`日別データを書き出す.js` の中身を全部貼ります。

### 2. シートの URL を入れる
1. 運用シートをブラウザで開き、アドレス欄の URL をコピーします。
2. スクリプトの先頭の `CONFIG` の `SHEET_URL` の値（`ここにシートのIDを入れる` を含む見本）を、コピーした URL に置きかえます。
3. `LOOKBACK_DAYS`（読み直す日数）は、最初は 14 のままにします。1〜30 で変えられます。

### 3. 認可する（ご本人）
1. 「承認」または「認可」のボタンを押します。
2. Google のアカウントを選び、スプレッドシートを使う許可の画面を確かめて、許可します。

### 4. まず試しに動かす（DRY_RUN = true のまま）
1. `DRY_RUN: true` のままであることを確かめます。このあいだはシートに何も書きません。
2. 「プレビュー」か「実行」を押します。
3. ログで、次を確かめます。
   - 「読む期間」が、昨日までの 14 日になっている
   - 「読んだ行」が 0 行ではない
   - 「読んだ期間の合計」の費用・クリック数が、管理画面の同じ期間の数字とだいたい合う（直近の日のコンバージョンは、管理画面を見た時刻によって少しずれます）
   - 「書く行の先頭」の列の並びが、日付・媒体・キャンペーン ID・キャンペーン・数字 5 つになっている
4. エラーが出たら、そのメッセージに書かれたこと（URL・タブの名前・見出し）を直して、もう一度試します。

### 5. 本番にする
1. `DRY_RUN: true` を `DRY_RUN: false` に変えて保存します。
2. 1 回「実行」して、シートの「日別データ」に行が入ったことを確かめます。
3. J 列から右の率と単価が、新しい行にも自動で出ていることを確かめます。

### 6. 毎日動くように予約する
1. スクリプトの一覧で、このスクリプトの「頻度」を「毎日」にします。
2. 時刻は **毎日 6 時** ごろにします（前の日の数字がそろってから読むため）。

## 動かしたあとに確かめること
- 次の朝、「日別データ」に昨日の行が足されている。
- スクリプトの「履歴」（実行のログ）に、エラーが出ていない。
- 週次のタブの合計が、管理画面の同じ期間とだいたい合う。ads-mcp の `report_sheet_check` で、束と 1 ますずつ照らせます。
- シートの A 列が日付として入っている（文字のままだと、週次のタブの式が数えません）。
- 1 週間ほどは毎朝ログを見て、行の数が急に減っていないかを確かめます。

## API の数字と違うことがあるもの
- **コンバージョンは後から足されます。** コンバージョンは広告がクリックされた日に数えられるので、数日たってから昨日の件数が増えることがあります。そのため、書いた日によって数字が変わります。
- スクリプトは、毎日、昨日から `LOOKBACK_DAYS` 日さかのぼって読み直し、その日の行を新しい数字に置きかえます。これで遅れて足された分も取り込めます。それより前の日は置きかえないので、遅れが長い商材は `LOOKBACK_DAYS` を 30 まで延ばします。
- 日付は、広告アカウントのタイムゾーンの日付です。ads-mcp の `report_numbers` と同じです。
- 数字が全部 0 の行は書きません（合計は変わりません）。
- 費用は 100 万分の 1 円（micros）の精度のまま書きます。表示では四捨五入されます。
- 書いた時刻と API を読んだ時刻が違えば、直近の日のコンバージョンは合わないことがあります。古い日（`LOOKBACK_DAYS` より前）は、書いたあとに増えた分が入りません。

## 止めるとき
- スクリプトの一覧で、このスクリプトの頻度を外すか、スクリプトを無効にします。シートの行はそのまま残ります。
