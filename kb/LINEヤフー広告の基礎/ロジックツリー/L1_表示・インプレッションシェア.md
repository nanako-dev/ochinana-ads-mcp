## 0. 共通の前提

### 0-1. 指標どうしの関係

```
【検索の需要（Yahoo! JAPAN と提携サイトの検索）】 ← 季節・話題・指名の話題・競合の出稿
   │ × 自分の設定で届く範囲（地域・曜日時間帯・デバイス〔−100% は出ない〕・オーディエンスリスト）
   │ × 拾う範囲（キーワード・マッチタイプ・対象外キーワード・検索クエリーマッチング・「広告を表示する検索画面」）
   ▼
【表示機会の総数】（インプレッションシェアの分母。どのオークションを数えるかの定義は ❓ 01§7-2）
   │ − 予算・入札価格・残高で出られなかった分 ＝ 損失率（予算）  ← キャンペーンだけで見える
   │ − 掲載順位（オークションランク）が低くて出られなかった分 ＝ 損失率（ランク）
   │      オークションランク ＝ 入札価格・広告の品質・検索の文脈（＋下限値・競争力・アセットの効果）
   │      （コンバージョン率は加味されない ✅ H000044983）
   ▼
【表示回数（インプレッション）】
   │ × 上部に出た割合（インプレッションにおけるページ上部の割合）
   ▼
【上部・最上部の表示】 → クリック（L2）
```

ディスプレイ（運用型）は流れが違う〔仕様。H000044610〕:

```
【面の訪問（Yahoo! JAPAN・LINE・LINEヤフー広告ネットワーク）】
   │ × ターゲティング（属性・オーディエンスリスト・プレイスメント・コンテンツキーワード・デバイス）と広告タイプが面に合うか
   │ × スマートターゲティング（オーディエンスリストの外にだけ広げる）
   ▼
【オークション】 オークションランク ＝ 入札価格（調整率を掛けた値）× 広告の品質（推定アクション率）＋目的のアルゴリズム（式は「もとに算出」△ 01§10-2）
   │ × 提携パートナーの追加のオークション（SSP・ヘッダービディング。負けたら出ないが料金も無い）
   ▼
【表示回数】（フリークエンシーキャップを付けるとビューアブルを測れる面だけに出る）
```

読み方のこつ〔推測。根拠は各節〕:

- **表示が減ったら、まず「機会が減った（需要・範囲）」か「機会はあるのに取れなかった（損失率）」かを分ける**。検索はキャンペーンの行で IS と 2 つの損失率を見る（広告グループの行では足しても 100% にならない。01§7-3）
- **損失率（予算）は検索では「予算」だけの話ではない**。入札価格が 1 日の予算に比べて高い、残高が 0、の 2 つも同じ列に入る（H000044896）
- **品質インデックスは完全一致の検索を前提にした参考値**。インテントマッチや検索クエリーマッチングで広く当たった分の質は表していない（01§4）

### 0-4. 切り分けの順（H000044221・H000044244 の公式の順に、損失率を足した）

1. **表示が 0 か、減っただけか**。0 なら §2（ZERO）。当日は「今月（今日を含む）」で見る（H000044221）
2. **日付で切る**（§0-3）。仕様の変更・自分の変更（操作履歴、366 日前まで `LY-運用-039`）
3. **検索: キャンペーンの行で IS と 2 つの損失率**。損失率（予算）が上がった → §4（BUD）、損失率（ランク）が上がった → §5（RNK）、どちらも動かず表示が減った → 機会が減った（§1 の IMP-下 の需要・範囲）
4. **ランクなら品質か入札か競合か**: 品質インデックス（履歴）の要素 → 入札・調整率・目標値の変更 → オークションインサイトの他社（01§8）
5. **ディスプレイ**: 配信設定 → 残高 → 審査（画像・動画を含む）→ ターゲティング（リストのサイズ 0）→ 1 日の予算 → 掲載期間 → 損失率 → 品質と入札（H000044244）。IS が出ないアカウントでは、予算の消化率と最適化提案で代える（01§10-5）

### 0-6. 少額・少量のアカウントでの注意〔推測。根拠は括弧内〕

- 品質インデックスは完全一致の検索が少ないと「-」のまま（H000044956）。少額では付かない語が多い前提で、広告グループの CTR で代える

## 1. 表示回数（IMP）

- ディスプレイには「ビューアブルインプレッション」もある（広告の 50% 以上が 1 秒以上連続で表示。インストリームは再生開始）✅（`LY-計測-030`）。ビューアブル関連の指標で「見られているがクリックされていない」のか「見られていないからクリックされていない」のかを分けられる、と公式 ✅（H000044396）

### 1-2. まず切り分ける順番（IMP に特有の点）

## 2. 表示がまったく出ない・0 になった（ZERO）

### 2-1. 定義

## 3. インプレッションシェア（IS）

### 3-1. 定義と分解式
- 検索: 広告表示機会の総数に対して実際に表示された回数の割合。キャンペーン・広告グループ・キーワードで見られる。完全一致のインプレッションシェアもある。クリックシェア（キャンペーン・キーワード。広告グループの一覧では見られない）✅（H000044896）
- ディスプレイ: 表示機会の総数に対する表示回数の割合（推定値）。**表示期間にインプレッション 10 万以上か表示機会 100 万以上**のときだけ。広告単位は無い、広告グループでは損失率（予算）が見られない。レポートの分割は月・日・時間だけ ✅（H000044406）
- IS が下がった ＝ 損失率（予算）が上がった（§4）か、損失率（ランク）が上がった（§5）か、分母の取り方が変わったか

### 3-2. まず切り分ける順番（IS に特有の点）
1. キャンペーンの行で、IS・損失率（予算）・損失率（ランク）を同じ期間で並べる（反映に 1〜3 日）
2. どちらの損失率が増えたかで §4・§5 へ
3. どちらも増えていないのに IS が下がった → 分母の側（範囲を広げた、検索クエリーマッチング）を疑う

### 3-3. 木（IS-下・IS-上）と詳細

- IS-下-02 損失率（ランク）が上がった（→ §5）
- IS-下-03 範囲を広げて分母が増えた（インテントマッチ・検索クエリーマッチング・新しい語）

- IS-上-01 損失が減った（予算を上げた・品質を直した・入札を上げた）
- IS-上-02 範囲を絞って分母が減った（完全一致に寄せた・除外を足した）

## 4. 損失率（予算）（BUD）

### 4-1. 定義
- 検索: 表示機会の総数のうち、**キャンペーンの 1 日の予算、キーワードや広告グループの入札価格、アカウント残高**が原因で取れなかった割合。**キャンペーンだけ**で見える ✅（H000044896）
- ディスプレイ: 表示機会の総数に対して、**キャンペーンの 1 日の予算が不足**していることで出なかった割合。広告グループでは見られない ✅（H000044406）

### 4-2. まず切り分ける順番（BUD に特有の点）
1. 残高（前払いの 0、後払いの上限）— 一瞬で確かめられて、全部を止める
2. 1 日の予算を使い切っている時刻（時間帯別のコスト。午前中に 50〜70% が使われるのが普通）
3. 入札価格が 1 日の予算に比べて高くないか（同額なら 1 クリックで止まる）
4. クリック数の最大化が共有予算を食っていないか、CV 最大化（目標値なし）に替えてコストが跳ねていないか
5. ここまで当たらなければ、需要の増加

### 4-3. 木（BUD-上）

  - BUD-上-01 アカウント残高が尽きた・後払いの上限（検索は損失率（予算）に入る）
- ② 予算
  - BUD-上-02 1 日の予算を下げた・需要が増えて早い時刻に使い切る
  - BUD-上-03 共有予算をクリック数の最大化（上限なし）のキャンペーンが使い切る
- ③ 入札
  - BUD-上-04 入札価格・調整率を上げて、予算に比べて 1 クリックが高くなった（検索）
  - BUD-上-05 CV 系・クリック数の最大化に替えて、日予算を使い切りにいくようになった
- ④ 範囲
  - BUD-上-06 範囲を広げた（インテントマッチ・検索クエリーマッチング・スマートターゲティング）のに予算は同じ

4. オークションインサイトで他社（新しいドメイン、他社の IS・上位表示率の上昇）
5. 文脈の構成（デバイス・時間帯の比率）

## 6. 品質インデックス（QI）

### 6-1. 定義
- 広告の品質を **10 段階**で示す。**キーワードごと**。**参考値で、掲載順位に直接影響しない** ✅（H000044956、H000044898）
- 要素は 3 つ（広告の関連性・ランディングページの利便性・推定クリック値）で、評価は「平均より上／平均値／平均より下」✅（H000044956）
- **完全一致を前提**に算出。マッチタイプ・対象外キーワードの登録状況、検索クエリー、オークション時の要素（デバイス・場所・時間帯・広告表示アセット）は入らない ✅（H000044956）
- 一覧・レポートは**表示期間にかかわらず今の値**。過去は「品質インデックス（履歴）」など。期間の最後の値 ✅（H000044956）

### 6-2. まず切り分ける順番（QI に特有の点）
1. 「-」か数字か。「-」なら §6-3 の QI-下-01（新規・情報不足）
2. （履歴）列で、いつから下がったかを週で見る（期間を変えても過去の値は出ない）
3. 3 要素のどれが「平均より下」に変わったか
4. その日の前後に、広告文・LP・キーワードの移動があったか
