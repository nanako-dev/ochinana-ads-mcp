## 0. 先に結論（10 行）

1. **文字の数え方は形式で 3 通りある**。検索広告（RSA・アプリ訴求・テキスト補足・カテゴリ補足）は「全角 2・半角英数記号 1」、クイックリンクとビジネス名は「半角 1 バイト・全角 2 バイト（25 文字＝全角 12 文字）」、**ディスプレイ広告の規定には数え方の記述が無い** ❓。URL はすべて「半角 1・全角 3 バイト」で 1,024 バイト ✅（§3-1）
2. **ディスプレイ広告の URL は日本語が使えない**（RFC3986 のみ、`{}` 可・`[]` 不可、「.」で始まる URL 不可）。**検索広告の URL は日本語が使える**（RFC3986・3987）✅（§3-4）
3. **電話番号アセットに携帯電話の番号は入らない**。使えるのは 0120・0800・0078・0570・050・0066-9・市外局番で始まる番号だけ ✅（§4-4）
4. **カテゴリ補足アセットは 13 の補足カテゴリーから選び、補足内容は 3〜10 個・各 25 文字**。1 つの補足内容に 2 つの要素（「スパ・エステ」）や宣伝文句（「おすすめの」「丁寧な」）は掲載不可。周辺地域に都道府県名・「〇〇駅」は不可 ✅（§4-4・§4-5）
5. **レスポンシブ（画像）は画像 15・タイトル 5（20 文字）・説明文 5（90 文字、友だち追加は 75 文字）**。主な比率は 1:1 と 1.91:1 の 2 つで、**3:2 は入稿できても出る面が限られる**。画像は推奨 300KB・上限 10MB、300KB 超か一辺 3,000px 超は自動圧縮、**圧縮して 300KB 以下にならなければエラー** ✅（§5-1）
6. **カルーセルは 1:1 の画像だけ、カード 2〜10 枚、カードのタイトル 20・説明文 40**。明記が必須の表記は**カードごとに画像の中**に入れる ✅（§5-3・§7）
7. **動画はバナー・レスポンシブとも 5〜60 秒、上限 1GB、MP4・MOV、H.264・AAC LC**。レスポンシブ（動画）は 16:9・1:1・9:16・3:2 の 4 比率、**バナー（動画）は 16:9・1:1 の 2 比率だけ**。サムネイル画像の入稿が必須 ✅（§6）
8. **9:16 の動画はセーフゾーンが狭い**。1,080×1,920px のとき、上 282px・下 758px・左右 48px を空け、ロゴ・商品・注釈を中央の 984×880px に置く（高さの約 46%）✅（§6-3）
9. **主体者表記（20 文字）はレスポンシブ（画像・動画）・カルーセル・動的ディスプレイで必須で、唯一の「表示：保証」の文字項目**（一部の面は保証の対象外）。バナー・テキストには主体者表記の欄が無い ✅（§7）
10. **LINE アプリに出るのは、バナー（画像 1:1・6:5・16:9／動画 1:1・16:9）・レスポンシブ（画像・動画の全比率）・カルーセル・動的ディスプレイだけ**。テキストとインストリーム、バナーのほかの比率は LINE アプリの対象に挙がっていない。Yahoo! JAPAN トップページ（PC）にはバナー 16:9・16:5 とレスポンシブ（動画）9:16 が出ない ✅（§8）

### 2-2. 旧 LINE 広告から入らない形式
- 旧 LINE 広告の画像（小）・画像（アニメーション）・動画（小）・長いタイトル・ラベルは入稿できない（61 §4-1、rules `LY-広告-022`）。この章の本文でも、**アニメーションはどの形式でも「GIF・APNG とも形式を問わず不可」**と書かれている ✅（H000045739、H000044228、H000045737、H000045743）

### 運用の判断への効き方
- **バナーとテキストには主体者表記の欄が無い**。法令や掲載基準で「誰の広告か」「必須の表記」を見せなければならない商材は、バナーなら画像の中に入れる（§7）。テキスト広告は文章だけで完結させる
- 形式を選ぶ順番は「目的で使える形式（23 §3-1）→ 出したい面で出る形式（§8）→ 作れる素材（§5〜§6）」。面の表で × の形式（例: PC の Yahoo! トップに 16:9 のバナー）を主力にしない

- **「全角 2」の規定と「2 バイト」の規定は、日本語の上限としては同じ**（25 文字＝全角 12 文字。半端の 1 は半角 1 字分）。違うのは言い方だけ〔推測: 結果が同じになることは規定の「半角 25 文字、全角 12 文字」の併記から読める〕

### 3-5. 共通の禁止事項と免責 ✅〔仕様〕（H000044215）
- 禁止: 機種依存文字、**文頭・文末のスペース（Tab スペースを含む）**、コンピューターウイルスを含むコンテンツ（2025-09-08 に「禁止事項」を更新）
- 免責: ブラウザのフォントの種類やサイズで意図しない改行が入る／ユーザーの操作の後に同じ面の他の広告やコンテンツで広告の一部が覆われる／災害・障害時にお知らせの枠が出る／ユーザーのクレームや使いやすさの観点から修正の依頼・掲載のお断り・掲載の中止がある
- **比率が決まった広告で最小の画素を超える画像は、端末ごとに掲載サイズが最適化され、インフォメーションアイコンや動画の尺の表示に覆われる範囲も端末で変わる**
- ディスプレイ共通: **透過画像は透過部分を白で塗る**。制作ツールで数値に誤差が出て入稿エラーになることがあるので、**規定より余裕を持った数値**で作る。同時に入稿できる本数は別のヘルプ ❓（今回は開いていない）
- インフォメーションアイコンは**広告の四隅のどれかに自動で付く**。入稿する画像に入れる必要は無い。位置と挙動は枠・フォーマットで違う ✅（H000044177）。検索連動型ブランディング広告では右上 ✅（H000044430）

### 運用の判断への効き方
- **ディスプレイの LP の URL に日本語が入っているなら、エンコードした URL か英数の URL を用意する**。検索広告では日本語 URL がそのまま通るので、検索で使っている URL を流用すると入稿で止まる
- 検索とディスプレイの文面を 1 つの表で管理するなら、**記号の列を 2 つ**（検索で使えるか／ディスプレイで使えるか）持つ。とくに ★・※・→・【】（アセット）でつまずく
- 画像の四隅のどれかにはアイコンが乗る。四隅にロゴや注釈を置かない〔推測: どの隅に出るかは枠で変わるので、4 隅とも空けるのが安全〕
- 背景が透過の PNG は白背景になる。暗い背景色の面（LINE のダークモードなど）で白い四角に見えないか、書き出し前に確かめる〔推測〕

| バナーオプション | 2 | 640×360（PC は横 200px 固定で横並び、スマートフォンは縦 120px 固定でカルーセル） | 同上 |
| 掲載 URL | 素材ごと 1 か所（カルーセル 3、オプション 2） | 1,024 バイト | ディープリンクは設定しない |

- スマートフォンの掲載は横最大 400px。150KB 超か一辺 2,000px 超は自動圧縮、150KB 以下にならなければエラー。掲載時に枠が付き、縮小・拡大される
- 動画は掲載枠の 50% 以上が見えると音声なしで自動再生、50% 未満で一時停止。**Yahoo! JAPAN アプリで設定した自動再生の設定は適用されない**。通信環境が向かないとサムネイルが出る
- 表示保証環境は予約型に準じる

### 運用の判断への効き方
- **クイックリンク・テキスト補足・カテゴリ補足・ビジネス名は「同じ種類の記号 1 つ」**。RSA の「2 つ」と違う。RSA の文言を短くしてアセットに回すときに記号で止まる
- **テキスト補足は【】「」を使えない**（丸括弧だけ）。「【送料無料】」のようなコールアウトは「送料無料」と書く
- カテゴリ補足は Google の構造化スニペットより中身の縛りが強い。**「周辺地域」に都道府県名、「到着地」に駅・空港を入れると落ちる**。入れる前に 13 カテゴリーの表で照らす
- **検索の画像アセットは文字の入らない写真で作る**。ディスプレイのバナー（文字入り）を流用しない（H000055286）。容量の上限も 2MB と、ディスプレイの 10MB より小さい
- ファビコンは PNG の透過がエラーになる。サイトの favicon.png をそのまま使わず、背景色を付けて書き出す
- 電話番号アセットは固定・フリーダイヤル・ナビダイヤル・050 で用意する。携帯しか無い店舗は使えない前提で計画する〔推測〕
- ビジネス名は 1 つの名称に絞る。Google で「会社名｜ブランド名」の形にしていたなら直す

## 13. 食い違い △

- **△-1 半角カナの数え方**: RSA・アプリ訴求の「使用可能な文字種別」はカタカナを全角だけに挙げ、数え方は「全角 2・半角英数記号 1」（H000044241、H000044893）。動的検索連動型の規定は「全角および半角カナ 2 文字」（H000044174）。「RSA とは」（H000044220）も半角カナ 2 と書く（00 §7-1、94 の 19 行目と同じ食い違い）。半角カナを入稿できるのかは、規定の中で食い違う
- **△-2 61 秒以上の動画**: 既存の章と rules（00 §7-4、23 §9-3、`LY-広告-019`）は「61 秒以上の動画は入稿不可」。入稿規定の本文は「再生時間 5〜60 秒。**16:9 の 61 秒以上の動画は広告管理ツールからアップロードできるが、広告作成時に表示・選択できない**」（H000045738、H000044155）。広告には使えない点は同じで、「アップロードはできる」の一点だけ違う。あわせて**下限の 5 秒**は既存の章に無い
- **△-3 主体者表記が必須の形式**: 既存の章と rules（00 §7-4、23 §9-3、`LY-広告-020`）は「レスポンシブ、カルーセル」。入稿規定では**動的ディスプレイも必須**（H000045743）。欠けているだけで矛盾ではない
- **△-4 画像の登録上限**: 04 §9-1（`LY-アセット-009`）は「画像アセットは 1 アカウント 1,000 件」（検索、H000045056）。ディスプレイは「ロゴを含めて 1 アカウント 20,000 個」（H000044693）。アカウントの種類が違うので両立する。混ぜて覚えない
- **△-5 絵文字**: 共通のルール（H000044192）は「広告のタイトル、および動的ディスプレイ広告の商品名で 2 回まで」と検索・ディスプレイを分けずに書く。検索広告（RSA・アプリ訴求・DAS）の使える文字の一覧には絵文字が無い（H000044241 ほか）。ディスプレイの一覧には 118 種がある（H000044294）。rules `LY-広告-027` は対象の区分を書いていない。**検索広告で絵文字が使えるとは読めない**〔推測〕
- **△-6 3:2 の画像**: 23 §9-4・§運用の判断は「1:1・1.91:1・3:2 の 3 比率をそろえる」。画像入稿時の注意（H000044693）は「主な画像サイズは 1:1 と 1.91:1 の 2 パターン」「3:2 は配信される面が限られる」。3:2 を足すこと自体は否定されていないが、優先度が違う
- **△-7 クイックリンクの数え方の言い方**: LYC ビズの公式コラム（検索結果の抜粋）は「全角・半角カナは 2 文字」。入稿規定は「半角 1 バイト、全角 2 バイト（25 文字＝全角 12 文字）」。上限としては同じ

## 15. よくある思い込みと実際

| 思い込み | 実際 | 根拠 |
|---|---|---|
| ディスプレイのタイトル 20 文字も全角 2 で数える | ディスプレイの規定に数え方は書かれていない。全角 2 は検索の規定の文言 | §3-1 |
| 検索広告の URL も、ディスプレイと同じく日本語不可 | 検索は日本語 URL 可（RFC3987）、ディスプレイは不可 | §3-4 |
| 「！」は 2 つまで、「？」も 2 つまでなら 4 つ使える | 「！」と「？」は同じ種類。合わせて 2 つ | §3-3 |
| サイトリンクの感覚で、クイックリンクにも記号を 2 つ使える | クイックリンク・テキスト補足・カテゴリ補足・ビジネス名は同じ種類の記号 1 つまで | §3-3・§4-4 |
| コールアウトの【送料無料】はそのまま入る | テキスト補足の括弧は丸括弧だけ | §4-4 |
| 電話番号アセットは店の携帯でもよい | 使える局番に携帯は無い | §4-4 |
| 検索の画像アセットにバナーを流用できる | 画像アセットは文字情報不可・JPEG/PNG・2MB 上限 | §4-4・§4-5 |
| ビジネス名は「会社名｜ブランド名」で両方出せる | 名称は 1 つだけ | §4-5 |
| 画像は 10MB まで入る | 推奨 300KB を超えると圧縮し、300KB 以下にならないとエラー | §5-1 |
| レスポンシブは 1:1・1.91:1・3:2 を同じ重さでそろえる | 主は 1:1 と 1.91:1。3:2 は出る面が限られる | §5-1 |
| カルーセルのカードは横長でもよい | カードの画像は 1:1 だけ | §5-3 |
| バナー（動画）も 9:16 で入れられる | バナー（動画）は 16:9・1:1 だけ。9:16 はレスポンシブ（動画）（予約型のバナーは 2026-11-11 から 9:16 可） | §6-1・§10 |
| 動画は 1 秒からでもよい | 5〜60 秒 | §6-1 |
| 9:16 の下のほうに注釈を置けば読める | 下 758px（約 40%）はセーフゾーンの外 | §6-3 |
| 必須の表記はタイトルか説明文に書けば足りる | ディスプレイは画像（動画とサムネイル）の中。カルーセルは各カードの中 | §7 |
| バナーにも主体者表記を入れる欄がある | バナー・テキストには欄が無い | §7 |
| テキスト広告も LINE に出る | LINE の対象はバナー（一部の比率）・レスポンシブ・カルーセル・動的ディスプレイ | §8-2 |
| Yahoo! トップの PC に 16:9 のバナーが出る | PC・タブレットのトップには 16:9 と 16:5 のバナーが出ない | §8-1 |
| 透過 PNG の背景はそのまま透ける | ディスプレイは白で塗る、ファビコンは透過不可 | §9 |
