## 0. 先に結論

1. **生成 AI の回答の面は 2 つ**: ① **Agent i の回答結果エリア**（LINE の各タブと Yahoo! JAPAN の検索窓の横のアイコンから開く AI エージェント。2026-04-20 に Yahoo! JAPAN の「AI アシスタント」と LINE の「LINE AI」を統合した新ブランド）、② **Yahoo!検索の検索結果上の AI 回答エリア**（Yahoo!検索の「生成 AI による回答表示機能」の枠）✅〔仕様〕（F68-01、F68-02、F68-08、F68-09）
2. **出る広告は 3 系統**: 検索広告（ショッピング）の**検索連動型ショッピング広告（SSA）**、**Yahoo! JAPAN 商品情報掲載**（無料）、**ディスプレイ広告（運用型）**。**通常の検索広告（レスポンシブ検索広告）が出るとはどの公式の文書にも書かれていない** ❓（F68-01、F68-02、F68-03）
3. **課金の開始日**: ディスプレイ（運用型）の Agent i は **2026-07-23**（テスト配信の開始と同時に課金対象）。SSA の Agent i は **2026-08-31**（それまでのテスト表示は無料）。**Yahoo!検索の AI 回答エリアのテスト表示（2025-12-15〜）は無料で、レポートに記録されない**。AI 回答エリアが有料になったという告知は見つからない ❓ ✅〔仕様〕（F68-01、F68-02）
4. **止め方**: ディスプレイは**プレイスメントで `search.yahoo.co.jp/chat` を除外**すれば止まる。**SSA と商品情報掲載は止められない**（面を指定する設定も、特定の面を外す設定も無い。質問の語を除外キーワードにしても必ず外れるとは限らない）✅〔仕様〕（F68-02、F68-05、F68-06 p16）
5. **レポート**: ディスプレイは配信先 URL に `search.yahoo.co.jp` と出る（`/chat` までは出ない）。**SSA は面ごとの実績を見られず、検索クエリーレポートにも Agent i の実績は入らない**。AI 回答エリアのテスト分は記録されない（サイトの流入とずれる）✅〔仕様〕（F68-01、F68-02、F68-05）
6. **広告主は Agent i を配信先として個別に指定できない**。業種や規模による限定は無い（出稿できる条件を満たしていれば対象）。ディスプレイは**今は一部のユーザーにだけ**出ている ✅〔仕様〕（F68-03、F68-04）
7. **審査・掲載の判定**: 質問文と生成 AI の回答の内容を見て、システムが「掲載が適切」と判断したときに出る。**どの質問・回答で出たかは答えない**。ディスプレイの「**制限カテゴリ**」は 2026-12 に公開予定 ✅〔仕様〕（F68-01、F68-02、F68-06 p16）。それまでは何の業種が出ないかの一覧は ❓
8. **予定**: ディスプレイの Agent i へのテスト配信を **2027-01 から拡大**。SSA は Yahoo!検索と Agent i の両方で「パフォーマンスと表示フォーマットを継続的に改善」。チャット誘導広告は「Agent i 面からの広告配信」を今後の予定に挙げる（時期未定）✅（F68-06 p9・p10・p16、F68-07 p14、F68-15）
9. **SSA の Agent i の掲載開始日は公式の中で食い違う** △: 「Agent i」のテスト配信のお知らせは 2026-08-31 に課金開始・配信機会の拡大、SSA の掲載面拡大のお知らせは Agent i の回答結果画面（スマートフォン版）を含む新しい面への掲載開始を 2026-09-16 と書く（§4-2）
10. Google の AI による概要・AI モードの広告は「既存の検索・ショッピング・P-MAX が自動で対象、オプトアウトできない、レポートは合算」（G13 §5-1）。**LINEヤフーはディスプレイだけ止められ、テキストの検索広告は対象かどうかも書かれていない**点が違う

### 3-1. どう選ばれるか ✅〔仕様〕
- 共通: **利用者の質問文と生成 AI による回答の内容を考慮し、システムが広告の掲載は適切と判定した場合に表示される可能性がある**（F68-01、F68-02、F68-06 p16）
- SSA: システムが Agent i との会話の内容に合う広告を選ぶ（F68-02）。掲載順位は**入札価格と、商品情報と掲載コンテキストの関連性**で決まり、掲載コンテキストには検索語・掲載面の内容・ユーザーの状況・商品フィード・過去のクリック実績などが入る（F68-05）。ヘルプは、対応する LINEヤフーのサービスでは検索クエリー以外の掲載面のコンテキストと商品情報の関連性を考慮すると書く（F68-16）
- ディスプレイ: 配信は広告の配信条件に応じて行われる（F68-04）

### 運用の判断への効き方
- **テキストの検索広告の成果が「AI 回答のせいで」動いた、という説明は公式の裏づけが無い**。Yahoo!検索の AI 回答エリアに出るのはショッピング系だけと書かれている〔仕様＋推測〕
- Agent i の SSA で選ばれるかは「会話の内容と商品情報の関連性」なので、**商品フィードのタイトル・説明の質**が効く余地がある（21 §5-3 の項目の整備）〔推測〕

- ディスプレイの Agent i は今は一部のユーザーだけで、**2027-01 に拡大**する。今の小さな数字で「効かない／効く」を決めず、拡大後にもう一度、配信先 URL で切って見る〔推測〕

## 5. 止め方と止められない面

| 面 × 広告 | 止められるか | やり方・注意 | 出典 |
|---|---|---|---|
| Agent i × ディスプレイ（運用型） | **できる** | プレイスメントターゲティングでプレイスメントリストを作り、**手動で `search.yahoo.co.jp/chat` を配信対象外にする**（ロードマップの書き方） | F68-02、F68-06 p16 |
| Agent i × SSA | **できない** | 回答結果エリアへの配信は停止できない。質問の内容を除外キーワードに登録しても必ず除外されるとは限らない。**掲載面を指定する設定も、特定の掲載面を外す設定もできない** | F68-02、F68-05 |
| Yahoo!検索の AI 回答エリア × SSA・商品情報掲載 | **できない** | 「生成 AI を利用した回答への表示は停止できません」 | F68-01 |
| 商品情報掲載をまるごと止める | できる（掲載設定をオフ。オフにすると SSA も止まる、21 §3-6） | 面だけでなく、すべての面から消える | 21 |
| 「Agent i だけに出す」 | できない | 広告主が Agent i を配信先として個別に指定することはできない | F68-04 |

- ディスプレイは**何も指定しないと Agent i にも出る**（66 §0 の「すべての面に出る」）。新しい面は既存のプレイスメント設定で自動では除外されないことがある（00 §8-2）〔推測〕
- `search.yahoo.co.jp/chat` の除外は、ディスプレイの面の除外の URL の書き方（サブドメインとディレクトリ）に従う（66 §4-4）

### 運用の判断への効き方
- **ディスプレイで面を絞っているアカウントは、配信リスト（指定）なら Agent i は入らない、除外リストだけなら入る**。どちらの作りかを確かめてから「出ているか」を判断する〔推測。66 §4 の配信・除外の仕組みから〕
- SSA を止める唯一の手は、キャンペーン・商品グループの配信を止めるか、商品情報掲載をオフにすることで、**Agent i の面だけを止める方法は無い**〔仕様〕。ブランドの安全の理由で AI の回答の中に商品を出したくない広告主には、SSA を使うかどうかから相談する〔推測〕

## 10. 判断の型

### 10-1. ディスプレイ: Agent i に出すか〔推測〕
1. 業種が掲載制限・販売制限に当たるか（66 §5）。当たるなら制限カテゴリ（2026-12 予定）が出るまで除外
2. ブランドの安全の方針（回答の文脈を選べなくてよいか）。だめなら `search.yahoo.co.jp/chat` を除外専用リストへ
3. 出すなら、配信先 URL の `search.yahoo.co.jp` の行を毎週別に見る（費用・CV・CPA）
4. 2027-01 の拡大の後に、同じ物差しでもう一度判断する

### 10-2. ショッピング: Agent i の分をどう扱うか〔推測〕
1. 止められないので「出る前提」で予算を組む
2. 2026-08-31 と 2026-09-16 をまたぐ比較は日付で切る
3. キャンペーン合計と検索クエリーレポートの差を毎月記録し、増え方を見る
4. 商品フィードのタイトル・説明を整える（会話の文脈との関連性が順位に入る）

### 10-3. 「AI 回答のせいで検索広告の成果が落ちた」と言われたら〔推測〕
1. テキストの検索広告が AI 回答の面に出るとは公式に書かれていない（§3）
2. 自然検索のクリックが AI 回答で減った可能性は広告とは別の話（広告のレポートでは測れない）
3. 広告の側は、01・04 の品質と入札の確認順で見る
