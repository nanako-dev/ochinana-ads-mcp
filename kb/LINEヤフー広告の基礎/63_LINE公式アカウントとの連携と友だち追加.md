## 0. 先に結論

1. **LINE 公式アカウントにつなぐと何ができるかは、ディスプレイ広告と検索広告で違う**。ディスプレイは友だち追加目的の広告・プロフィール画像の連携・オーディエンスリストの連携・計測タグ。検索広告は 2026-04-01 時点で**使える機能なし**、検索広告（ショッピング）は商品管理（カタログ連携）と計測タグ ✅〔仕様〕（F63-01）
2. **1 つの広告アカウントにつなげる BM の組織と LINE 公式アカウントは、それぞれ 1 つだけ**。逆に、1 つの BM・LINE 公式アカウントには複数の広告アカウントをつなげる。**つないだ LINE 公式アカウントは広告管理ツールから変えられない**（公式 PDF は「接続すると解除できません」）✅〔仕様〕（F63-01、F63-03 p38・p48）
3. 接続できるのは、広告アカウントの広告主情報・BM の組織・LINE 公式アカウントの 3 者で**サービス対象国と企業の所在国が同じ**とき ✅〔仕様〕（F63-01）
4. **つながっていても機能が使えない状態がある**: BM が未認証・審査中なら BM の機能（オーディエンス連携）は使えない。LINE 公式アカウントが審査で否認されたら、友だち追加広告・友だちリスト・プロフィール画像は使えない。**機微な情報を扱う可能性があると判断された LINE 公式アカウントは、審査の結果にかかわらず同じ機能が使えない**。どの場合も広告の配信そのものはできる ✅〔仕様〕（F63-01）
5. **友だち追加目的の広告は「友だち追加 1 件 ＝ 1 クリック」**。広告をタップした回数は数えず、友だち追加した数が「クリック」の列に入り、その数で課金される。ポップアップが出る形では、ポップアップの「友だち追加」ボタンが押されたときに数える。**ポップアップの表示数は見られない** ✅〔仕様〕（F63-02、F63-03 p11・p47）
6. **使える条件は「広告主情報が日本国内」かつ「契約当事者が広告主」**。代理店契約のアカウントは 2024-10-01 改定の広告取扱基本規定への同意が要る。BM の組織と LINE 公式アカウントがどちらも**認証済み**で、両者の接続審査が終わっていること ✅〔仕様〕（F63-02、F63-03 p9）
7. **入札戦略は 3 つ**: 友だち追加数の最大化（目標値あり）・（目標値なし）・個別友だち追加単価。**推奨入札価格は無い**（公式 FAQ）。目標値ありで何件たまれば安定するかの線は ❓（コンバージョンの「30 日 40 件」に当たる記述が無い）✅〔仕様〕（F63-07、F63-03 p13・p47）
8. **「LINE 公式アカウントの友だち」リストは友だち追加キャンペーンの広告グループに自動で除外として付き、外せない**。配信対象には付けられない。スマートターゲティングは**非推奨** ✅〔仕様〕〔公式の推奨〕（F63-02、F63-03 p11・p42）
9. **友だち・ブロック中の友だちのリストを「配信対象」に使うと、広告データ利用基準の審査がある**。否認されると、そのリストを配信対象にした広告グループが止まる（除外で使っている分と友だち追加キャンペーンは影響なし）。否認リストを付けたまま再開を続けると **BM との接続が解除されることがある** ✅〔仕様〕（F63-04、F63-03 p18〜21）
10. **広告側の「友だち追加数」と LINE 公式アカウント側の数字は合わない前提で読む**。LINE 公式アカウントの分析は、経路別では「友だち追加広告」に LINEヤフー広告の友だち追加目的と LINE 公式アカウントの管理画面から出す友だち追加広告がまとめて入る。20 件未満の経路は「その他」、絞り込むと 50 単位の概算、**概要はブロック解除で増えないが追加経路は増える** ✅〔仕様〕（F63-20、F63-24）
11. **友だちが増えると LINE 公式アカウントのメッセージ代が増える**。メッセージの通数は「送信回数 × 送った友だちの数」。無料の通数はコミュニケーション 200・ライト 5,000・スタンダード 30,000（月額 0・5,000・15,000 円、税別）。追加メッセージが使えるのはスタンダードだけ ✅〔仕様〕（F63-23）。友だちの獲得単価だけで判断せず、維持の費用を足して見る〔推測〕
12. **LINE 公式アカウントの管理画面にも別の「友だち追加広告」がある**（2026-05-09 にリニューアルして「友だち追加広告（新）」）。LINEヤフー広告の友だち追加目的とは予算の仕組み（1 日の予算は目安で上限ではない、月の上限に達すると翌月まで再開しない）もターゲティングも違う ✅〔仕様〕（F63-22）

## 2. つながりの地図: 広告アカウント・BM・LINE 公式アカウント

### 2-1. 3 つの役割 ✅〔仕様〕（F63-01、F63-03 p25〜26）
| もの | 役割 | 管理する場所 |
|---|---|---|
| 広告アカウント（ディスプレイ・検索・ショッピング） | 広告の配信と課金 | 広告管理ツール（ads.yahoo.co.jp） |
| ビジネスマネージャー（BM）の組織 | 「LINEヤフーやパートナー企業、クライアント企業が持つデータを収集・統合し、データ管理、データ分析、オーディエンスの共有や作成に活用できるデータ活用基盤」 | BM の管理画面（公式マニュアルの URL は data.linebiz.com/business-manager/manual） |
| LINE 公式アカウント | LINE 上で企業・店舗がアカウントを作り、友だちに情報を届けるサービス | LINE Official Account Manager |

- **BM は 2 種類ある**ので取り違えない。「Yahoo!ビジネスマネージャー」は Yahoo! JAPAN ビジネス ID の管理ツールで、ここで使うのは左の「ビジネスマネージャー」（データの基盤）の方 ✅〔仕様〕（F63-03 p26）
- 広告アカウントの情報は、**BM を介して** LINE 公式アカウントの情報を使う形。友だち追加目的と友だち関連リストには、広告アカウント⇔BM、広告アカウント⇔LINE 公式アカウントの両方の接続が要る ✅〔仕様〕（F63-03 p25）

### 2-2. 接続で使える機能 ✅〔仕様〕（F63-01、S-12）
| 広告アカウント | 接続で使えるもの |
|---|---|
| ディスプレイ広告 | 友だち追加目的の広告、LINE 公式アカウントのプロフィール画像の連携、オーディエンスリスト連携（友だち・ブロック中の友だち、BM 経由のオーディエンス）、計測タグ |
| 検索広告（ショッピング） | 商品管理（カタログ連携）、計測タグ |
| 検索広告 | **2026-04-01 時点で無し** |
| 共通 | 今後提供予定の、LINEヤフーのサービスを横断する新機能（S-12） |

### 2-3. 接続が必須か任意か ✅〔仕様〕（F63-01、S-12）
| 申し込み方 | 広告アカウントを新しく追加するとき |
|---|---|
| オンラインサインアップ | **必須**（BM と LINE 公式アカウントの両方） |
| 代理店経由 | 任意 |
| LINEヤフー広告 API で作る | 任意 |
| 2026-03-31 までに作った広告アカウント | 任意 |
| 広告アカウントの住所が日本国外 | 任意（お知らせ S-12。ヘルプ本文 F63-01 の「任意」の一覧には住所の行が無い △） |

- オンラインサインアップで、ビジネス ID を統合していないか、BM の権限（管理者・運用者・運用者（データ）・利用者（閲覧のみ））が無いと、2026-04-01 以降は広告アカウントを追加できない ✅〔仕様〕（S-12）

### 2-4. 1 対 1 の制約と、変えられないこと ✅〔仕様〕（F63-01、F63-03 p38・p48）
- 1 つの広告アカウントにつなげる BM 組織と LINE 公式アカウントは**それぞれ 1 つ**。BM 組織と LINE 公式アカウントの側には、複数の広告アカウントをつなげる
- **接続済みの LINE 公式アカウント・BM 組織は広告管理ツールから変えられない**（ヘルプ）。公式 PDF の FAQ は「LINE 公式アカウントと広告アカウントの接続解除はできますか？」に「いいえ、できません」
- 一部の LINE 公式アカウントは広告アカウントと接続できない（条件は ❓）
- 代理店経由で接続するときは、**LINE 公式アカウントと BM の片方だけにはつなげない**（両方を指定する）✅〔仕様〕（F63-01）
- BM の組織は「同じルート MCC 配下の広告アカウントと接続済みの組織」だけ選べる。同じルート MCC 配下の広告アカウントがすでに BM 組織とつながっていると、BM 組織の新規作成はできない ✅〔仕様〕（F63-01）

### 2-5. 接続の操作に要る権限 ✅〔仕様〕（F63-01、F63-03 p30）
| 対象 | オンラインサインアップ | 代理店経由 |
|---|---|---|
| 広告アカウント | 既存の広告アカウントをつなぐなら**ルート MCC の管理権限** | 広告アカウントの管理権限 |
| LINE 公式アカウント | BM と未接続なら LINE 公式アカウントの管理権限（接続済みなら不要） | 同じ |
| BM | **BM 組織の管理権限** | 権限は要らない（組織 ID を入れて申請し、BM の管理者が承認） |

- 申請の取り下げ・再申請にもルート MCC の管理権限が要る ✅（F63-01）

### 2-6. 手順と日数 ✅〔仕様〕（F63-01、F63-03 p31〜37）
- 場所: 広告アカウントの作成・編集画面の「ビジネスマネージャー・LINE 公式アカウント接続」（PDF は「ツール」→「アカウント設定」から）
- オンラインサインアップ: LINE 公式アカウントは「BM 組織から選ぶ」「利用中の LINE 公式アカウントから選ぶ」「新規作成」の 3 通り。BM は「BM 組織から選ぶ」「新規作成」の 2 通り
- 代理店経由: BM の**組織 ID** と LINE 公式アカウントの**ベーシック ID** を入れる。広告管理ツールからは新規作成できない（各サービスの画面で作る）
  - BM 組織の管理権限があれば、その時点で自動承認
  - 無ければ「管理者認証用 URL」を BM の管理者に送って承認してもらう。**URL の有効期間は 168 時間**（7 日）。切れたら再申請
  - BM の管理者が「接続を申し込む」を押すと、BM で接続の審査がある。**認証審査は 5 営業日ほど**（PDF p36）
- 接続の状態は広告アカウントの「アカウント設定」の「ステータス」で見る（完了すると「接続済み」）。審査の状況は BM の管理画面でも見られ、完了時に BM の管理者へメールが届く
- **BM と広告アカウントの企業情報が違うと、接続の審査で否認されることがある**。企業情報を変えたら接続の再審査が要る ✅〔仕様〕（F63-03 p38）

### 2-7. つながっていても使えない状態 ✅〔仕様〕（F63-01、F63-17）
| 状態 | 広告の配信 | 使えなくなるもの |
|---|---|---|
| BM 組織が未認証・審査中 | できる | BM の機能（オーディエンスリスト連携など） |
| LINE 公式アカウントが審査で否認 | できる | 友だち追加広告、友だち関連のオーディエンスリスト、プロフィール画像の連携 |
| LINE 公式アカウントが「機微な情報を扱う可能性がある」と判断された | できる | 同上（**審査結果にかかわらず**） |
| LINE 公式アカウントが未認証（接続はできる） | できる | 接続審査が「未認証」のままで、データは使えない（コラム F63-17） |

### 2-8. よくあるつまずき（公式コラム、2026-07-30）〔公式の推奨〕（F63-17）
- 別のビジネス ID でログインしていて、既存の LINE 公式アカウントや BM が出てこない
- 管理権限が無く「管理権限がないため接続申請できません」と出る
- BM 組織が「未認証」のまま（登録メールの認証メールが迷惑メールに入っていることがある）
- BM 組織が「否認」（理由を見て直し、再申請）
- 接続先が「管理者確認待ち」のまま
- LINE 公式アカウントが複数あり、広告で訴求しないアカウントを選んでしまう
- コラムの推奨: **1 企業につき 1 組織**の作成を勧める。進め方は ビジネス ID の確認 → LINE 公式アカウントの作成・選択（広告で訴求する店舗・サービスのもの）→ BM の作成・選択 → 広告サービス情報の入力 → ログインしてステータス確認

### 運用の判断への効き方
- **接続は後から変えられない**。ブランドや店舗ごとに LINE 公式アカウントが分かれている会社は、「どの広告アカウントがどの LINE 公式アカウントの友だちを増やすか」を先に表にしてから広告アカウントを切る〔推測。F63-01 の 1 対 1 と変更不可から〕
- 代理店経由なら、BM の管理者（広告主側の人）に承認 URL を送る段取りを先に決める。**168 時間で切れ**、承認後も**接続審査に 5 営業日ほど**かかる。開始日から逆算して 2 週間前には申請する〔推測。F63-01、F63-03 p36 の日数から〕
- 検索広告だけの広告主は、つないでも 2026-04-01 時点で使える機能が無い。オンラインサインアップの新規追加で必須なだけ（S-12）
- 医療・介護・婚活・債務などの業種は、LINE 公式アカウントが「機微」と判断されると、友だち追加広告もリストも使えない。**つなげば使える、と見積もらない**（§5-3）

## 3. 友だち追加目的の広告

### 3-1. 何をする広告か ✅〔仕様〕（F63-02、F63-03 p5・p11）
- LINE 公式アカウントの友だち獲得を目的にした広告。**ディスプレイ広告のデータを使って配信する**。キャンペーン目的に「友だち追加」を選ぶと作れる
- 最適化ポイントは「友だち追加数（広告クリック数）」。友だち追加数が最大になるよう配信を最適化する
- 提供開始は 2024-10-07（当時の Yahoo!広告 ディスプレイ広告（運用型））✅（F63-10）
- 公式 PDF は、LINE 広告や LINE 公式アカウントで友だち追加広告を出している場合も「活用できるデータ・ターゲティングなどの配信プラットフォームごとの差異やオークションの状況も異なる」ので状況に応じて検討を、と書く ✅〔公式の推奨〕（F63-03 p6）

### 3-2. 使える条件 ✅〔仕様〕（F63-02、F63-03 p9・p41・p47〜48）
| 条件 | 中身 |
|---|---|
| 広告アカウント | 広告主情報が**日本国内**。契約当事者が「**広告主**」 |
| 代理店契約のアカウント | 2024-10-01 改定の広告取扱基本規定に同意すれば使える。オンラインサインアップは手続き不要 |
| 海外の広告主情報 | 使えない（今後提供予定、詳細未定） |
| BM | 組織が**認証済み** |
| LINE 公式アカウント | **認証済み** |
| BM と LINE 公式アカウント | 接続審査が完了 |
| 例外 | 条件を満たしても、一定の条件に当たる LINE 公式アカウントは使えない（§2-7） |

- 目的の選択肢: PDF は「キャンペーン目的『友だち追加』はすべてのアカウントに表示されますが、上記以外のアカウントでは利用いただけません」と書き、作成手順のページは「本機能の提供対象でない、もしくは BM や LINE 公式アカウントとの接続が完了していない場合は選択できません」と書く ✅（F63-03 p9・p41）。23 §3-1 の「一部のお客様のみ」（H000044496）と合わせると、**表示はされるが選べない**状態がありうる △（表示の扱いの書き方が資料で違う）
- BM のメニューが出ない理由: 「アプリ・ツール連携」メニューの「ビジネスマネージャー」は、使えるアカウント（国内・広告主契約）にだけ表示される ✅（F63-03 p47〜48）

### 3-3. 課金と数え方 ✅〔仕様〕（F63-02、F63-03 p11・p12・p47・p48）
- 課金方式は「クリック課金（友だち追加課金）」。**友だち追加 1 件を 1 クリックとして扱い**、友だち追加数はパフォーマンスデータ・パフォーマンスレポートの「**クリック**」に入る
- **広告タップの数は数えない**。広告をタップせず直接友だち追加できる場合もある
- 広告をタップしたときの動きは 2 通り: **ワンタップで友だち追加が完了**する形と、**ポップアップが出てから追加**する形。どちらが出るかは配信時のデザインで決まり、**選べない**
- ポップアップの形では、ポップアップの友だち追加ボタンが押されると実績に入る。**ポップアップの数は確認できない**
- PC で表示された広告から友だち追加すると、スマートフォンの LINE アプリに「友だち追加された」旨のメッセージ通知が届く（クロスデバイス、2026-06-09〜）✅（F63-12）

### 3-4. 入札戦略 ✅〔仕様〕（F63-07、F63-03 p13）
| 入札戦略 | 中身 | 公式の使い分け（フロー図） |
|---|---|---|
| 友だち追加数の最大化（目標値あり） | 友だち追加単価の目標値を保ちながら、できるだけ多く友だちを獲得するよう入札を自動調整 | 「1 日の予算内で友だち追加数を最大化したい」かつ「目標とする友だち追加単価を決めたい」 |
| 友だち追加数の最大化（目標値なし） | キャンペーンの 1 日の予算の範囲で友だち追加数が最大になるよう自動調整 | 「1 日の予算内で最大化したい」が、目標単価は決めない |
| 個別友だち追加単価 | 友だち追加 1 件あたりの最大入札価格を指定。それを上限に入札 | 「指定した入札価格を上限に入札したい」 |

- 入札戦略はキャンペーンで設定し、広告グループ独自の入札価格も置ける（ディスプレイ共通、S-120）
- 自動の 2 つ（目標値あり・なし）は、年齢・性別・デバイス・興味関心・時間帯・地域・サイト訪問履歴・**過去の検索キーワード**・広告配信実績・オーディエンスリスト・プレイスメント・広告タイプを読んで最適化する。**性別や年齢で広告グループを分ける必要はなく、まとめる方を勧める** ✅〔公式の推奨〕（F63-07）
- **学習状況が表示される**（友だち追加数の最大化の 2 つ）。「学習中」が **7 日以上**続いたら、配信されているか・ターゲティングを絞りすぎていないか・予算は適切かを見直す。それでも続くなら拡張クリック単価か動画再生課金に変えるよう書かれているが、**この 2 つは友だち追加目的では選べない**ので、友だち追加目的での最後の手は ❓ ✅〔公式の推奨〕（F63-08）
- **推奨入札価格は無い**（「友だち追加目的のキャンペーンについて、推奨入札価格はありますか？」→「いいえ、ありません」）✅（F63-03 p47）
- 目標値ありの**推奨件数**（コンバージョン数の最大化の「キャンペーン単位で直近 30 日 40 件」、`LY-入札-028`・00 §4）に当たる記述は友だち追加では見つからない ❓
- 目標値の上限・下限の値 ❓（記載なし）

### 3-5. ターゲティングと除外 ✅〔仕様〕（F63-02、F63-03 p11・p42・p45）
- 運用型で使えるターゲティングはすべて設定できる
- 広告グループを作ると「**LINE 公式アカウントの友だち**」リストが**配信設定「除外」として自動で付く**。**解除はできない**（PDF p42）。目的は、すでに友だちの人を配信対象から外すこと
- このリストが未作成なら、キャンペーン作成時にシステムが自動で作って除外に付ける（ヘルプ F63-02）△ 23 §5-4・オーディエンスリストのヘルプ（F63-06）は「事前に作成が必要」と書く。PDF の FAQ は「事前作成せずとも、キャンペーンを作成できます」、同じ PDF の注意事項 p14 は「事前に…リストの作成が必要」。**公式の中で食い違う**。実際の手順としては、事前に作っておけば両方の記述を満たす〔推測〕
- 「LINE 公式アカウントの友だち」リストを**配信対象には設定できない**（友だち追加目的の中で）
- 「LINE 公式アカウントの友だち」以外のリストは任意で付けてよい
- **スマートターゲティングの利用は非推奨** 〔公式の推奨〕（F63-03 p11）
- 2026-12-09 予定のチャット誘導広告の資料: 友だち追加目的のキャンペーンでは、すでに友だち追加済みのユーザーに広告は表示されない ✅（S-40）

## 4. 友だち追加の数え方と、数字の突き合わせ

### 4-1. 広告管理ツール側 ✅〔仕様〕（F63-02、F63-03 p11・p47）
| 何を見たいか | どの列か | 注意 |
|---|---|---|
| 友だち追加数 | 「クリック」 | 広告タップは入らない。ポップアップ形はポップアップ内のボタンで数える |
| 友だち追加単価 | 費用 ÷ クリック（＝平均クリック単価） | 「友だち追加単価」という名前の列はヘルプで見つからなかった ❓ |
| 表示に対する追加率 | クリック率 | タップしたが追加しなかった人の数は見られない |
| ポップアップの表示数 | なし | 「ポップアップの数は、確認できません」 |

### 4-2. LINE 公式アカウント側（分析 ＞ 友だち）✅〔仕様〕（F63-20、2026-03-24 更新のマニュアル）
- 「概要」は友だち追加・ターゲットリーチ・ブロックを示す。既定は直近 7 日、過去は最大 397 日まで選べる
- 「属性」はターゲットリーチの性別・年齢・地域。**おおむね 3 日前の数値**。ターゲットリーチが少ないと「不明」になる
- 「追加経路」は最大 90 日。経路ごとの友だち追加とブロック
  - **ブロック数は「期間中のブロック数」**で、期間中に追加した人のブロック数ではない
  - **友だち期間が 90 日以上の人のブロックは「その他」に入る**。そのため「その他」はブロックが追加を上回ることがある
  - 期間内に追加・ブロックが **20 回未満**の経路・流入元・キャンペーンは数値を出さず「その他」にまとめる。日別の折れ線も、その日が 20 未満なら 0 と表示
  - フィルターで絞り込むと数値は **50 単位の概算**
  - 経路「**友だち追加広告**」には、LINE 広告・**LINEヤフー広告の友だち追加目的のキャンペーン**・LINE 公式アカウントの管理画面から出した友だち追加広告からの追加が**まとめて**入る
- 分析には「友だち追加広告」の欄もあり、表示・友だち追加・追加率・友だち追加単価が出る。旧版と「友だち追加広告（新）」があり、旧版は 5 年分。**この欄は LINE 公式アカウントの管理画面から出した友だち追加広告の数字**と読める（マニュアルは別ページを参照させる）〔推測〕
- アプリの版によって、分析の数値と追加経路の数値が合わないことがある ✅（F63-20）

### 4-3. 「概要」と「追加経路」でも合わない ✅〔仕様〕（F63-24、LINE for Business の FAQ、2023-12-14）
| 画面 | ブロック解除 |
|---|---|
| 概要 | **ブロック解除しても友だち追加数は増えない** |
| 友だち追加経路 | **ブロック解除で友だち追加数が増える** |

### 4-4. 広告側と LINE 公式アカウント側が合わない理由（まとめ）
| 理由 | 広告側 | LINE 公式アカウント側 | 根拠 |
|---|---|---|---|
| 経路の束ね方 | 友だち追加目的のキャンペーンだけ | 「友だち追加広告」経路に LINE 広告・管理画面の友だち追加広告も入る | ✅ F63-20 |
| 少数の扱い | 1 件から出る | 20 回未満は「その他」、絞り込みは 50 単位 | ✅ F63-20 |
| ブロック解除 | 数えるかは ❓ | 概要は数えない、追加経路は数える | ✅ F63-24、❓ |
| 期間の切り方 | 日付ごと（広告管理ツールの集計の日） | 概要 397 日・経路 90 日・属性は約 3 日前 | ✅ F63-20 |
| 追加後すぐのブロック | 課金済みの追加として残る〔推測〕 | ブロックとして別に数える | 〔推測〕 |

### 4-5. ブロック・再追加・重複の扱い ❓
- 同じ人がブロック → 広告から再追加したとき、広告側で 1 件と数え課金するか: **記載なし** ❓
- 友だち追加直後にブロックされても課金は戻るか: **記載なし** ❓（課金は「友だち追加 1 件」に対して発生、と書くだけ）
- ブロック中の友だちに友だち追加広告が出るか: 自動除外は「友だち」リストだけ（§3-5）。ブロック中の人が広告から追加（＝ブロック解除）したときの扱いは ❓

### 4-6. 友だち追加の「後」の成果の測り方
- 友だち追加広告には最終リンク先 URL もトラッキング URL も無い（§3-6）。**友だち追加目的のキャンペーンの中で、追加後のサイトでの購入を広告のコンバージョンとして測る仕組みの記述は見つからない** ❓
- LINE 公式アカウントでも計測タグが使える（認証済み BM に接続した LINE 公式アカウント、06 §計測タグ・S-17）。LINE 公式アカウントのメッセージ経由の購入を計測タグで追う形はありうるが、**友だち追加目的の広告の成果に結びつける公式の方法は ❓**
- 公式の事例（旧 LINE 広告、2021 年）でも、追加後の成果は「友だち数」と「友だち獲得単価 30〜40 円」までで、追加後の売上は書かれていない〔実務家・仮説ではなく公式の事例だが、古く条件不明〕（F63-28）

### 運用の判断への効き方
- **報告では、友だち追加の数は広告管理ツールの「クリック」を正にする**（課金の根拠がそこにある）。LINE 公式アカウントの経路の数字は「広告全体でどれだけ増えたか」の参考として並べ、差を「束ね方・20 未満・ブロック解除」で説明する〔推測。§4-4 から〕
- **ブロック率は LINE 公式アカウント側でしか見えない**。しかも経路の「ブロック数」は期間中に追加した人のブロックではない。「広告で来た友だちのブロック率」は公式の画面から正確には出せない ❓。BM 経由の「友だち追加経路オーディエンス」（§6）を使っても、ブロックの率までは出ない〔推測〕
- 友だち追加の単価だけで止めず、**追加後のメッセージで何が起きたか**（メッセージのクリック・計測タグの CV）を別に測る設計を、広告を出す前に決める〔推測〕

### 5-1. 23 に無い仕様 ✅〔仕様〕（F63-03 p17・p49〜51、F63-06）
- **ブロックリストから LINE 公式アカウントを削除したユーザー**も、友だち関連リストに入らない（長期間未ログインの人に加えて）
- 友だち関連リストは **MCC アカウントのオーディエンスリスト共有ができない**。友だち関連リストを使った**組み合わせリストも共有できない**
- 有効な友だち関連リストは、**配信に使っているかどうかにかかわらず**各 1 つだけ（データ連携停止で使えなくなったリストは件数に数えない）
- 削除できる条件: 組み合わせリストの元に使っていない、広告グループに設定していない
- データ連携は、LINE 公式アカウントと広告アカウントが連携していれば**自動**
- 連携元（LINE 公式アカウント）の人数と、広告側のユーザーサイズには**差が出ることがある**
- **オーディエンス分析の対象外**
- **一部の配信面ではユーザーを識別できず、友だち関連リストのターゲティングが効かない**ことがある（2025-04 追記）
- **提携パートナーなど一部の媒体では、友だち関連リストを配信対象として使えない**（2025-08 追記、プライバシー保護の規定と配信ポリシーによる）
- 「友だち追加」目的以外のキャンペーンでも使える（配信対象・除外とも）

### 5-2. 配信・除外に使える人数の下限 ✅〔仕様〕（F63-03 p45、F63-10、F63-15）
| 使い方 | 下限 | 時期 |
|---|---|---|
| **除外** | **下限なし**（0 から）。友だち関連リストは最初から制限なし。高度なセグメント・広告アクションユーザーは 1,000 → 0 | 2024-10-07 |
| 配信対象 | 1,000 以上 → **100 以上**（広告アクションユーザー・高度なセグメント・BM・LINE 公式アカウントの友だち・ブロック中の友だちの 5 種） | 2026-11-10 |
| 友だち関連リストを含む**組み合わせ**リストを配信対象に | PDF（2026 年 8 月版）は「1,000 以上」 | 2026-11-10 の変更が組み合わせに及ぶかは ❓（お知らせに記載なし） |

- 2026-11-10 の変更について、公式は「配信傾向が変わる可能性がある」ので対象リストを付けている広告グループの実績を確かめるよう案内 〔公式の推奨〕（F63-15）

### 5-3. 配信対象に使うときの審査 ✅〔仕様〕（F63-04、F63-03 p18〜21）

### 5-4. 類似ユーザーの元にする ✅〔仕様〕（F63-03 p17、F63-06）
- **2026-03 から「LINE 公式アカウントの友だち」を元に類似ユーザーを作れる**（それまでは友だち関連リストは元にできなかった）
- 「ブロック中の友だち」を元にできるかは、ヘルプの元リストの一覧に無い（一覧は広告アクション・ウェブサイト訪問・アプリ・顧客データ・Yahoo! Audience Discovery・LINE 公式アカウントの友だち・BM）→ 元にできないと読める〔推測〕

### 5-5. 接続が止まったとき（23 §5-4 の補足）✅〔仕様〕（F63-03 p23）
- 止まる場合: LINE 公式アカウントの削除・停止、**広告アカウントと BM の接続停止**、**BM と LINE 公式アカウントの接続停止**など
- 友だち追加キャンペーンは配信停止・再開不可・新規作成不可。**再接続した後も、既存のキャンペーンやリストは使えず作り直し**
- 友だち関連リストは 0 になり、配信・除外・組み合わせに使えない。**友だち追加目的以外のキャンペーンに付けている場合、自動では配信停止しない**（つまり、除外のつもりのリストが効かないまま配信が続く）
- 広告管理ツールのキャンペーン一覧やオーディエンスリストの画面に警告マークが出る

### 運用の判断への効き方
- **除外は下限なし、配信対象は 100 以上**。友だちが少ない立ち上げ期でも「既存の友だちを外す」除外はすぐ効く。配信対象として使うのは 100 人を超えてから〔推測。§5-2 から〕
- **接続が切れると、友だち追加目的以外の除外が黙って効かなくなる**（自動停止しない）。サイト誘導やコンバージョンのキャンペーンで「既存の友だちを外す」設計にしている場合は、警告マークを週次の点検に入れる〔推測。F63-03 p23 の ※2 から〕
- 医療・介護・婚活・債務などは、友だちリストを**配信対象**に使う設計を最初から立てない。使うなら除外だけ〔推測。F63-03 p21 から〕
- 友だちへの配信・ブロック中の友だちへの配信は、**もともと買う人に出している**可能性が高い。増分（ι）が小さくなりやすいので、ほかのキャンペーンと同じ CPA の目標で並べない（`36` 型02 の行、`90`）〔推測〕
- ブロック中の友だちはメッセージが届かない人たち（§7-1）。広告で再接触できる唯一の手段の 1 つだが、公式の推奨としての使い方は見つからない（チャット誘導のお知らせが期待効果に「ブロックユーザーの抑制」を挙げるだけ、S-40）〔推測〕

- **MCC アカウントへの共有はできない**

- △ **類似ユーザーの元にできるか**: BM 経由のページ（F63-05）は「オーディエンスリスト『ビジネスマネージャー』は、オーディエンスリスト『類似ユーザー』の基となるリストとして利用できません」。オーディエンスリストとは（F63-06）は類似ユーザーの元に「ビジネスマネージャー（LINE 広告の『類似オーディエンス』は対象外）」を挙げる。**同じヘルプの中で逆のことを書いている**（23 §5-5 は後者を採っている）

## 7. LINE 公式アカウントのメッセージ配信との関係

広告の料金ではないが、友だちを増やす判断に効く範囲だけを書く。

### 7-1. 料金プランと通数 ✅〔仕様〕（F63-23、料金プランのページ、2026-11-23 取得）
| プラン | 月額（税別） | 無料メッセージ通数 | 追加メッセージ |
|---|---|---|---|
| コミュニケーションプラン | 0 円 | 200 通 | 不可 |
| ライトプラン | 5,000 円 | 5,000 通 | 不可 |
| スタンダードプラン | 15,000 円 | 30,000 通 | 可（従量。「〜¥3/通（税別）」と表示、段階の単価は画像のみで文字では ❓） |

- **通数 ＝ 送信回数 × 配信した友だちの人数**。1 回の配信は最大 3 吹き出し
- 課金対象: メッセージ配信（絞り込み・ステップ配信を含む）、Messaging API の Push・Multicast・Broadcast・Narrowcast
- 課金対象外: LINE チャットの送受信、応答メッセージ、**あいさつメッセージ**、Messaging API の Reply API
- **ブロックしている友だちにはメッセージが届かない**。ブロック中の人が通数に入るかはページに明記なし ❓（下のターゲットリーチの定義からは、配信の対象はブロックを除いた人と読める〔推測〕）
- 開設時はコミュニケーションプラン。月の途中の上位変更は差額で即時、差分の通数が付く
- 追加メッセージには**上限の目安**を設定し、超えると配信が止まる（ただし目安で、配信方法によっては超える）
- 追加メッセージ料金は **2026-10-01 に改定**。プレミアム ID は 2026-12-01 に改定予定
- 支払いはクレジットカードが基本。請求書払いは認証済みアカウントだけ

### 7-2. ターゲットリーチ ✅〔仕様〕（F63-25 抜粋、F63-20）
- 基礎用語集の定義: **友だち数からブロックした人などを除いた、メッセージを配信できるユーザーの数**（2023 年 10 月の資料。本文の文字はフォントの都合で取り出せず、検索結果の抜粋と、取り出せたカタカナ部分で確かめた △ 本文照合が不完全）
- 性別・年齢・地域の属性は、ターゲットリーチについて見る（F63-20）
- 属性で絞り込むメッセージ（ターゲティングメッセージ）は**ターゲットリーチ 100 人以上**が要る（検索結果の抜粋、本文未確認 △）

### 7-3. 友だち追加の「維持の費用」の考え方〔推測〕
- 例（計算の型だけ。数字は仮）: 友だち追加単価 100 円で 1,000 人を足し、週 1 回配信する。月の通数は 1,000 人 × 約 4 回 ＝ 約 4,000 通増える。ライトプランの 5,000 通を超えるなら上位プランか、配信の頻度を下げるか、絞り込み配信にする
- つまり**友だち 1 人の費用 ＝ 獲得単価 ＋ その人に送るメッセージの代金 ×（ブロックされるまでの回数）**。広告の「友だち追加単価」だけを KPI にすると、増えた友だちへの配信費が見えない
- 逆に、ブロックされた友だちは通数に入らない（§7-1、明記なし ❓）ので、ブロック率が高いと「獲得したのに配信できない人」に広告費を払ったことになる

### 7-4. 友だち追加の前に LINE 公式アカウント側で整えること〔公式の推奨〕（F63-27 キャンパスのレッスン、F63-21）
- **プロフィール**: 友だち追加時に表示されるので、営業時間・住所・URL・問い合わせ先をできるだけ更新する
- **あいさつメッセージ**: 友だち追加時に自動で送られる。初期状態は定型文なので、配信前に見直す（あいさつメッセージは通数の課金対象外、F63-23）
- 経路を設定すると「分析 ＞ 友だち ＞ 追加経路」で流入を見られる（20 件未満は「その他」）（F63-21）
- ユーザーが LINE 公式アカウントに期待することの調査（LINEヤフー社調べ、n＝2,060、時期は記載なし）: 1 位「最新情報や新製品・キャンペーンなどが見落としにくい」、2 位「自分に合った情報やクーポン」。**友だち限定の情報（新商品の予約・クーポンなど）を出すと友だち追加を促しやすい**（F63-27 oa-4-5-1）

### 7-5. チャット誘導広告（2026-12-09 予定）との関係 ✅〔仕様〕（S-40）
- 広告をクリックした人を LINE 公式アカウントの**トークルームへ誘導し、広告に設定したシナリオでメッセージを自動送信**する
- 条件: BM と LINE 公式アカウントが認証済み、BM・LINE 公式アカウント・ディスプレイ広告アカウントの接続が完了、広告管理ツールで自動応答のシナリオを作成、**チャット誘導目的か友だち追加目的**のキャンペーンで「レスポンシブ広告（チャット誘導）」を作る
- 友だち追加目的では、すでに友だちの人には出ない。チャット誘導目的では、**ブロックしている人には出ない**
- シナリオ内のメッセージは**広告審査の対象**で、広告掲載基準が適用される
- 課金・最適化・メッセージ通数との関係・計測は、お知らせのページに記載なし ❓（資料 PDF は未取得）

### 運用の判断への効き方
- **友だち追加の目標は「友だち数」ではなく「配信できる友だち（ターゲットリーチ）」と「その人たちの反応」で置く**。友だち数はブロックした人も含む（用語集の定義から）〔推測〕
- 友だち追加広告を始める前に、プラン（通数）と配信の頻度を決める。コミュニケーションプランの 200 通は、友だち 200 人に 1 回送れば終わる〔推測。F63-23 の数え方から〕
- あいさつメッセージは課金外で、追加直後に必ず届く唯一の接点。広告の訴求（クーポンなど）と中身をそろえる〔推測〕

## 8. LINE 公式アカウントの管理画面から出す「友だち追加広告」との違い

LINE 公式アカウントの管理画面（LINE Official Account Manager）にも「友だち追加広告」がある。名前が同じで、**LINEヤフー広告の友だち追加目的とは別の入口**。

### 8-1. 管理画面の友だち追加広告 ✅〔仕様〕（F63-22、2026-05-20 更新のマニュアル）
- **2026-05-09 にリニューアル**。新規出稿は「友だち追加広告（新）」から。旧版は提供終了予定で、旧版を使っていたアカウントにだけ表示
- 使える条件: **認証済みアカウント**（一部業種は掲載不可）、支払い方法が登録済み、**BM の認証済み組織と接続**。**LINEヤフーの認定セールスパートナーが開設・管理するアカウントは対象外**
- 課金: 友だち追加された場合にだけ料金が請求される
- **1 日の予算は目安で上限ではない**。実際のコストは予算を下回ることも上回ることもある
- **月の上限**: 当月の利用額が上限に達すると配信が止まる。上限の引き上げは問い合わせ。**今月中に引き上げても再開は翌月から**
- 友だち 1 人あたりの上限予算: 任意。「**設定しない（推奨）**」。設定すると上限を超えない入札になり、1 日の予算を使い切れないことがある。ターゲットが狭いと単価が上がりうるので、オーディエンスは広めを推奨
- ターゲティング: 性別、年齢、エリア（店舗のアカウントは地域の設定を特に推奨）、興味・関心、プレイスメント（「全て」「LINE アプリ面」「Yahoo! JAPAN サービス面」）。推計オーディエンスが出る
- 素材: 見出し・本文、画像か動画、比率を選んでアップロード（文字数・画素の記載なし ❓）

## 9. プロフィール画像の連携

### 9-1. 仕様 ✅〔仕様〕（F63-13、F63-01、F63-03 p43）
- **2026-01-06 から、ディスプレイ広告（運用型）の「全ての広告」で** LINE 公式アカウントのプロフィール画像を連携できる（それまでは友だち追加目的の広告だけ）
- 表示される面（実施時）: LINE アプリの広告配信面のうち **LINE VOOM と LINE オープンチャット**。対象は今後拡大予定
- LINE VOOM は 2026-09-30 で広告配信終了（S-44）。**2026-11 時点で表示される面はオープンチャットだけと読める**が、その後の拡大のお知らせは見つからない ❓〔推測〕
- 使うには LINE 公式アカウントとの**接続と設定**が要る。**実施日より前に接続していたアカウントは自動で連携**
- 友だち追加広告では、ロゴは LINE 公式アカウントのプロフィール画像に固定（§3-6）
- LINE 公式アカウントが否認・機微と判断された場合は使えない（§2-7）
- プロフィール画像そのものは LINE 公式アカウントの管理画面（ビジネスプロフィール）で設定する

### 9-2. 公式コラムの推奨〔公式の推奨〕（F63-18、2026-08-04）
- LINE 面の配信では、コンバージョンの傾向から**トークリストと LINE NEWS が特に重要**、**ホームタブが 3 番目**。ホームタブへの配信に備えて、**LINE 公式アカウントのアイコンを設定しておく**ことを勧める

### 運用の判断への効き方
- プロフィール画像は**広告の一部として表示される**。友だち追加広告ではロゴとして必ず出る。店舗ロゴの角丸や文字の詰め込みなど、ディスプレイのロゴ画像の決まり（180×180、角丸禁止、23 §9-1）と同じ感覚で整えておく〔推測。F63-03 p43 と 23 §9-1 から〕
- どの面で表示されるかが VOOM 終了で狭まっている。連携の効果を測る段取りは立てにくい〔推測〕

## 11. 判断の型

### 11-1. 始める前に決める順番〔推測。§2〜§8 から組んだ〕
1. **どの LINE 公式アカウントの友だちを増やすか**を決める（広告アカウントと 1 対 1、後から変えられない、§2-4）
2. LINE 公式アカウントが**認証済み**か、業種が「機微」に当たりそうか（§2-7、§5-3）。当たるなら友だち追加広告とリストの配信対象は諦め、除外の用途だけを見込む
3. **BM の組織**を 1 つに決め、認証を済ませる。代理店経由なら承認 URL（168 時間）と接続審査（約 5 営業日）を逆算（§2-6）
4. LINE 公式アカウント側: プラン（通数）、プロフィール、あいさつメッセージ、友だちになった後に送る内容と頻度（§7）
5. 計測: 友だち追加の数は広告の「クリック」。追加後の成果をどこで測るか（§4-6）
6. 入口を選ぶ: ディスプレイの友だち追加目的か、LINE 公式アカウントの管理画面の友だち追加広告か（§8）。両方なら数字の分け方を決める
7. 入札: まず目標値なしで単価の相場を見て、目標値ありへ〔推測〕
8. 面: PC と Yahoo! 各サービス（2026-06〜）、Yahoo! JAPAN トップ（2026-02〜）に出してよいか（§3-7）

### 11-2. 友だち追加の単価が悪いときの確認順〔推測〕
1. 接続の状態（警告マーク）。切れていたら作り直し（§5-5）
2. 配信先 URL レポートで面の内訳（LINE 面か Yahoo! 面か PC か）
3. 学習状況（7 日以上の「学習中」）（§3-4）
4. ターゲティングの絞りすぎ（友だち除外は外せないので、既存の友だちが多いほど配信できる人は減る）
5. 素材（画像・タイトル・75 文字の説明文）。LINE 公式アカウントの名前とプロフィール画像も広告の一部
6. 入札（目標値を上げる・個別単価を上げる）。**推奨入札は公式に無い**ので、相場は自分の実績から

### 11-3. 「友だちは増えたが成果が出ない」とき〔推測〕
- LINE 公式アカウントの経路別のブロック数（ただし期間中のブロックで、追加した人のブロックではない、§4-2）
- メッセージのクリック、BM 経由のメッセージクリックオーディエンスの大きさ（§6）
- 通数の消化とプラン（配信できていない友だちがいないか、§7-1）
