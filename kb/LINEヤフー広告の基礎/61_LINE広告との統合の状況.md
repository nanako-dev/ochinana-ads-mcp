### 4-2. 配信面の注意 ✅〔公式〕S-03 p37
- **プレイスメントを指定しないと、LINE の面に加えて Yahoo! の面、提携パートナーにも出る**。配信先のプラットフォームを指定しないと、配信対象は LINE 広告のころより広がる
- LINE 面の主な配信先: トークリスト、LINE NEWS、ホーム など（S-48）、友だちタブ（2026-07-06〜、S-45）、ミニアプリタブ（旧ウォレット、S-46）。LINE VOOM は 2026-09-30 で終了（S-44）。LINE のファミリーアプリ（LINE camera、LINE GAME など）にも配信される（S-47）
- Talk Head View（トークリスト最上部）と LINE NEWS Top Ad は予約型の商品（代理店経由）として扱われる ✅〔公式・抜粋〕（検索結果の抜粋。商品一覧の本文は未取得）

運用の判断への効き方:
- 旧 LINE 広告で「詳細ターゲティングで絞り、さらにオーディエンスで絞る」設計だったものは、**統合後は OR になって配信が広がる**。移行ツールでコピーした直後に、組み合わせリストで AND を作り直すか、意図どおりかを確認する（S-03 p26）
- Yahoo! 面と LINE 面で CPC や CVR が違う。公式コラムの代理店事例は「面ごとに入札を分けた」ことを成功の理由に挙げる（S-48、事例は代理店の発言で一般化はできない〔推測〕）。**面ごとに成果を見たいなら、面ごと（またはアカウントごと）にキャンペーンを分ける**のが公式の移行設計の一案（S-03 p39「配信面ごとの予算をアカウント単位で管理したい場合」）

### 4-3. 移行の方法（2026-11-18 時点では「後片付け」の段階）✅〔公式〕S-03 p38〜60、S-04

| 方法 | 中身 | 引き継げるもの | 引き継げないもの |
|---|---|---|---|
| 移行ツール | LINE 広告の管理画面で提供。設定をコピー（元は残る）。キャンペーンは配信オフで作られる | グループ（→MCC）、広告アカウント、カード情報（任意）、権限（任意）、キャンペーン・広告グループ・広告の設定、素材、**オーディエンスに溜まったユーザー**、審査の承認（自動承認） | 「商品フィードから販売」目的、LINE Tag とコンバージョン設定、**過去の実績とレポート、自動入札の学習**、外部ツールの API 連携、操作履歴、免税設定 |

運用の判断への効き方:
- **移行ツールでも学習は引き継がれない**。移行直後は入札の学習が一からになり、成果が揺れる前提で予算と評価期間を組む（S-03 p46、p72）。〔推測〕自動入札の評価は、移行から少なくとも 1〜2 週間を外して見る
- 移行ツールで「自動承認」された広告も、**移行後は LINEヤフー広告の基準で掲載後に否認されうる**（S-03 p47）。旧 LINE 広告では通っていた表現でも、Yahoo!寄りに統一された基準で落ちることがある

## 5. タグ・計測・API・審査の統合の中身

### 5-1. タグ
- **計測タグ**は「LINEヤフーのさまざまなサービスのパフォーマンスを計測するためのタグ」。グローバルスニペット（全ページ、1 ページに 1 つ）＋イベントスニペット（計測したいページ）の構成 ✅〔公式〕S-17
- 計測タグを使えるのは、**認証済み BM に接続した LINE 公式アカウント、LINEヤフー広告 ディスプレイ広告、LINEヤフー広告 検索広告（ショッピング）**。通常の検索広告は挙がっていない ✅〔公式〕S-17。通常の検索広告で計測タグが使えるようになる時期は ❓ 公式に記載なし。ただし 2026-10-15 から、検索広告の自動タグ設定の広告に `_ly_c`・`_ly_r`・`_ly_src` のパラメーターが「今後の機能拡充の事前準備」として付き始めた ✅〔公式〕S-36
- 計測できるイベント: page_view、view_listing、view_product、view_cart、add_cart、search、check_out、purchase、generate_lead、login、reservation、sign_up、payment_info、add_wishlist ✅〔公式〕S-19
- 重複排除: アカウント ID と transaction_id の組で 7 日間。計測タグとコンバージョン API の両方から同じ組が来ても重複とみなす。transaction_id が無いときはアカウント ID と event_time の組で、計測期間の間 ✅〔公式〕S-18
- YDA の旧タグ（サイトジェネラルタグ・コンバージョン測定タグ・サイトリターゲティングタグ）は引き続き使えるが、将来的に提供終了の予定 ✅〔公式〕S-03 p29。検索広告（ショッピング）では従来版コンバージョン測定タグ（ウェブ（従来版）・電話発信）の**新規作成が 2026-10-06 に終了**、計測も「今後終了予定」 ✅〔公式〕S-51
- 旧タグと計測タグを同じページに並べると、「全て」の列は両方の合算になる（重複して数える可能性） ✅〔公式・抜粋〕S-94、✅〔公式〕S-50

運用の判断への効き方:
- **計測の設計は「検索広告」と「ディスプレイ・ショッピング」で別に考える**。今のところ、検索広告は旧タグ＋検索広告用の API、ディスプレイ・ショッピングは計測タグ＋計測タグ用の API。1 つのタグで両方を賄う形には、まだなっていない（S-17、S-23）

## 7. 運用者が気をつけること（まとめ）

1. **「LINE 広告」の記事・マニュアル・社内メモは 2026-10-26 以降、日本向けには使えない**。今の正は YDA の仕様（S-03 p18）
2. **ディスプレイの「オーディエンス × 詳細ターゲティング」は OR**。LINE 広告の AND の感覚で組むと広がる（S-03 p26）
3. **プレイスメントを指定しないと Yahoo! 面と提携先にも出る**（S-03 p37）。LINE 面だけ・Yahoo! 面だけで成果を比べたいなら、プレイスメントかアカウントで分ける
4. **インプレッションの定義が vCPM（50%・1 秒）**。LINE 広告の CPM と表示回数・単価を並べて比べない（S-03 p24）
5. **LINE Tag は動かない**。計測タグに貼り替え、コンバージョン設定を作り直す（S-03 p19、p46）
6. **学習は引き継がれない**。移行直後の成果で良し悪しを決めない（S-03 p72）
7. **掲載基準は Yahoo! 寄りに統一**。LINE 広告で通っていた表現でも、掲載後に否認されうる（S-07、S-03 p47）
8. **検索広告は統合の外**。名前が変わっただけで、計測もタグも旧 Yahoo!広告の作法が続いている（S-03 p9、S-17）
