## 0. 先に結論

1. **友だち追加目的は「友だち追加 1 件 ＝ 1 クリック」の友だち追加課金**。レポートには「友だち追加数」という列は無く、**友だち追加数は「クリック数」（API の `CLICKS`）、友だち追加単価は「平均 CPC」（`AVG_CPC`）に入る** ✅〔仕様〕（F64-01、F64-15）。サイト誘導の CTR・CPC と同じ表に並べない
2. **入札戦略は 3 つ**: 友だち追加数の最大化（目標値あり）・（目標値なし）・個別友だち追加単価。API の名前は `MAXIMIZE_GAINING_FRIENDS`（目標値は `targetCpf`＝tCPF、任意）と `CPF`（`cpf` が必須）✅〔仕様〕（F64-02、F64-14）
3. **目標値（tCPF）はキャンペーンにも広告グループにも置ける**（広告グループは任意）。個別友だち追加単価もキャンペーン必須・広告グループ任意 ✅〔仕様〕（F64-14）。目標値・入札の上限下限の数字は ❓ 公式に記載なし。**推奨入札価格は無い** ✅（F63-03 p47）
4. **入札価格調整率（年齢・地域・デバイスなど）は「友だち追加数の最大化（あり／なし）」では効かない** ✅〔仕様〕（F64-03）。除外の一覧に「個別友だち追加単価」は無いので、効くのは個別友だち追加単価だけ〔推測。一覧の裏返し〕
5. **ポートフォリオ入札で「友だち追加数の最大化（目標値あり／なし）」を使える**。個別友だち追加単価はポートフォリオに入らない（API のポートフォリオの型の一覧に `CPF` が無い）✅〔仕様〕（F64-04、F64-14）。共有予算とも組める（1 共有予算 1,000 キャンペーン）✅（F64-04、F64-05）
6. **最適化スコアの対象は「友だち追加数の最大化（目標値なし）」だけ**。目標値ありと個別友だち追加単価にはスコアが出ない ✅〔仕様〕（F64-06）
7. 自動の 2 つは、年齢・性別・デバイス・興味関心・時間帯・地域・サイト訪問・**過去の検索キーワード**・オーディエンスリスト・プレイスメント・広告タイプ・配信実績を読む。**性別・年齢で広告グループを分けず、まとめる**のが公式の推奨 ✅〔公式の推奨〕（F64-02）
8. **友だち追加目的の配信対象は「未友だち」と「ブロック中の友だち」**。すでに友だちの人は自動の除外で外れるが、ブロック中の人には出て、広告から「ブロック解除」できる ✅〔仕様〕（F64-11 p12・p45）。**ブロック解除を 1 件の友だち追加として数えて課金するかは ❓**（63 の ❓ のまま）
9. **審査**: ボタン・主体者・ロゴは LINE 公式アカウントのもので固定。主体者表記には **LINE 公式アカウントガイドラインの「アカウント名称の設定」**がかかり、広告掲載基準の「広告の主体者の明示」の表現規制は適用されない ✅〔仕様〕（F64-08、F64-16、F64-09）。広告そのものの審査の日数は通常のディスプレイと同じ扱い（新規は約 3 営業日、`34`）〔仕様。友だち追加に固有の日数の記載は無い〕
10. **友だち追加の「後」の成果を、友だち追加目的のキャンペーンのコンバージョンとして測る道は、2026-12-09 のチャット誘導広告で初めてできる**: 友だち追加目的の中に「レスポンシブ広告（チャット誘導）」を作ると、追加後にトークルームへ移り、シナリオのメッセージのリンク先での成果を**計測タグ**で測れる（コンバージョン測定タグは使えない）。トークへの遷移とよくある質問の選択はコンバージョンにならない ✅〔仕様〕（F64-11 p26〜p37）
11. **LINE 広告（日本向け）は 2026-10-26 に配信停止・機能提供終了**。管理画面は読み取り専用で、完全な提供終了は 2027 年 3 月末頃の予定（移行ツールも同時期に終了予定）✅〔仕様〕（F64-18、F64-19 p10・p15）。旧 LINE 広告の友だち追加の学習・実績は移行ツールでも引き継がれない（F64-19 p46）。**LINE 公式アカウントの管理画面の友だち追加広告は「LINEヤフー広告で提供している友だち追加広告を LINE 公式アカウントの管理画面から出稿できる機能」としてリニューアルされた（2026-05-09）** ✅（F64-20）
12. 友だちが増えるほど LINE 公式アカウントのメッセージ代が増える。**追加メッセージの単価は 2026-10-01 から 1 通 3 円（月 20 万通まで）・2.5 円（超えた分）、税別、日本** ✅〔仕様〕（F64-21）。友だち追加単価だけで判断しない〔推測〕

## 1. Google との対比

Google 広告には「メッセージアプリの友だちを増やす」目的も課金も無い。比べる相手は、Google の**目標コンバージョン単価で最適化するキャンペーン**と、Google の**リードフォーム**（広告の中で完結する獲得）くらいで、どちらも同じものではない〔推測〕。違いは次のとおり。

| 観点 | Google 広告 | LINEヤフー広告の友だち追加目的 | 運用の判断への効き方 |
|---|---|---|---|
| 成果の単位 | コンバージョン（タグ・インポートで数える） | **友だち追加**（LINE 公式アカウント側の事実。タグは要らない）✅（F64-01） | 計測の設計が要らない代わりに、追加の「後」の価値は自分で測る（§10） |
| 課金 | クリック・表示・（一部）コンバージョン | **友だち追加 1 件に課金（友だち追加課金）**。広告のタップは数えない ✅（F63-03 p11） | 「クリックはあるのに追加が無い」は起きない。追加が無ければ費用も出ない |
| レポートの列 | 「コンバージョン」「コンバージョン単価」 | **「クリック数」「平均 CPC」が友だち追加数と単価** ✅（F64-15） | 媒体をまたぐ表では列名を読み替えて注記する |
| 目標単価の戦略 | 目標コンバージョン単価（独立の戦略） | 「友だち追加数の最大化」の**オプションで目標値**（tCPF）。Yahoo! 流の「最大化の中に目標値」✅（F64-02、F64-14） | 名前の付け方は 02 の検索と同じ向き |
| 入札単価調整 | 自動入札では多くが効かない（デバイスなど一部） | **最大化の 2 つでは一切効かない**（ディスプレイ）✅（F64-03） | 面・デバイスで出し分けたいなら、広告グループかキャンペーンを分けるか、個別友だち追加単価にする |
| 推奨の件数・入札 | 目標 CPA は 30 件以上がたまる期間など | **推奨入札価格は無い**。推奨件数の記載も無い ❓（F63-03 p47） | 相場は自分の実績から作る（§15） |
| 着地先 | LP（最終ページ URL） | **URL が無い**。着地先は LINE 公式アカウントの友だち追加（とトーク）✅（F64-01） | LP 改善の打ち手が使えない。LINE 公式アカウントのプロフィールとあいさつが LP の代わり〔推測〕 |
| 主体者の決まり | 広告主名・ドメインの表示 | **LINE 公式アカウントの名前とプロフィール画像に固定**。決まりは LINE 公式アカウントガイドライン ✅（F64-08、F64-09） | 広告の審査より先に、LINE 公式アカウントの名称と認証を整える |

## 2. 目的の位置づけと、使える条件

### 2-1. 何を最大化するか ✅〔仕様〕（F64-01、F63-03 p11〜p12）
- 最適化ポイントは「**友だち追加数（広告クリック数）**が最大化するように配信を最適化」。課金方式は「クリック課金（友だち追加課金）」
- ディスプレイ広告のデータを使って配信する（Yahoo! JAPAN の検索・行動の情報も最適化に入る、§6）
- ヘルプ本文の特徴の説明は「LINE アプリや Yahoo! JAPAN サービス（スマートフォン、PC）などの広告掲載面に友だち追加広告を表示する」（2026-11-24 の本文。2024-10 の開始時は LINE NEWS だけ、面の移り変わりは 63 §3-7）

### 2-2. 使える条件（要約。本体は 63 §3-2）
- 広告主情報が日本国内、契約当事者が「広告主」、BM 組織と LINE 公式アカウントが**認証済み**、両者の接続審査が完了 ✅（F64-01）
- 一定の条件に当たる LINE 公式アカウントは条件を満たしても使えない（F64-01。中身は 63 §2-7）
- API では、アカウントが使える目的を `AccountAuthorityService/get` の `authorities` で確かめる。**友だち追加目的の値は `GAIN_FRIENDS`** ✅〔仕様〕（F64-14 AccountAuthority）

### 2-3. 他の目的と比べたときの立ち位置 ✅〔仕様〕（F63-03 p12、F64-11 p13）
| 目的 | 最適化ポイント | 課金 | 入札戦略 |
|---|---|---|---|
| 友だち追加 | 友だち追加数（広告クリック数） | クリック課金（友だち追加課金） | 友だち追加数の最大化（あり／なし）、個別友だち追加単価 |
| サイト誘導 | サイト誘導数（広告クリック数） | クリック課金 | クリック数の最大化、拡張クリック単価、個別クリック単価 |
| チャット誘導（2026-12-09 予定） | トークへの誘導数（広告クリック数） | クリック課金 | クリック数の最大化、拡張クリック単価、個別クリック単価 |
| コンバージョン | コンバージョン数 | クリック課金 | CV 数の最大化（あり／なし）ほか |

### 運用の判断への効き方
- **「友だちを増やす」と「トークで話す」と「サイトで買う」は別の目的**。友だちの数そのものが目標なら友だち追加、既存の友だちにも話しかけたいならチャット誘導（§12）、サイトの成果が目標ならコンバージョン目的に LINE 公式アカウントの友だちリストを配信対象として組む（63 §5）〔推測。目的ごとの最適化ポイントから〕
- API で目的を作る道具を組むなら、`GAIN_FRIENDS` が返らないアカウントには友だち追加目的のキャンペーンを作れない前提で分岐を書く〔仕様＋推測〕

## 3. 課金と数え方

### 3-1. 何に課金されるか ✅〔仕様〕（F64-01、F63-03 p11・p47・p48）
| 場面 | 課金・計上 |
|---|---|
| 友だち追加が完了した | **1 クリックとして計上し、課金** |
| 広告をタップしたが追加しなかった | 数えない・課金しない（「広告タップの数はカウントされず」） |
| 広告をタップせずに直接追加できる形 | 追加すれば 1 クリック |
| ポップアップが出る形 | **ポップアップの「友だち追加」ボタン**が押されたら計上。ポップアップの表示数は確認できない |
| ワンタップ形かポップアップ形か | 配信時のデザインで決まり、**選べない** |
| PC で表示された広告から追加 | スマートフォンの LINE に「友だち追加された」旨の通知（2026-06-09〜、F63-12） |

### 3-2. レポートでどの列を見るか ✅〔仕様〕（F64-15 `reports/v20/jp/AD.csv`）
| 見たいもの | 列（日本語表示 / API） | 注意 |
|---|---|---|
| 友だち追加数 | クリック数 / `CLICKS` | 「友だち追加数」という名前の列は無い（レポート項目の一覧で確認） |
| 友だち追加単価 | 平均 CPC / `AVG_CPC` | |
| 表示に対する追加率 | クリック率 / `CLICK_RATE` | タップしたが追加しなかった人の数は出ない |
| 目的で絞る | キャンペーン目的 / `CAMPAIGN_GOALS`（値「友だち追加」） | 他の目的と混ぜて集計しないための切り口 |
| 広告タイプで分ける | 広告タイプ / `AD_TYPE`（値「レスポンシブ（友だち追加）」「カルーセル（友だち追加）」） | 通常のレスポンシブ・カルーセルとは別の値 |
| ビューアブルクリック | ビューアブルクリック数 / `VIEWABLE_CLICKS` | 友だち追加目的でこの列が何を数えるかは ❓（記載なし） |

- コンバージョン系の列（`CONVERSIONS_VIA_AD_CLICK` など）は、友だち追加目的の広告に URL もトラッキングも無いので、2026-12-09 より前は通常は入らないと読める〔推測。§10〕

### 3-3. 重複の扱い
| 場面 | 扱い | 印 |
|---|---|---|
| すでに友だちの人 | 「LINE 公式アカウントの友だち」リストが除外として自動で付き、外せない。チャット誘導の資料も「友だち追加済みのユーザーには広告は表示されない」 | ✅（F63-03 p42、F64-11 p12・p44） |
| ブロック中の友だち | **配信対象に入る**。広告から「ブロック解除」できる | ✅（F64-11 p12・p45） |
| ブロック解除を友だち追加 1 件として数えて課金するか | 記載なし | ❓ |
| 同じ人が追加 → ブロック → 再び広告から追加 | 記載なし | ❓ |
| 追加直後にブロックされた | 課金が戻るとは書かれていない | ❓ |
| 友だちリストに反映されるまでの間に同じ人へ出るか | リストの反映は最大 3 日（F63-03 p50）。その間に既存の友だちへ出たときの扱いは記載なし | ❓ |
| LINE 公式アカウント側の数字との重複・ずれ | 63 §4（経路の束ね方・20 未満・50 単位・ブロック解除の数え方） | ✅（63） |

### 運用の判断への効き方
- **報告の「友だち追加数」は広告管理ツールの「クリック数」を正にする**（課金の根拠がそこ）。LINE 公式アカウント側の経路の数は参考として並べ、差の理由を 63 §4-4 で説明する〔推測〕
- **ブロック中の人に出る**ので、「友だち追加数」の中に「ブロック解除」が混ざっている可能性がある（混ざるかどうかが ❓）。ブロックの多いアカウントで友だち追加単価が急に安く見えたら、LINE 公式アカウント側の「概要」（ブロック解除で増えない）と「追加経路」（増える）を並べて確かめる（63 §4-3）〔推測〕
- 媒体をまたいだ表で「CTR」「CPC」を並べるときは、友だち追加目的の行に「＝友だち追加率・友だち追加単価」と注記する〔推測〕

## 4. 入札戦略

### 4-1. 3 つの戦略 ✅〔仕様〕（F64-02、F63-03 p13、F64-14）
| 戦略（管理画面） | API の値 | 中身 | 設定する値 |
|---|---|---|---|
| 友だち追加数の最大化（目標値あり） | `MAXIMIZE_GAINING_FRIENDS`＋`targetCpf` | 友だち追加単価の目標値を維持しながら、できるだけ多く友だちを獲得するよう入札を自動調整 | 目標友だち追加単価（tCPF） |
| 友だち追加数の最大化（目標値なし） | `MAXIMIZE_GAINING_FRIENDS`（`targetCpf` を入れない） | キャンペーンの 1 日の予算の範囲で友だち追加数が最大になるよう自動調整 | なし（予算だけ） |
| 個別友だち追加単価 | `CPF`＋`cpf` | 友だち追加 1 件あたりの最大入札価格を指定し、それを上限に入札 | 最大入札価格（CPF） |

- 公式の使い分け（フロー図）: 1 日の予算の中で最大化したい → 目標単価を決めたいなら「目標値あり」、決めないなら「目標値なし」。指定した入札価格を上限にしたい → 「個別友だち追加単価」 ✅〔公式の推奨〕（F64-02 のフロー図、F63-07）
- PDF の言い回し: 目標値あり＝「目標友だち追加単価内で友だち追加数を最大化したい場合」、目標値なし＝「目標予算内で友だち追加数を最大化したい場合」✅（F63-03 p13）

### 4-2. 値を置く場所 ✅〔仕様〕（F64-14、F64-02）
| 値 | キャンペーン | 広告グループ | API の決まり |
|---|---|---|---|
| tCPF（目標値あり） | 任意 | 任意（キャンペーンが `MAXIMIZE_GAINING_FRIENDS` のときだけ） | キャンペーンの SET で `targetCpf` を省くと**値が消える**。広告グループは `isRemoveTargetCpf` で消す |
| CPF（個別友だち追加単価） | **必須** | 任意（キャンペーンが `CPF` のときだけ） | 広告グループは `isRemoveCpf` で消す |

- 入札戦略はキャンペーンで決め、広告グループ独自の入札価格（目標値）も置ける、はディスプレイ共通 ✅（F64-02）
- **API で目標値ありのキャンペーンを SET するときは `targetCpf` を毎回入れ直す**。入れ忘れると目標値なしに変わる ✅〔仕様〕（F64-14 CampaignServiceMaximizeGainingFriendsBiddingScheme）
- tCPF・CPF の上限と下限の数字は ❓（ヘルプ・PDF・API の説明に記載なし。他の戦略の「1〜80,000 円」は検索のキーワード入札の値で、ここには当てはまらない）

### 4-3. 入札価格調整率 ✅〔仕様〕（F64-03）
- ディスプレイの入札価格調整は、広告グループのターゲティングごとに **引き上げ 1〜100%・引き下げ −1〜−90%**。掛け算で効く
- **キャンペーンの入札戦略が次のときは適用されない**: CV 数の最大化（あり／なし）、価値の最大化（あり／なし）、クリック数の最大化、動画再生数の最大化、拡張クリック単価、**友だち追加数の最大化（目標値あり／なし）**、ビューアブルインプレッション数の最大化（β）
- 一覧に個別友だち追加単価は無い → **個別友だち追加単価では調整率が効く**〔推測。上の一覧の裏返し。02 §7 と同じ読み方〕
- 配信除外にしたオーディエンスリスト・プレイスメント・コンテンツキーワードには調整率を付けられない ✅（友だち追加目的で自動で付く「友だち」リストの除外も同じ扱いと読める〔推測〕）

### 4-4. 学習 ✅〔仕様〕（F63-08、02 §4-2）
- 「学習中／学習停止／学習完了」が出るのは**最大化の 2 つ**。個別友だち追加単価には出ない
- 「学習中」が 7 日以上続いたら、配信されているか・ターゲティングを絞りすぎていないか・予算は適切かを見直す 〔公式の推奨〕
- 学習の引き金（新規作成・戦略の変更など）は 02 §4-2。友だち追加に固有の日数・件数の線は ❓

### 4-5. ポートフォリオ入札 ✅〔仕様〕（F64-04、F64-14）
- ディスプレイのポートフォリオで設定できる戦略に「**友だち追加数の最大化（目標値あり／なし）**」が入る（ヘルプ本文の一覧）。ヘルプの一覧の全体は クリック数の最大化・拡張クリック単価・動画再生数の最大化・コンバージョン数の最大化（目標値あり／なし）・コンバージョン価値の最大化（目標値あり／なし）・友だち追加数の最大化（目標値あり／なし）・ビューアブルインプレッション数の最大化で、個別友だち追加単価は入らない ✅
- API のポートフォリオの型（`BiddingStrategyServiceType`）は `MAXIMIZE_CONVERSIONS`・`MAXIMIZE_CONVERSION_VALUE`・`MAXIMIZE_CLICKS`・`MAXIMIZE_VIDEO_VIEWS`・`MAXIMIZE_VIEWABLE_IMPRESSIONS`・`MAXIMIZE_GAINING_FRIENDS`・`CPC`。**`CPF` は無い** → 個別友だち追加単価はポートフォリオにできない
- ポートフォリオを付けると、**広告グループの目標値・入札価格は無効になり、編集もできない**（個別に戻すと復活）
- ポートフォリオのキャンペーンでは、コピー・CSV での入札の変更・一覧での入札の変更ができない。自動運用ルールの「入札価格・目標値を変更する」は**失敗**になる
- 古い道具で触ると外れる: キャンペーンエディター 5.51.0 未満、スクリプト V202510 未満で入札を更新すると、ポートフォリオが外れて個別設定に上書きされる
- **A/B テストはポートフォリオと共有予算を考慮しないので、対象にするのは非推奨** ✅（F64-04、F64-07）

### 4-6. 最適化スコアと最適化提案 ✅〔仕様〕（F64-06）
- ディスプレイの最適化スコアの対象: CV 数の最大化（あり／なし）、クリック数の最大化、動画再生数の最大化、**友だち追加数の最大化（目標値なし）**、ビューアブルインプレッション数の最大化
- **友だち追加数の最大化（目標値あり）と個別友だち追加単価はスコアの対象外**（一覧に無い）
- スコアは日次更新、過去の表示は見られない、効果の向上を保証しない ✅
- 最適化提案の個々の項目が友だち追加目的に出るかは ❓（提案の一覧は 13 §4-7。友だち追加に限った記述は無い）

### 運用の判断への効き方
- **最初は「目標値なし」で単価の相場を見てから、目標値ありへ**、が筋だが公式の記述ではない〔推測〕。推奨入札も推奨件数も無いので、目標値は自分の実績（直近の友だち追加単価）から置く
- **面やデバイスで単価を変えたいなら、個別友だち追加単価にするか、広告グループを分ける**。最大化の 2 つでは調整率が黙って無視される（エラーは出ない）〔仕様＋推測〕
- **ポートフォリオは「複数の LINE 公式アカウント」ではなく「1 つの LINE 公式アカウントへの複数キャンペーン」を束ねる道具**（広告アカウントにつながる LINE 公式アカウントは 1 つ、63 §2-4）。地域別・面別にキャンペーンを分けた友だち追加をまとめて最適化したいときに使う〔推測〕
- 目標値ありに切り替えると最適化スコアが出なくなる。「スコアが消えた」を不具合と取り違えない〔仕様〕
- 自動運用ルールで tCPF を動かす運用は、ポートフォリオに入れると止まる（失敗）〔仕様〕

## 5. 予算

### 5-1. 1 日の予算と請求の上限（ディスプレイ共通。本体は 02 §8・16）✅〔仕様〕
| 項目 | 値 | 出典 |
|---|---|---|
| 1 日の予算 | キャンペーンに必須。個別予算は 100 円以上・1 円単位（動画再生課金は 1,000 円以上）、または共有予算 | 16（H000044451） |
| 1 日の請求対象 | 1 日の予算の 200% まで（その日に何度か変えたら最も高い額の 200%） | 02 §8-2（H000044428） |
| 1 か月の請求限度額 | 1 日の予算 × その月の掲載日数（配信オフ・審査否認の日も数える） | 02 §8-2（H000044428） |
| 予算の単位 | キャンペーンだけ。広告グループの予算は無い | 00 §0（S-03 p23） |
| 友だち追加に固有の予算の決まり | 記載なし | ❓ |

- 目標値なしは「キャンペーンで指定した 1 日の予算の範囲内で」最大化する戦略 ✅（F64-02）。**予算が入札の実質の上限になる**〔推測。目標値なしの説明から〕

### 5-2. 共有予算とポートフォリオ ✅〔仕様〕（F64-05、F64-04）
- キャンペーン間の共有予算: 1 日の予算をアカウント内の複数キャンペーンで共有し、余りを不足へ自動で回す。**配分は制御できない**（1 つのキャンペーンが多く使うことがある）。1 共有予算 1,000 キャンペーン
- **ポートフォリオ入札が付いたキャンペーンは、共有予算の作成画面では選べない**。ポートフォリオと共有予算を組むときは、ポートフォリオの作成・編集画面の「共有予算の利用」から ✅（F64-05 H000054414）
- 共有予算の編集画面からはキャンペーンを外せない（キャンペーンの編集画面で個別予算に戻す）。キャンペーンに付いた共有予算は削除できない ✅
- **ディスプレイで「目標値なし」の最大化を共有予算に入れられるか**: 02 §8-3 は検索と同じく入れられないと書くが、**ディスプレイの共有予算のヘルプ本文 2 本（H000054413・H000054414）には、入れられない戦略の記述が無い**。友だち追加数の最大化（目標値なし）× 共有予算の可否は ❓（§18 #2）
- 共有予算ごとの実績は「共有予算レポート」か共有予算の一覧で見る ✅（F64-05）

### 5-3. 自動運用ルールとの関係（13 §4-6 の要約）✅〔仕様〕
- ディスプレイの自動運用ルールで、キャンペーンの「1 日の予算を変更」「入札価格・目標値を変更」ができる。**共有予算のキャンペーンは予算の変更の対象外**、**ポートフォリオのキャンペーンは入札・目標値の変更が失敗**
- 友だち追加目的に限った制約の記述は無い ❓

### 運用の判断への効き方
- 友だち追加目的は「目標値なし＝予算が上限」。**友だちを急いで増やしたい月だけ予算を上げる**運用は効きやすいが、予算を上げた分だけ単価が上がりうる（相場は自分の実績で見る）〔推測〕
- 月の請求の上限は「日予算 × 掲載日数」で、検索の 30.4 と違う（02 §8-4）。友だち獲得のキャンペーンを期間限定（キャンペーン施策の 2 週間など）で出すなら、掲載期間を先に決めると月の上限も決まる〔仕様＋推測〕
- 共有予算で友だち追加とサイト誘導を同じ財布に入れると、片方が使い切る（配分は制御できない）。**目的の違うキャンペーンは共有予算を分ける**〔推測。F64-05 の注意から〕

- 「LINE 公式アカウントの友だち」リストが除外として自動で付き、外せない。そのほかのリストは任意（F64-01）

### 6-3. ターゲティングの範囲（要約。本体は 63 §3-5、23）
- 運用型で使えるターゲティングはすべて設定できる ✅（F63-03 p11）
- 友だち関連リスト（友だち・ブロック中）を配信対象に使うと審査がある（63 §5-3）。友だち追加目的では「友だち」リストは配信対象にできない ✅
- 2026-12-09 からのチャット誘導広告の資料では、使えるオーディエンスリストの種類と上限（オーディエンスリスト 30 件・共通オーディエンスリスト 50 件、OR）、100 件未満のリストは配信対象に使えない（除外は可）と書く ✅（F64-11 p16）。友だち追加目的の通常の広告も同じ上限と読める〔推測。23 §4 と同じ値〕

### 運用の判断への効き方
- **地域・年齢で絞りすぎると「学習中」が続く**（7 日の見直しの線、§4-4）。絞るのは配信先として本当に要らない層だけにし、残りは自動に任せる〔公式の推奨＋推測〕
- 「過去の検索キーワード」を最適化に使う、は LINE 広告には無かった Yahoo! 側の強み（61）。**Yahoo! 面に出したくない理由が無ければ、面を LINE に絞らない**方が学習の材料は多い〔推測〕。ただし面ごとの単価は違うので、配信先 URL レポートで確かめてから判断する（§8）

## 11. ブロックとの関係

### 11-1. 目的ごとに、ブロック中の人に出るか ✅〔仕様〕（F64-11 p12・p44・p45、F64-12）
| キャンペーン目的 | 未友だち | 友だち | ブロック中 | クリック後 |
|---|---|---|---|---|
| 友だち追加 | 出る | **出ない**（自動の除外） | **出る**（広告からブロック解除できる。解除でメッセージを送れるようになる） | 友だち追加（チャット誘導の広告なら追加後にトークへ） |
| チャット誘導（2026-12-09〜） | 出る | **出る** | **出ない**（ブロック中の人は配信対象から除外。BM から連携されたリストで自動で除外が付く） | 友だち状態にかかわらずトークへ |

- 63 §3-5 の「ブロック中の友だちは自動では除外されない」と一致する。**ブロック中の人に出ることは、チャット誘導の資料で明記された**（63 §15 の ❓「ブロック中の友だちに友だち追加広告が出るか」が解けた）

### 11-2. ブロックの率をどこで見るか
- 広告管理ツールにブロックの列は無い（レポート項目の一覧に無い）✅（F64-15）
- LINE 公式アカウントの分析の「追加経路」のブロック数は**期間中のブロック数**で、期間中に追加した人のブロックではない（63 §4-2）
- 「広告で来た友だちのブロック率」を公式の画面から正確に出す方法は ❓（63 §4）

### 11-3. ブロックを減らす公式の打ち手
- チャット誘導広告の資料は、効果として「顧客リードの獲得や、**LINE 公式アカウントのブロックユーザーの抑制**」を挙げ、使い道の 1 つに「**良質な友だちの獲得**」（商品・サービスへの理解を深め、友だちのメリットを伝えて、納得したうえで追加を促す）を挙げる。友だち追加目的で使う例は「友だち追加直後の利用促進」✅〔公式の推奨〕（F64-11 p6・p39）
- 友だち追加の前にプロフィールとあいさつメッセージを整える（63 §10 R9）
- 友だち追加目的でチャット誘導広告を使い、LINE 公式アカウントで「あいさつメッセージ」も設定していると、**あいさつメッセージとシナリオの両方が送られる** ✅（F64-11 p46）

### 運用の判断への効き方
- **ブロック中の人への再接触は友だち追加目的の仕事**（チャット誘導目的ではブロック中の人に出ない）〔仕様〕。休眠した友だちを戻したいなら、友だち追加目的で「ブロック中の友だち」リストに配信を寄せる設計がありうる（ただし配信対象に使うと審査、63 §5-3。課金の扱いが ❓ なので、小さく試して LINE 公式アカウント側の数と並べる）〔推測〕
- あいさつメッセージとシナリオが二重に届く。**チャット誘導の広告を友だち追加目的に入れるなら、あいさつメッセージを短くするか、シナリオと役割を分ける**〔推測。F64-11 p46 から〕
- ブロックが増えると LINE 公式アカウントの「届く友だち」が減り、追加の価値が下がる。追加メッセージは 1 通 3 円（月 20 万通まで、税別）なので、**送る相手が増えるほど費用も増える**（F64-21）〔仕様＋推測〕

- レポートの目的の値の一覧（v20）は「ブランド認知, 動画再生, サイト誘導, アプリ訴求, コンバージョン, 商品リスト訴求, 来店促進, PayPayギフト, 友だち追加, 未設定」。**チャット誘導はまだ無い**（v21 で増えるかは ❓）✅（F64-15）

## 15. 判断の型

### 15-1. 立ち上げの順番〔推測。§2〜§13 と 63 §11-1 から組んだ〕
1. 63 §11-1 の 1〜6（どの LINE 公式アカウントか、認証、BM、LINE 公式アカウント側の準備、計測、入口）を先に片づける
2. **LINE 公式アカウントの名称**が「アカウント名称の設定」に合っているか（正式名称を含む。変更は原則不可）（§9-2）
3. 面: Yahoo! JAPAN トップ・PC・各サービスに出してよいか。出さないならプレイスメントかデバイスで外す（§8）
4. 入札: 目標値なしで始めて、1〜2 週間の友だち追加単価を見てから目標値ありか個別友だち追加単価へ（§4）。面・デバイスで単価を変えたいなら個別友だち追加単価（§4-3）
5. 予算: 期間を決めて「日予算 × 掲載日数」で月の上限を出す（§5）。共有予算は目的ごとに分ける
6. 2026-12-09 以降: 追加の後に話す内容（シナリオ）を決められるなら、チャット誘導の広告を足し、計測タグを置く（§10・§12）
7. LINE 公式アカウントの通数と追加メッセージの費用（§11）

### 15-2. 友だち追加単価が悪いとき（63 §11-2 に入札・予算の確認を足したもの）〔推測〕
1. 接続の状態（警告マーク）・LINE 公式アカウントの審査状態（63 §5-5、§2-7）
2. 配信先 URL レポートで面の内訳（LINE・Yahoo! トップ・PC・各サービス）
3. 学習状況（7 日以上の学習中）と、直前に戦略・目標値を変えていないか
4. **入札価格調整率を当てにしていないか**（最大化の 2 つでは効かない、§4-3）
5. **API・自動運用ルール・古いキャンペーンエディターで目標値が消えていないか**（SET での `targetCpf` の省略、ポートフォリオの解除、§4-2・§4-5）
6. ターゲティングの絞りすぎ（友だちの除外は外せないので、既存の友だちが多いほど配信できる人は減る）
7. 素材（画像・タイトル・75 文字）と LINE 公式アカウントの名前・プロフィール画像
8. 入札（目標値・個別単価を上げる）。推奨入札は無いので、自分の実績を基準にする

### 15-3. 「友だち追加数が急に増えた／単価が急に下がった」とき〔推測〕
1. 面が増えていないか（2026-02 の Yahoo! トップ正式化、2026-06 の PC・各サービス）
2. ブロック中の人の「ブロック解除」が混ざっていないか（LINE 公式アカウントの「概要」と「追加経路」を並べる、§3-3）
3. LINE 公式アカウントの管理画面の友だち追加広告を止めた・始めた（同じ基盤、§13-3）
