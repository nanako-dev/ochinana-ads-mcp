## 0. 先に結論

1. **キャンペーン目的が「何を最大化するか」を決め、入札戦略がそれを上書きしうる**。「クリック数の最大化」は目的に関係なくクリックで最適化、コンバージョン・アプリ訴求・商品リスト訴求で「個別クリック単価」を選ぶと目的の最適化は効かない ✅〔仕様〕（H000044496）
2. **オークションランク＝入札価格 ×「広告の品質」**。品質は推定アクション率（目的の最適化ポイントで測る）で、過去のインプレッションとアクション、地域・デバイスの実績、広告文と面の関連、広告と閲覧者の関連が入る。これに**目的を最大化するアルゴリズムが原則として加わる**。ランクも品質も数値では見られない ✅〔仕様〕（H000044610）
3. **1 日の予算は配信アルゴリズムの入力**。予算の上限が近いと「目的を達成しそうな広告」を優先して出す。少なすぎても多すぎてもアルゴリズムが働かない、と公式。**個別予算は 100 円以上、動画再生課金のキャンペーンは 1,000 円以上** ✅〔仕様〕（H000044610、H000044451）
4. **目標値なしの最大化は「直近 7 日に 20 件」が境目**。20 件以下でも設定はできるが、最大化ではなく「一定のコンバージョン数に達するよう」配信し、20 件を超えると最大化に切り替わる（コンバージョン数・価値とも）✅〔仕様〕（H000044233、H000054705）
5. **目標値ありは「30 日 40 件」**。ただしコンバージョン数の最大化は「キャンペーン単位」、価値の最大化は「広告グループ単位」と書かれ、公式の中で言い方が違う △（H000044473、H000054705）
6. **入札に使う成果はキャンペーンの「最適化に使用するコンバージョン」で決まる**。対象は CV 数・価値の最大化（あり／なし）と**拡張クリック単価**。1 キャンペーンに 1 設定か 1 グループ。**アプリ訴求は必須**。ラベルの無い古いコンバージョン測定タグは選べない ✅〔仕様〕（H000044344、H000044451）
7. **フリークエンシーキャップはキャンペーンで設定し、効かせる単位（キャンペーン・広告グループ・広告）を選ぶ。数え方はビューアブルインプレッション。付けると計測できない面には出なくなる**。回数の上限は 2 本のヘルプが 1〜100、上限一覧の FAQ が 1〜99,999 で食い違う △ ✅（H000044438、H000044451、H000044203）
8. **動画の課金は 3 通り**: 動画再生課金（**10 秒以上の再生、10 秒未満の動画は完了で 1 回。入札は 1,000 再生あたり、同じセッションの 2 回目以降は無料、クリックでは課金されない**）、ビューアブルインプレッション課金、クリック課金（動画付きでも個別クリック単価ならクリックに課金）✅〔仕様〕（H000044496）
9. **インストリーム広告（TVer・ABEMA）は別物**: 目的「動画再生」で掲載タイプ「プライベートマーケットプレイス」。入札はビューアブルインプレッション単価・課金はビューアブルインプレッション課金で固定、ビューアブルは**再生開始で 1 回**。スマートターゲティング・プレイスメント・コンテンツキーワード・入札価格調整は使えない。広告管理ツールでだけ作れる ✅〔仕様〕（H000055939、H000044834）
10. **LINE 広告から無くなったもの**: LINE Tag と LINE Conversion API、「イベント単価の上限／目標」の 2 本立て、CV 目的でクリックを最適化する上限・目標型、手動 CPM、日本以外への配信、未成年を含む年齢、ネットワークの一括指定、地域の除外、BM で直接作ったカスタムオーディエンスの共有、フィードコンバート、61 秒以上の動画、画像（小）・アニメーション・動画（小）、長いタイトル、ラベル、説明文の絵文字、広告グループ予算・キャンペーン予算の上限と最適化 ✅〔仕様〕（S-03 p19〜26）

## 2. 仕組みの全体像

### 2-1. 運用型と予約型 ✅〔仕様〕（S-03 p22、S-47、H000055939）
| | 運用型 | 予約型 |
|---|---|---|
| 買い方 | 掲載機会ごとのオークション | 面・期間・回数・課金・ターゲティングをまとめた商品を買う |
| 使える人 | 誰でも（オンラインサインアップ・代理店） | **代理店経由のみ**（「一部のお客様」） |
| アカウント | 1 つの広告アカウントで両方を出せる（運用型／予約型の区分は統合で廃止） | 同左 |
| LINE の枠 | トークリスト・NEWS・ホーム・友だちタブ・ミニアプリなど（66 §2-3） | Talk Head View・NEWS TOP AD など（66 §2-3 (c)） |
| 運用型の中の「予約に近い」もの | **インストリーム広告**（掲載タイプ「プライベートマーケットプレイス」、Deal ID の商品を選ぶ）（§7-3） | — |

### 2-2. 配信が決まる流れ ✅〔仕様〕（H000044610）
1. ユーザーが面のあるサイト・アプリを訪れる
2. **ターゲティング**（属性・オーディエンス・プレイスメント・デバイスなど。23）と**広告タイプ**（面に合うもの。66 §2-2）で候補を選ぶ
3. 候補を**オークションランクの高い順**に掲載
   - 入札価格: キャンペーンか広告グループの入札価格。手動入札なら調整率を掛けた値（02 §7-2）。自動入札は戦略が調整
   - 広告の品質: **推定アクション率**（クリック等の見込み。目的の最適化ポイントで測る）。要素は過去のインプレッション、過去のアクション、状況に応じて地域ごと・デバイスごとの掲載実績、**広告のタイトル・説明文と面の関連**、**広告の内容と閲覧者の関連**
   - さらに「サイト誘導」「コンバージョン」などの**目的を最大化するアルゴリズムが原則として加わり**、最終的なランクが決まる
4. ランク・品質は掲載機会ごとに動く値で、**レポート・一覧では確認できない**。品質が低いと掲載されないことがある
- 提携先では SSP・ヘッダービディングの追加オークションがあり、負けると掲載・課金とも無し（66 §2-1、23 §2-1）

ヘルプの例（品質を仮に数値で表したもの）: 入札 50 円・品質 10 の広告は、入札 100 円・品質 4 の広告に勝つ。スマートフォン +50% の調整率は、スマートフォンの面でだけ効く ✅（H000044610）

### 2-3. 予算と配信の関係 ✅〔仕様〕（H000044610）
- 配信アルゴリズムは**予算の範囲内で目的の最大化を目指し**、日予算の上限が近づくと目的を達成する見込みが高い広告を優先して出す
- 一部の入札戦略では目的を最大化するアルゴリズムが適用されない（§4-2 の注意事項）
- **予算は少なすぎても多すぎても、アルゴリズムが適切に機能しない**。定期的に見直すよう公式は勧める 〔公式の推奨〕

### 運用の判断への効き方
- **品質の数値が見えない**ので、検索の品質インデックスのような「品質を直す点検」はできない。代わりに要素から逆算する: 面と広告文の関連（面ごとに素材を分ける）、閲覧者との関連（ターゲティングと訴求をそろえる）、過去のアクション（CTR の低い素材を外す）〔推測。要素は H000044610〕
- 「予算を増やせば成果も比例する」とは言えない。予算は配信の優先順位を変える入力でもある（上限が近いと効率の良い配信に寄る）。増額は段階的に、評価は 02 §4 の学習の見方で〔推測〕

## 3. 目的とキャンペーンの種類

### 3-1. 目的の一覧（何を最大化するか）✅〔仕様〕（H000044496）
目的ごとの入札戦略・課金・広告タイプの全表は `23` §3-1。ここでは最適化ポイントと、23 に無い点だけ書く。

| 目的 | 最適化ポイント | 23 に無い点 |
|---|---|---|
| サイト誘導 | 広告クリック数 | CPC 系 3 戦略だけ。CV 系は選べない |
| 動画再生 | 動画の再生数 | **戦略が 3 つ**: 動画再生数の最大化（動画再生課金かビューアブル課金 β）、動画再生単価（動画再生課金）、ビューアブルインプレッション単価（**インストリーム広告だけ**） |
| アプリ訴求 | サブタイプ「インストール」= インストール数、「標準」= アプリ内イベント数 | **インストールは CV 最大化（あり／なし）だけ**。標準はそれに加え CPC 系 3 戦略。バナー動画は 16:9 のみ。**最適化に使用する CV の設定が必須**（H000044451） |
| コンバージョン | コンバージョン数 | CV・価値の最大化（あり／なし）と CPC 系 3 戦略 |
| 友だち追加 | LINE 公式アカウントの友だち追加数 | 一部のお客様のみ。**友だち追加 1 件を 1 クリックとみなすクリック課金**。トラッキング URL とカスタムパラメータは設定できない（H000044451） |
| 商品リスト訴求 | コンバージョン数（動的ディスプレイの商品リスト必須）。「広告クリエイティブと配信」を最適化 | CV・価値の最大化と CPC 系 3 戦略 |
| ブランド認知 | ビューアブルインプレッション数 | ビューアブルインプレッション単価・数の最大化（2025-07 正式）だけ |
| 来店促進 | 実店舗への来店 | CV 最大化（あり／なし）と CPC 系 3 戦略。来店計測（ヤフー方式・ソフトバンク方式）の設定が別に要る（H000044451） |
| チャット誘導（2026-12-09 予定） | LINE 公式アカウントのトークへの誘導 | 61 §2、S-40。中身は提供後に取り直す |

- **使える目的はアカウントによって違う** ✅（H000044496、H000044451）
- **「動画再生」以外の目的でも広告に動画を設定できる**。公式の例: CV を増やしたいなら目的「コンバージョン」で広告タイプ「レスポンシブ（動画）」「バナー（動画）」 〔公式の推奨〕（H000044496）

### 3-2. キャンペーン作成で決めること ✅〔仕様〕（H000044451）
| 項目 | 中身 |
|---|---|
| キャンペーン名 | 256 文字以内 |
| 配信設定 | オン／オフ |
| 掲載期間 | 開始は当日 0:00 が初期値、分単位、過去不可。終了は「指定しない」か「指定する」（初期値 1 か月後の 23:59）。**終了時刻を指定すると、終了日に日予算を使い切らないことがある** |
| 1 日の予算 | 個別予算 **100 円以上 1 円単位、動画再生課金は 1,000 円以上**、または共有予算 |
| 入札戦略と課金方式 | キャンペーン個別か、ポートフォリオ（02 §9-2）。**作成画面で共有予算とポートフォリオは同時に選べない**（ポートフォリオ側で「共有予算の利用」を設定して日予算欄で選ぶ） |
| 最適化に使用するコンバージョン | アカウント単位か、キャンペーン単位（§8）。アプリ訴求は必須 |
| 詳細設定 | フリークエンシーキャップ（§6）、URL オプション（トラッキング URL・カスタムパラメータ。友だち追加以外） |
- 作成時に入稿内容をもとにした**シミュレーション機能**を使える ✅（H000044451。中身は未読 ❓）

### 運用の判断への効き方
- 目的「コンバージョン」で作っても、戦略がクリック数の最大化や個別クリック単価なら CV で最適化されない（02 §2-3）。**点検表は「目的 × 戦略 × 課金」の 3 つ組で持つ**〔推測〕
- アプリ訴求の「インストール」は CV 最大化しか選べないので、**計測（広告効果測定ツールの連携）が先**。計測が無いと始められない（H000044496、06）〔推測を含む〕
