## 0. 先に結論（この章で一番効く 10 点）

1. **「Meta Advantage+」は製品スイートの名前で、中は 2 段**。①エンドツーエンド（売上・アプリ・リードのキャンペーン全体に AI を当てる「Advantage+ キャンペーン」）②シングルステップ（オーディエンス・配置・予算・クリエイティブ・カタログ・リンク先の個々の自動化）✅（ヘルプ 2486309305148646）
2. **Advantage+ キャンペーンは「種類」ではなく「状態」**。売上・アプリ・リードで、予算（キャンペーン予算）・オーディエンス（提案を使う）・配置（除外しない）の 3 つがそろうと Advantage+。管理画面は欄ごとに［Advantage+ オン／オフ］を出す ✅（S-02、ヘルプ 906206294602874）
3. **旧 ASC・AAC（独立した種類）は 2025〜2026 年に廃止**: v24.0（2025-10-08）で作成・更新不可 → v25.0（2026-02-18）、2026-05-19 に全 API バージョン → v26.0（2026-07-29）で未移行のものは編集不可、既存顧客の予算上限を使うものは停止 ✅（S-02・S-06・S-07）
4. **Advantage+ カタログ広告は管理画面で「商品メディアを表示する広告」に改称**され、売上キャンペーンではカタログはキャンペーン単位で 1 つ・商品データは既定でオン・切り替えは消えた ✅（ヘルプ 397103717129942・2441336696279825。日付は ❓）
5. **Advantage+ クリエイティブは 30 のエンハンスの束で、うち「AI」印（生成 AI を使う、または使うオプションがある）が 16**。一部は既定でオン、いつでもオフにできる。キャンペーンの核のメッセージは保ちつつ、入れたメディアと文が調整されることがある ✅（ヘルプ 297506218282224）
6. **アカウント単位の「新しいクリエイティブ機能のテスト」にオプトインしていると、広告ごとに選ばなくてもエンハンスが適用されることがある** ✅（ヘルプ 2084198785720343）。入稿の点検は広告単位だけでは足りない
7. **生成 AI の文は「メインテキストと見出しを各最大 5 つ」**。ペルソナ別のバリエーションは**入力が英語・ポルトガル語・スペイン語のときだけ** ✕（日本語は対象に書かれていない）。生成にはメインテキストに 5 語以上が要る ✅（ヘルプ 497610041230617）
8. **画像生成（画像のバリエーション）は Advantage+ アプリ・セールス・カタログのキャンペーンでは今は使えない** ✅（ヘルプ 1684513971952814）。売上で Advantage+ オンのキャンペーンでは、画像生成は選べない前提で素材を用意する
9. **規制業種（金融サービス・製薬・健康）、住宅・雇用・金融（HEC）、社会問題・選挙・政治（SIEP）、「特定の国」では一部の AI 機能がすぐには使えない**、と Meta は全ての生成 AI のページに書く ✅。日本が「特定の国」に入るかは ❓
10. **最適化スコア（0〜100）は推奨の適用度で、成績ではない**。キャンペーン作成中の「キャンペーンスコア」は別物でアカウントのスコアに影響しない。自動ルールは 1 アカウント 250 個、トリガー型は API だけ ✅（ヘルプ 804913634782260・3864826443789572・222640851458826、開発者文書 Ad Rules）

## 2. 地図の軸: Meta の自動化は何を受け持つか

Meta のヘルプ「Meta Advantage+ の機能」（2486309305148646、本文）の分け方に、入札・生成・推奨・ルールを足して並べる。

| 層 | 自動化の対象 | 部品（今の名前） | 機械が決めること（要約） |
|---|---|---|---|
| エンドツーエンド | キャンペーン全体 | Advantage+ セールス／アプリ／リード獲得キャンペーン | 予算配分・オーディエンス・配置を同時に |
| シングルステップ: オーディエンス | 誰に出すか | Advantage+ オーディエンス、Advantage+ カスタムオーディエンス、Advantage+ 類似オーディエンス、Advantage+ 詳細ターゲット設定（それぞれ「〜を提案として利用」） | 指定した条件の外まで配信を広げるか |
| シングルステップ: 配置 | どこに出すか | Advantage+ 配置（Advantage+ オンの配置） | 面ごとの配信 |
| シングルステップ: 予算 | 広告セットへの配分 | Advantage+ キャンペーン予算（キャンペーン予算、Advantage+ がオンの予算） | 広告セット間の予算の配分 |
| シングルステップ: クリエイティブ | 素材の選び方・加工・生成 | Advantage+ クリエイティブ（30 のエンハンス）、フレキシブル広告フォーマット、形式の自動化 | どの素材・形式を、どう加工して、誰に |
| シングルステップ: カタログ | どの商品を見せるか | 商品メディアを表示する広告（旧 Advantage+ カタログ広告） | 人ごとの商品の選び方 |
| シングルステップ: リンク先 | どこへ送るか | Advantage+ リンク先、ウェブサイトのリンク先の最適化 | 行き先のページ（ウェブとアプリ） |
| 入札 | オークションごとの入札 | 入札戦略（最大数量・バリュー最大化・結果の単価目標・ROAS 目標・入札価格上限）、バリュールール | 入札額（`02`） |
| 生成 AI | 素材そのものを作る | テキスト生成・画像生成・背景生成・画像拡張・アニメーション・動画の拡張・翻訳・音楽・ステッカー など | 新しい文・画像・動画 |
| 推奨 | 設定の提案 | 最適化スコア・推奨事項・キャンペーンスコア | 何を勧めるか（適用は人） |
| ルール | 条件で動く操作 | 自動ルール（テンプレートを含む） | 人が決めた条件で止める・上げる・知らせる・結合する |

## 4. エンドツーエンド: Advantage+ キャンペーン（売上・アプリ・リード）

### 4-1. 何か ✅〔仕様〕

- 「キャンペーン全体に AI を適用してキャンペーンの目標を達成する、最も効率的な方法」。売上・アプリの宣伝・リードの目的で使える（ヘルプ 2486309305148646）
- 売上・アプリの宣伝・リードを選ぶと Advantage+ の設定が表示される。社会問題・選挙・政治と医薬品のキャンペーンでは一部の機能が使えない場合がある（ヘルプ 1292656978738967）
- **手動キャンペーンの機能はすべて引き続き使える**。［Advantage+ オフ］が出ても、できるだけ幅広い設定や他の Advantage+ 機能で効果を高められる、とヘルプは書く ✅（同）

### 4-2. オンとオフの条件（欄ごと）✅〔仕様〕（ヘルプ 906206294602874、本文。94 第 2 段で読めなかった折りたたみの中身）

| 欄 | ［Advantage+ オン］ | ［Advantage+ オフ］ |
|---|---|---|
| 予算 | キャンペーン予算を予算戦略に（広告セットが 1 つでも複数でも）。任意の上限予算を置いてもオン | 広告セットが複数で、キャンペーン予算を使わない |
| オーディエンス | 利用可能な状況で、選んだオーディエンス設定の提案を使う | 通常、［広告のリーチをさらに限定］（または［オーディエンスをさらに制限する］→［限定されたオーディエンスにリーチする］）を選んだとき、［提案として使用する］のチェックを外したとき。**最低年齢を 25 歳まで上げる・カスタムオーディエンスを除外するのはオフにならない** |
| 配置 | Advantage+ 配置を使う | 広告セットで配置を除外したか、［モバイル］か［デスクトップ］をオフにした |

- ほとんどのキャンペーンは推奨設定（Advantage+ キャンペーン設定）で作成が始まる。一部のオプションではキャンペーンスコアが 100 と表示され［Advantage+ オン］になっている場合がある ✅

## 12. 最適化スコア・キャンペーンスコア・推奨

### 12-1. 最適化スコア ✅〔仕様〕（ヘルプ 804913634782260、本文。開発者文書 Performance Recommendations）

| 項目 | 内容 |
|---|---|
| 何を測るか | キャンペーン・広告セット・広告がどれだけ最適化されているかを **0〜100 ポイント**で。推奨の適用数に基づく |
| 推奨の中身 | テストで成果の向上が実証済みのベストプラクティス＋エラーと警告（フォーマットの誤り・未入力・ポリシー違反など） |
| ポイントの重さ | 推奨ごとに違い、推定価値が高いほど大きい。ビジネスの種類・目的・特性・予算配分・テストでの向上で変わる |
| 例 | スコア 60、断片化の解消で +35、Advantage+ 配置で +5（両方で 100 になりうる） |
| 却下 | スコアは変わらず、［アカウント概要］の［却下済み］へ。却下はそのキャンペーンにだけ効き、他のキャンペーンでは同じ推奨が出ることがある。だから事業上の制約で適用できない推奨があると、スコアは常に 100 未満 |
| 更新 | ほぼリアルタイム。ただしエラーが複数あると全部解決するまでポイントは付かない。新しいキャンペーンの機会の推奨（最適なプリセットで作るなど）を適用すると加点され、キャンペーンがアクティブになると推奨は消える |
| 示さないこと | **実際・将来の成果を反映しない**。適用で成果が上がる保証は無い。**スコアが低いことを理由にキャンペーンをオフにしない**。成果はビジネスゴールで判断 |

### 12-2. キャンペーンスコア ✅〔仕様〕（ヘルプ 3864826443789572、本文）

- 公開前に、そのキャンペーンがどれだけ最適化されているかを **0〜100 で予測**したもの。作成時に適用した推奨の数に基づく

- 今後の成果を反映しない。開発中

### 12-4. 運用の判断への効き方

- **推奨は「材料」で「命令」ではない**: Meta の推奨は Meta の配信システムが学ぶ材料を増やす方向（予算・広さ・素材）に寄る〔推測〕（`28§0-2` の芯と同じ）。計測とエラーの推奨は先に、予算の増額は事業の上限で、表現を変える推奨は表現の管理で判断
- **スコアを KPI にしない**（ヘルプが明記 ✅）。報告でスコアを書くなら「推奨の適用度で、成果ではない」と添える
- **却下は「キャンペーンごと」**: 同じ推奨が別のキャンペーンでまた出る ✅。却下の理由を変更の記録に残しておく〔推測〕

### 13-2. API の自動ルール（Ad Rules Engine）✅〔仕様〕（開発者文書 Ad Rules Engine・Trigger Based Rules・Schedule Based Rules・Execution Spec・Rebalance Budget）

| 項目 | 内容 |

### 13-3. 運用の判断への効き方

- **自動ルールは「止血」と「通知」に使い、「最適化」に使わない**〔推測〕: Meta の配信システムは週平均で動き（`02§3`）、日次・毎時のルールで予算や入札を動かすと情報収集期間を何度もやり直させうる。予算・入札を動かすルールには `action_frequency` を 1 週間（10080 分）以上、`execution_count_limit` を小さく置く（API の場合）〔推測〕
- **自動結合のテンプレートは［お知らせのみ送信］から**（`04§4-3`）
- **予算の上限の事故を防ぐ通知**: 「通算予算を一定の割合消化したらお知らせ」（ヘルプ目次にある手順）を使う。日予算の上振れ（1 日 175%）は仕様で、ルールで止めるべき異常ではない（`02§5-3`）
- 引き継ぎ: ルールはアカウント単位で他人の広告にも効く ✅。最初に一覧を見て、誰のどのルールが何に効いているかを表にする（`28§2-1`）〔推測〕

## 16. 判断の型: どの自動化をどこまで使うか

### 16-1. 4 つに仕分ける〔推測〕（仕様 ✅ を当てはめた書き手の型）

| 仕分け | 該当 | 扱い |
|---|---|---|
| A. 手放してよい（守る線をアカウント制御に置けば失うものが少ない） | Advantage+ 配置、Advantage+ キャンペーン予算（広告セットを一様に重視するとき）、Advantage+ オーディエンス（新規の獲得） | 使う。守る線はアカウント制御・制御（地域・最低年齢・除外） |
| B. 条件つき | 商品データ・商品メディア（カタログの質しだい）、ウェブサイトのリンク先の最適化（LP の検証がなければ）、テキストの改善・CTA エンハンス（表現の規制がなければ）、予算共有 | 前提を確かめてから |
| C. 点検してから | 画像・動画のタッチアップ、拡張、背景生成、アニメーション、音楽、関連の高いコメント、商品のショーケース、商品セットの拡張 | プレビューで 1 本ずつ。規制業種は原則オフ |
| D. 自分で持つ | 目的・コンバージョンの場所・パフォーマンス目標、計測、素材とカタログの中身、守る線、自動ルールの条件、推奨の採否 | 機械に渡せない（渡す仕組みが無い） |

### 16-2. 「この表示・推奨が出たら」

| 表示・推奨 | 確かめる | する／しない |
|---|---|---|
| 欄に［Advantage+ オフ］ | 絞った理由（`04§9-2`） | 理由が法令・配送ならアカウント制御へ移してオンに戻す。件数・配分の理由ならそのまま |
| 推奨: エンハンスのオン（`AUTOFLOW_OPT_IN`・`APLUSC_*`） | 表現の規制、ブランドの線 | プレビューで確かめてから。規制業種は却下（却下してもスコアは変わらない） |
| 推奨: `GEN_AI_MVP`（AI 生成のバリエーション） | 生成物の正確さ | 1 本ずつ見る。Meta は正確さを保証しない |
| 推奨: `BUDGET_LIMITED`・`SCALE_GOOD_CAMPAIGN` | 3 週間安定しているか、限界の単価 | 事業の上限で（`02§3-3`） |
| 推奨: 計測（ピクセル・CAPI・CRM） | 今の計測の穴 | 先に対応（運用の型の順序） |
| アカウントの［新しいクリエイティブ機能をテスト］がオン | 誰がいつオンにしたか | 表現の管理が要る商材ならオフ。オンのままなら入稿の点検に「テストのエンハンス」を足す |
| 生成物の［AI 情報］ラベル | どの機能で付いたか | 付けたくないなら生成系をオフ |

## 17. 少額・少量のアカウントでの注意〔推測〕

| 状況 | 自動化の扱い |
|---|---|
| 週 50 件に届かない | Advantage+ の 3 つは使う（絞るほど件数が遠のく＝`36§4-4`）。広告セット 1 つ、キャンペーン予算 |
| 素材が少ない | 比率合わせ（`adapt_to_placement`、既定オン）と拡張で配置を埋める価値はある。ただしプレビューは必ず |
| 生成 AI を試す | テキスト生成（日本語でも使える）から。画像生成は売上の Advantage+ オンでは使えない |
| 自動ルール | 通知だけ。停止・予算変更・結合の自動実行は、件数が少なく判定がぶれるので使わない |
| 推奨 | 計測とエラーだけ先に。予算増額・形式の推奨は件数が増えてから |
