## 0. 先に結論（この章で一番効く 10 点）

1. **ブランドコンテンツ**は対価（金銭・無料ギフト・商品の無償提供を含む）を受けてビジネスパートナーを取り上げた**オーガニックの投稿**で、投稿の上に［タイアップ投稿］ラベルが付く。**パートナーシップ広告**（旧 ブランドコンテンツ広告）は広告で、ヘッダーにパートナーと広告主のどちらか一方か両方の名義が出る。**別のもので、許可も別** ✅〔仕様〕（H:788160621327601、H:546615926108316）
2. パートナーシップ広告は**両方のアカウントのシグナルを使ってランキングと成績を上げる**、と Meta は書く。ヘッダーにどちらの名義が出てもランキングには両方を使う ✅〔仕様〕（H:342728904797642、H:1732548120741800、D:Ads Creation）
3. 許可は 2 種。**コンテンツレベル**（個々の投稿・ストーリーズ・リール。［ブランドパートナーによる宣伝を許可］か**パートナーシップ広告コード**）と**アカウントレベル**（継続的な提携向け。既存の投稿なしでクリエイターの名義から広告を作れる、クリエイターのカスタムオーディエンスを含める・除外できる）。**同じビジネスが両方のアカウントを持ち、従業員が両方に広告の権限を持つなら許可は要らない** ✅〔仕様〕（H:711659943695726）
4. **広告コードがあれば、ブランドコンテンツでなくても・広告主がタグ付けされていなくても**、その投稿を広告にできる。**コードは一度に 2 社まで**。コードのスイッチを切っても**配信中の広告は続く**（新しい広告が作れなくなるだけ）✅〔仕様〕（H:1176637123293001、IG:797201308253238）
5. **Instagram の投稿はアーカイブしても広告にできるが、アーカイブ済みの Facebook の投稿は広告にできない**。広告として使われている間、クリエイターは投稿を**編集できず**、**削除すると広告が止まる** ✅〔仕様〕（IG:797201308253238、IG:1022082264667994）
6. 新しく作ったブランドコンテンツでは、［ブランドパートナーによる宣伝を許可］が**最後に投稿されてから 28 日間は自動でオン** ✅〔仕様〕（IG:1022082264667994）
7. 使える目的とコンバージョンの場所は表で決まる。**通話はどの目的でも不可**。リードでは**ウェブサイト・インスタントフォーム・アプリだけ**（Messenger・Instagram・インスタントフォームと Messenger は不可）✅〔仕様〕（H:1173889323625775）
8. 配置は Instagram（フィード・ウェブフィード・発見・ストーリーズ・リール）、Facebook（フィード・ストーリーズ・リール・Marketplace）、**WhatsApp ステータス（2026-09 から）**。**Threads はオーガニックのラベルだけで、パートナーシップ広告は不可**。**ダイナミック名義と単一名義は Facebook のリールとフィードだけ**、Marketplace・Facebook ストーリーズ・WhatsApp ステータスは常に両方の名義 ✅〔仕様〕（H:1173889323625775、H:906775900606811、H:546615926108316）
9. 計測: 広告主は広告マネージャで広告の成績を見る（クリエイターだけに見える追加の情報は見えない）。**クリエイター別の内訳 `pa_creator_ig_handle` は 2026-09-24 以降のデータで、出せるのはインプレッション・リーチ・リンクのクリック・動画の再生率だけ**（費用・コンバージョンは出ない、他の内訳と組めない）✅〔仕様〕（H:6687851991333112、D:Insights Breakdowns）
10. **クリエイターへの支払いは Meta の外**。Meta はアプリでの支払いを扱わない。ブランドコンテンツポリシーで制限された商品は、オーディエンスの制限や書面の認証が要る（中身は 31§4-3）✅〔仕様〕（H:788160621327601）

## 2. ブランドコンテンツとパートナーシップ広告の違い

### 2-1. 3 つの言葉 ✅〔仕様〕（H:788160621327601、H:342728904797642、H:546615926108316）

| | ブランドコンテンツ | パートナーシップ広告 | 通常の広告（BAU） |
|---|---|---|---|
| 何か | オーガニックの投稿の 1 種。クリエイターがブランドやビジネスパートナーから報酬（商品・サービスの無償提供を含む）を受け取るもの | 広告主がパートナーのクリエイター・ブランド・その他のビジネスと連携して出す広告 | 広告主の名義だけの広告 |
| ラベル | 投稿の上に［タイアップ投稿］ | ［広告］（ヘッダーにパートナーと広告主のどちらか一方か両方） | ［広告］ |
| 誰が出すか | クリエイター・パブリッシャー（Threads・Facebook・Instagram） | 広告主（広告マネージャ） | 広告主 |
| 費用 | Meta に広告料金を払わない | Meta に広告料金 | Meta に広告料金 |
| 許可 | ブランドコンテンツのタグ付けの許可 | パートナーシップ広告のアクセス許可（§3）。**タイアップ投稿ラベルでタグ付けすることの許可とは別に付与する** | 不要 |

- 「ブランドコンテンツ広告はパートナーシップ広告に改称されました」と各ページの冒頭にある ✅
- 広告なしのサブスクリプションの利用者には広告は出ないが、ブランドコンテンツ（オーガニック）は出る ✅（H:788160621327601）
- **アフィリエイトリンクを含むコンテンツには［タイアップ投稿］ラベルが要るが、ビジネスパートナーのタグ付けは要らない** ✅（H:788160621327601。31§4-1 と同じ）
- 適切な最低年齢が設定されていないブランドコンテンツはポリシー違反で削除される ✅（H:788160621327601）

### 2-2. 広告主にとっての中身 ✅〔仕様〕（H:342728904797642）

| Meta が挙げるメリット | 中身 |
|---|---|
| 成績 | 信頼性と訴求力の高いコンテンツで広告の成績を上げられる。両方のアカウントのシグナルでランキングと成績が向上 |
| 届く相手 | 自社とクリエイターのアカウント・ページから配信して新しいオーディエンスに |
| おすすめの投稿 | 広告マネージャで、**過去 60 日以内に投稿された承認済みブランドコンテンツのうち掲載制限の無いもの**を、新規か既存のキャンペーンに追加できる |
| トレンド | クリエイターマーケットのトレンドのリアルタイムインサイト（**米国の Instagram のトレンドデータ**） |
| クリエイター側 | 新しいオーディエンス、収益の手段（動画やテキストだけの推薦を作る）、分野での信頼性 |

△ 31§4-1 と 31§5 の表は「広告マネージャで、過去 60 日以内の承認済みブランドコンテンツを使える」と書く（出典は IG:292748974937716）。今日読んだ H:342728904797642 では、60 日は**広告マネージャの「おすすめの投稿」の対象**の条件で、アカウントレベルの許可やコードでは**それより古い投稿・アーカイブ済みの Instagram の投稿も広告にできる**（§3）。「60 日を過ぎた投稿は使えない」とは読まない〔推測〕

**運用の判断への効き方**
- クリエイターとの契約では「ブランドコンテンツ（オーガニック）の投稿」と「その投稿を広告に回す権利（パートナーシップ広告）」を**別の項目**として書く。Meta の上でも許可が別だから〔推測〕
- 「60 日以内」はおすすめの一覧の条件。古い投稿を回したいなら、コードかアカウントレベルの許可をもらう〔推測〕

## 3. アクセス許可とパートナーシップ広告コード

### 3-1. 2 種類の許可 ✅〔仕様〕（H:711659943695726、H:1176637123293001、H:526786565561304）

| | コンテンツレベル | アカウントレベル |
|---|---|---|
| 向き | 特定の投稿の宣伝。短期・単発のプロモーション | 継続的なパートナーシップ |
| 付与のしかた | クリエイターが投稿ごとに［ブランドパートナーによる宣伝を許可］をオン、または**パートナーシップ広告コード**を渡す | 広告主がリクエストを送り、パートナーがパートナーシップ広告ハブ・Instagram アプリ・Facebook アプリで承認。Instagram と Facebook がリンクされていれば両方に通知が届き、承認で**両方のアカウント**の許可になる |
| 広告主ができること | (1)［宣伝を許可］がオンで、タイアップ投稿ラベルで自社がタグ付けされた既存のコンテンツから広告やマーケティングメッセージを作る。(2) **コードがあれば、ブランドコンテンツかどうか・タグ付けの有無に関係なく**、Instagram 投稿・Facebook 投稿・ストーリーズ・リールから広告を作る。(3) 元の投稿を残したまま広告用に編集。(4) 広告と元の投稿のコメントを非表示に。(5) パートナーシップコンテンツのインサイトをすべて見る | (1) **既存のコンテンツなしで**パートナーの名義から広告・他の広告タイプ・マーケティングメッセージを作る。(2) 自社がタグ付けされたパートナーの既存のコンテンツ（**アーカイブ済みを含む**）から広告を作る。(3) **パートナーのカスタムオーディエンスを含める・除外する**。(4) コメントを非表示に |
| タグ付けの条件 | タイアップ投稿ラベル（コードなしの場合） | **Instagram: タイアップ投稿ラベル・@メンション・人物タグ・商品タグ・コラボのどれか。Facebook: タイアップ投稿ラベルだけ** |
| クリエイターができること | 宣伝を許可する投稿を選ぶ。広告主が非表示にしたコメントを見る。自分でコメントを非表示・削除 | ブランドコンテンツを作るときに広告主をタイアップ投稿ラベルでタグ付け。投稿ごとの承認の手間を減らす。コメントの扱いは同左 |
| 取り消し | クリエイターやパートナーはいつでも無効にできる | 同左 |

- **同じビジネスが 2 つの Instagram か Facebook のアカウントを持ち、両方に広告の権限を持つ従業員**は、パートナーシップ広告の許可なしで出せる ✅（H:711659943695726、D:Ads Creation）
- **広告会社を通す広告主は、広告会社に Instagram アカウント・Facebook ページ・広告アカウントへのアクセス許可を付ける** ✅（H:546615926108316）
- 許可が無いまま公開すると、広告は**配信保留**になり、クリエイターに許可のリクエストが届く。承認されると配信される ✅（D:Ads Creation）
- Facebook ページを持たない広告主でないパートナーとのパートナーシップ広告は、Facebook 上ではそのパートナーの Instagram の名前・プロフィール写真などで出る ✅（H:1176637123293001、IG:797201308253238）
- △ 名前の揺れ: ヘルプの題名は「パートナーシップ広告ハブ」、同じページの本文は「Creator Marketing Hub（クリエイターマーケティングハブ）」、開発者文書は「Partnership Ads Hub」。同じものを指すと読む〔推測〕

### 3-2. パートナーシップ広告コード ✅〔仕様〕（IG:797201308253238、H:1176637123293001）

| 項目 | 中身 |
|---|---|
| 誰が作るか | クリエイター（Instagram のプロアカウントか、Facebook のページかプロフェッショナルモードのプロフィール） |
| 作れる時点 | Instagram: 作成時（［パートナーシップのラベルと広告］→［パートナーシップ広告コードを取得］）と公開後。Facebook: 公開後（［オプション］→［パートナーシップ広告コードをシェア］） |
| 渡し方 | コピーするか、ダイレクトメッセージで送る。**新しいコードはいつでも取得できる** |
| 使える社数 | **一度に 2 社（2 パートナー）まで** |
| 止め方 | スイッチを切ると、コードを使った**新しい広告の作成**が止まる。**配信中の広告は続く** |
| アーカイブ | Instagram ではアーカイブしてもコードでアクセスできる（［宣伝を許可］が有効な限り）。非表示のコラボ投稿も宣伝できる。**アーカイブ済みの Facebook のコンテンツは広告にできない** |

| コードの有効期限 | 記載なし ❓ |

| 既存のコンテンツなしの広告 | クリエイターのプロフィールやページに出ない |

| EU・EEA・スイス | 広告なしのサブスクリプションか低パーソナライズ広告のアカウントでは、広告と広告による収益化の機能が制限される |

| 投稿レベル（宣伝の許可） | `/{ig-media-id}/branded_content_partner_promote` | `instagram_branded_content_creator` |
| 作成 | 広告の作成 API（既存のメディア ID か広告コード） | `ads_management`・`business_management`・`instagram_basic`・`instagram_branded_content_ads_brand`・`pages_read_engagement`・`pages_show_list`・`create_ads`。ページに `ADVERTISE` の役割のページのトークン |
| 探す | `GET /{business-id}/partnership-ads-advertisable-content`（旧 `/{fb-page-id}/advertisable-posts`・`/{ig-user-id}/branded_content_advertisable_medias` の後継） | `facebook_branded_content_ads_brand` か `instagram_branded_content_ads_brand`（後者は `instagram_basic` も、無いと 403）。直接の検索（ID・URL・広告コード）は **50 件まで**、ページの大きさは **1〜50（既定 25）**、前に戻る cursor は無い |
| リスト | `/{business-id}/partnership-ads-hub-lists` | 1 リスト **50 件まで**、1 回の追加・削除は 50 件まで。超えると 409 |
| ブランドコンテンツの投稿（Facebook） | `/{page-id}/feed` などに `sponsor_id` | 認証済みのページかプロフィール。`direct_share_status=1` でブランドの直接の宣伝を許可。コメントは `is_hidden` で非表示（ページの投稿だけ） |

- 探す API の `content_types`: `BRANDED_CONTENT`（タイアップ投稿ラベル）・`PRODUCT`（商品タグ）・`AFFILIATE`・`COLLAB_POST`・`TAGGED`（タグか @メンションした UGC）・`REPOSTED`。`ad_eligibilities` は `AD_READY`・`INELIGIBLE`・`NEEDS_ATTENTION`・`EXCLUDED`。`is_recommended` は Meta の推薦モデルが勧めるもの ✅
- 開発者文書のブランドコンテンツの節は、ブランド ID の付いた投稿の内容の変更はウェブ・モバイルでは対応せず、API で `sponsor_id` を変えると書く ✅（D:Branded Content）

**運用の判断への効き方**
- この章の範囲では API の鍵を作らない（共通の指示）。API の地図は「何が自動化できるか」の判断用〔推測〕
- `TAGGED`（タグや @メンションの UGC）も一覧に出るが、**広告にするには許可が要る**（アカウントレベルなら Instagram の @メンション・人物タグで足りる。§3-1）〔仕様の読み〕

## 8. ポリシーと法令の地図（中身は他の章）

| 論点 | どこを読むか | この章で確かめた接点 |
|---|---|---|
| ブランドコンテンツの定義・タグ付けの義務・アフィリエイトのラベル | 31§4-1 | 対価には商品・サービスの無償提供を含む。何らかの価値交換があればタグ付けが義務（H:788160621327601） |
| 宣伝できない・制限付き・書面の認証が要る商品、形式の制限（プリロール・タイトルカードなど） | 31§4-3 | 制限された商品はオーディエンスの制限や書面の認証が要る（H:788160621327601） |
| 審査で落ちる（タグ付けなし） | 34 の M48 | ブランドコンテンツを宣伝する広告はブランドコンテンツツールでタグ付け |
| ステマ告示（景品表示法 5 条 3 号の告示）との対応、責任の置き場所 | 31§4-2、G31§3 | パートナーシップ広告は［広告］ラベルとヘッダーの両名義。オーガニックの投稿は［タイアップ投稿］ラベル |
| 政治・選挙 | 31§3、34 | 政治家・政府はブランドコンテンツ広告の資格なし。両者が SIEP の許可を得ていればパートナーシップ広告は可（H:906775900606811） |
| 年齢 | 31§4-1 | 適切な最低年齢の無いブランドコンテンツは削除（H:788160621327601） |
| 支払い | — | 支払いは Meta の外。Meta はアプリでの支払いを扱わない（H:788160621327601） |
| 広告ライブラリ | — | パートナーシップ広告は広告ライブラリに登録（IG:797201308253238） |

- 31§4-2 の要点だけ再掲: Meta のタグ付けの義務はクリエイター側に置かれるが、告示の責任は広告主に残る。**広告主はタグ付けとラベルを契約と点検の項目に入れる**〔推測。31 の結論〕
- パートナーシップ広告に［広告］ラベルと［タイアップ投稿］ラベルの両方が出るかは、31§9 が ❓ として残している。今回読んだページにも記載が無い ❓
