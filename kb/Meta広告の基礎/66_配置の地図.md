## 0. 先に結論（この章で一番効く 10 点）

1. Meta の「配置」は**Meta のアプリの中の面**（フィード・ストーリーズ・リール・検索…）で、Google の「プレースメント」（掲載先のサイト・アプリ・チャンネル）とは単位が違う。掲載先の外部アプリに当たるのは Audience Network だけ。ヘルプの今の一覧は 6 つのテクノロジー（Facebook・Messenger・Instagram・WhatsApp・Threads・Audience Network）に **20 の配置**を 5 群（フィード／ストーリーズ・ステータス・リール／リール動画向けインストリーム／検索／アプリとサイト）で並べる ✅〔仕様〕（H:407108559393196）
2. **配置を足しても広告費は増えない**、と Meta は書く。そして Advantage+ 配置を勧める ✅〔公式の推奨〕（H:407108559393196、H:23942209872116948）
3. 使える配置は**目的 × 形式**で決まる。たとえば「認知」の目的では Audience Network と Facebook 右側広告枠はどの形式にも印が無く、「トラフィック」「エンゲージメント」「リード」「売上」では Facebook のお知らせにテキストと画像が出せる。Threads フィードの行があるのは「認知」「トラフィック」「売上」の表だけ ✅〔仕様〕（H:279271845888065、§2）
4. 「売上・リード・アプリの宣伝」で**廃止されたのは「手動配置」の選択肢**で、広告セットの［その他の設定を表示］→［配置の制御］で**個々の配置を外すことは今もできる**。ただし 1 つでも外すと［Advantage+ オフ］になる ✅〔仕様〕（H:175741192481247）
5. **除外した配置にも予算の最大 5% を回す「限定的な予算消化」は、対象の広告主では既定でオン**。使える目的は売上・リード・トラフィック・エンゲージメント・アプリの宣伝（認知は対象外）。Meta の分析で結果の単価が平均 7.7% 低い ✅〔仕様〕（H:1462437878221374）。△ rules.csv の M-配置-008 は「売上とリードの目的」と書く（§3-4）
6. **アカウント単位で外せる配置は 4 つだけ**（Audience Network のネイティブ・バナー・インタースティシャル／Audience Network 動画リワード／Facebook Marketplace／Facebook 右側広告枠）。全キャンペーンに自動で効き、既存への反映は最大 48 時間。社会問題・選挙・政治、金融商品・サービス、雇用、住宅の広告には効かない ✅〔仕様〕（H:1438478636941047。01§9-2 と一致）
7. ブランドの安全の道具は**配置ごとに効く範囲が違う**。インベントリーフィルター（拡張・中程度・制限）はフィード（Facebook・Instagram のフィード、リールフィード、Threads フィード）・コンテンツ内（Facebook インストリームリール動画・Facebook リール広告）・Audience Network の 3 つで別々に選ぶ。**既定は［拡張］**。アカウントで決めるとキャンペーンでは同じかより厳しい設定しか選べない ✅〔仕様〕（H:3001448133206080、H:260992311471821、D:Placement Targeting）
8. **パブリッシャーブロックリストが効くのは Audience Network・Facebook インストリームリール動画・Facebook プロフィールフィード・Facebook リール広告・Instagram プロフィールフィードだけ**。フィードのそばのコンテンツを止めるのは「コンテンツブロックリスト」で、Meta ビジネスパートナー経由でしか作れない。1 つのリストは **10,000 件まで** ✅〔仕様〕（H:255483958155378、H:1314478651899918）
9. **配信レポート**（どのパブリッシャー・コンテンツの近くに出たか）はブランドセーフティと適合性センターで、配置ごとに**オプトインが要り、データは約 1〜2 日後から**。Facebook フィードと Facebook リールは**過去 15 日のインプレッション上位 100 件の投稿だけ** ✅〔仕様〕（H:148229179267759）
10. 配置ごとの成績は API なら `publisher_platform`・`platform_position`（＋`impression_device`）の内訳で取れる。**配置ごとの CPA を並べて「高い配置を外す」と判断しない**（結果の内訳効果。28§9-3）。外す理由は「単価」ではなく「法令・ブランド・素材が合わない」に限る〔公式の推奨〕＋〔推測〕（H:965529646866485、01§9-6）

## 4. 配置の選び方（公式の推奨と、外す判断）

### 4-1. Meta の推奨 ✅〔公式の推奨〕（H:23942209872116948、H:407108559393196、H:965529646866485）

| 推奨 | 中身 |
|---|---|
| すべての配置を使う | Advantage+ 配置で Facebook・Instagram・Messenger・Threads・Audience Network のすべての配置を有効のままにする（このページは WhatsApp を挙げない） |

| コンテンツの内訳 | Facebook リール広告とインストリームリール動画は、行の［コンテンツレベルの内訳］で、出たコンテンツへのリンクと概算インプレッション。［コンテンツリストをダウンロード］。インストリームでは［コンテンツタイプ］（ライブかどうか）の列 |
| ブロックへ | 行から［パブリッシャーブロックリストに追加］ |
| ダウンロード | ［パブリッシャー配信レポート（.csv）］か［コンテンツ配信レポート（.csv）］ |
| 空のとき | 配置を選んでいない、データの準備中、配信システムがその配置で機会を見つけられなかった、のどれか |

- △ 配信レポートの対象に **Instagram のフィード・リール・Threads が無い**（読んだ本文の一覧）。Instagram 側の「どこの近くに出たか」は今回の公式の本文では確かめられない ❓

**運用の判断への効き方**
- ブランドに厳しい依頼主の案件では、**配信開始の前日までに配信レポートのオプトインを済ませる**。後からでは最初の 1〜2 日が見えない〔推測。オプトインの約 1〜2 日後からデータが出るため〕
- Facebook フィードの配信レポートは上位 100 件だけで、全部の掲載先の監査には使えない。「全件を見た」と報告しない〔推測〕
