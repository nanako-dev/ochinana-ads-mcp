## 3. ChatGPT の広告: いま言えること・言えないこと（要約）

詳しくは `ChatGPT広告の基礎/61_いま言えること言えないこと.md`。

**公式の本文で確かめたこと（2026-11-18）**
- **日本では 2026-08-11 に提供開始**（英国・メキシコ・ブラジル・韓国と同時）。米国のテストは 2026-02-09 から
- **日本の法人はセルフサーブで出稿できる**（ads.openai.com の Ads Manager。条件は請求先の法人の所在国）。最低の 1 日の予算は **2,500 円**
- 広告が出るのは **Free と Go の利用者だけ**。Plus・Pro・Business・Enterprise・Edu、18 歳未満、一時チャット、健康・心の健康・政治などの会話には出ない
- 広告は回答の下に「スポンサー」として別枠で出る。回答には影響しないと OpenAI は約束。広告主に渡るのは集計の数字だけ（会話・記憶は渡らない）
- 目的は 表示・クリック・コンバージョン の 3 つ。2026-11-09 から新しいキャンペーンは目標 CPA／目標 CPC（平均の目標）。旧来の上限入札は 2027-01-01 に廃止
- 1 日の予算は「7 日間の平均」で、1 日は 2 倍まで。目的は作った後に変えられない
- 文面の書き換え・翻訳・リンク先の変更を OpenAI が自動で行う「クリエイティブの強化」が、2026-10-30 から既定でオン。変わった文面を 1 本ずつ事前に見る手段は無い
- **日本を含む米国外では、金融・ヘルスケア・法律サービスの広告は原則出せない**。初期は生活用品、地域サービス、旅行・体験、デジタル製品・教育が中心
- 計測は OpenAI のピクセルとコンバージョン API

**公式に無い・分からないこと**
- 「どんな会話で出たか」のレポート（Google の検索語句レポートに当たるもの）があるか
- 日本の中で都道府県・市を指定できるか、日本語の文字数の数え方、日本の法規（薬機法・景表法）の扱い
- 払う額の決まり方: 公式ヘルプは「落札の入札額が払う額を決める」と書き、報道の「2 位価格」と食い違う
- 日本の加盟店が商品フィードを出せるか（今の標準は米国向け）

**推測**: 「AI の回答の中で自社を薦めてもらう広告」ではないので、そう提案すると誤りになります。今すぐ費用ゼロでできるのは、LP が OpenAI のクローラー（OAI-AdsBot・OAI-SearchBot）を弾いていないかの点検です。

## 4. Meta・LINEヤフーで「Google の常識を持ち込むと間違える」上位

**Meta**
- 情報収集期間は **件数の関門**（最後の大きな編集から 1 週間で約 50 件）。Google の「最長 7 日の表示」とは違い、件数が足りないと「情報収集が不十分」が続く
- クリエイティブの変更・新しい広告の追加・ターゲットの変更は、それぞれ情報収集期間をやり直させる（Google では広告文の変更で「学習中」にならない）
- 2026-03 から「クリック」の成果は **リンクのクリックだけ**。いいね・シェアの後の成果は「エンゲージスルー」に移った（請求は変わらない）
- 2026 年は アトリビューションに「標準・インクリメンタル・カスタム」のモデルの層がある
- 日予算は 1 日に最大 75% 上振れする（週で平均）

**LINEヤフー広告**
- LINE 広告の日本向け配信は **2026-10-26 に終了**。今は「LINEヤフー広告 ディスプレイ広告」で作る。検索広告は名前が変わっただけで、統合の外
- 検索とディスプレイでアカウント・タグ・コンバージョン API が別系統。検索のコンバージョン API は広告クリックの ID（yclid）が無いと送れない
- 「検索クエリーマッチング」（2026-09-14〜。Google の AI Max の検索語句の拡張に近い）は**自分でオンにする**。一方「クイックリンクの自動作成」は **2026-09-16 から全アカウントで既定オン**（止めるにはアカウント設定でチェックを外す）
- 新しい広告の審査は配信開始まで 3 営業日前後かかることがある
- レスポンシブ検索広告の文字数は全角を 2 文字と数える
