## 1. レスポンシブ検索広告の仕組み

| 項目 | 仕様 | 判定 |
|---|---|---|
| 広告見出しの本数 | 最少3、最大15 | ✅ |
| 説明文の本数 | 最少2、最大4 | ✅ |
| 文字数 | 見出し 半角30、説明文 半角90、パス 半角15（各2つ） | ✅ |
| 日本語の数え方 | 全角1文字＝半角2文字ぶん。見出しは全角15、説明文は全角45。半角の英数字や記号は1文字ぶん | ✅ |
| 表示される数 | 見出しの位置に最大3、説明文は最大2。毎回少なくとも見出し1・説明文1が選ばれる。見出し2・3と説明文2は出るとは限らない | ✅ |
| 見出しが1本だけの表示 | 成果が上がると予測されるとき、見出し1本で表示されうる（2024-02-01 発表）。頻度は組み合わせレポートで見られる | ✅ |
| 見出しが別の場所に出る | 説明文の冒頭に出る／使われなかった見出しがサイトリンクの枠に最大2つ出る（同じ広告グループの別の広告の見出しが借りられることもある）。日本語ヘルプの呼び名は「高い柔軟性」 | ✅ |
| 省略 | **何文字目から「...」になるかは公式に記載なし**。上限（半角30・90・15）以内でも、ブラウザの幅と字の幅（幅の広い字が多いと見出しが入りきらない）で短縮されうる。電話番号アセットが出ると広告文の一部が省略されうる、画像アセットが出ると説明文の位置2が省略されうる。詳しくは §1-1 | ✅（数字は ❓） |
| 広告グループあたりの上限 | 有効なレスポンシブ検索広告は広告グループごとに最大3件 | ✅ |
| 推奨本数 | 「高い」以上を2つ以上（ヘルプ本文）／少なくとも1つ（同じベストプラクティスのFAQ、2023年の公式ガイド） | △ |
| キャンペーン単位の見出し・説明文 | 見出し3・説明文2までをキャンペーンに付けられ、配下の全広告で使われうる。期間指定と固定ができる（2024-02-01 発表） | ✅ |

**組み合わせの選ばれ方 ✅（Google の公表、2023年の公式ガイド）**
1. 検索語句と、マッチしたキーワードの文脈を読む
2. 手持ちのアセットから、関連性と見込み成果で組み合わせを作る
3. 重複や冗長なものを落とし、採点して、良いものだけをオークションに出す

- 学習は「新しいアセットが最初に配信されてから数時間のうちに起こりうる」「検索の量が多いほど学習は効く」と書かれている
- あまり表示されない見出しが悪いとは限らない。一部の検索者にだけ強く効く見出しは、表示が少なくても上位の成績になりうる（公式ガイドの例え）
- 見出しの中で検索語句と一致・近い語は自動で太字になる

**広告を足すと成果が増えるという数字（Google の公表）**: 1本→2本でコンバージョン数 平均+6.6%、2本→3本で平均+3.7%（同程度のコンバージョン単価）。出典は Google 内部データ、期間 2025-08-15〜08-20。6日間の観測値で、対象の規模や業種は書かれていない。

### 1-1. どこで省略されるか（2026-11-19 追記）

**結論**: Google は「何文字を超えたら『...』」という数字を出していない。公式が書いているのは「上限の中でも、場所が足りなければ短くする」ことと、その原因（画面の幅、字の幅、一緒に出る部品、掲載先）だけ。数字が要るなら、広告プレビューで端末を変えて見るしかない（それも実際の配信と同じとは限らない）。

**公式に言えること** ✅〔公式〕（ヘルプ 7684791 の日本語版・英語版、9566341、148778 を 2026-11-19 に本文で確認）

| 項目 | 公式の記述 |
|---|---|
| 上限の意味 | 文字数の上限は「できるだけ広告全体を表示するため」に置いている。上限は見出し 半角30、説明文 半角90、パス 半角15（全角は 1 文字を半角 2 文字ぶんと数える） |
| 短くされること | 必要に応じて自動で短くされることがあり、通常は省略記号（...）を使う（英語版: "may need to shorten your text, usually with an ellipsis"。"some shortening may occur in some formats" とも書く） |
| 何で決まるか | 「幅が狭い字（i など）より幅が広い字（m など）を多く使うと、**ブラウザのサイズによっては**見出しが使える場所より長くなる」。つまり字数ではなく**表示の幅**の話として書かれている。何ピクセル・何文字かは書かれていない |
| 一緒に出る部品 | 電話番号アセットを使うと、広告文の一部が省略されて［電話］ボタンが出ることがある。画像アセットが出ると、**説明文の位置 2 が省略されることがある**（9566341。「フォーマットによっては一部が省略される場合もある」とも） |
| 掲載先 | ディスプレイ ネットワークに出るとき、形式によっては見出し 2 が出ない |
| そもそも出ない部分 | 見出し 2・3 と説明文 2 は「最も効果的と予測される」か「十分なスペースがある」ときに出る＝**出るとは限らない**。見出し 1・説明文 1 の欄の文は出る。見出しが説明文の冒頭に出ることもある |
| 固定の効き方 | 見出しの位置 1・2、説明文の位置 1 に固定したものは常に出る。見出しの位置 3、説明文の位置 2 に固定したものは出るとは限らない。法律で必要な文言はこの 3 か所のどれかに |
| パス | 上限（半角15、2 つ）だけで、パスが省略されるかの記述は無い ❓ |
| 確かめ方 | 広告プレビューと診断ツール（148778）で検索結果での見え方を確かめられる。ただし「キャンペーンのすべてのアクティビティは反映されない場合がある」。省略の扱いについての記述は無い |
| API | Google 広告 API の RSA の説明（overview・ResponsiveSearchAdInfo）は「配信時に見出し最大 3・説明文最大 2」と書くだけで、文字数・省略の記述は無い。path2 は path1 があるときだけ設定できる |

**公式に無く、第三者だけが言っていること**〔第三者〕（数字の根拠の計測が示されていないので、運用の判断の根拠にしない）
- デジタルチェンジ編集部「検索連動型広告の文字数まとめ＆広告文が途中で切れる場合の対処法」（2022-10-21 公開、10-28 更新）: 見出し 1 はほぼ全文が出る、見出し 2 はスマホでは全文が多いが **PC では 11 文字目以降が省略されるケースが多い**、見出し 3 はめったに出ない。筆者の観察で、計測の方法・件数・時期の画面は書かれていない。2022 年の画面の話で、今も同じかは分からない https://www.digitalchange.co.jp/column/listing-ad/20221021_1/ （2026-11-19 本文を取得）
- 英語の文字数チェックの道具・解説のサイト（2026 年の記事が多い）は「スマホでは説明文が 60〜80 字（半角）前後で切れる」「80〜90 字は切れうる」などと書くが、サイトごとに数字が違い、出どころの計測も無い（WebSearch の抜粋だけで本文は読んでいない）
- Search Engine Land「Are your Google text ads getting truncated?」（2019 ごろ、拡張テキスト広告の時代）は字数ではなくピクセルで決まると論じた記事として検索結果に出るが、本文は 403 で取得できず ❓

**分からないこと** ❓
- 端末・画面の幅ごとに何文字（何ピクセル）で切れるか
- 全角の日本語で、上限ちょうど（見出し全角 15 字・説明文全角 45 字）の文がどのくらいの頻度で切れるか
- 省略が起きたかどうか・その回数を見る手段（組み合わせレポート 11894820 が切れたかを示すかは今回は確かめていない）

**運用の判断への効き方**
- **言いたいことは各アセットの前半に置く**。どこで切れるかが決まっていない以上、後ろが落ちても意味が通る文にしておくのがいちばん確か〔推測〕
- **必ず見せたい文（法律で要る表示、価格の条件など）は、見出しの位置 1・2 か説明文の位置 1 に固定する**。説明文 2 は、画像アセットや電話ボタンで削られうるうえ、そもそも出ない場合がある（公式）
- **全角の上限ぎりぎりは「幅の広い側」になる**: 日本語の字はどれも幅が広い字なので、上限いっぱいの日本語の見出しは英字の見出しより切れやすい側にあると考えておく〔推測。公式の「幅が広い字を多く使うと入らない」からの読み〕
- 入稿前に広告プレビューで PC とスマホの両方を見る。ただし見えたものを「本番でも同じ」とは言わない（公式がそう書いている）

## 2. 固定（ピン留め）の効果と副作用 ✅

| 点 | 内容 |
|---|---|
| 効果 | 固定した見出し・説明文は指定の位置にだけ出る。見出し位置1・2と説明文位置1に固定したものは常に表示される |
| 出ないことがある位置 | 見出し位置3と説明文位置2は、固定しても表示されないことがある。必ず見せたい文（「非公式」の明記など）は見出し1・見出し2・説明文1のどれかに固定する |
| 副作用 | その位置にほかの見出しが出なくなる／検索に合わせられる組み合わせが減る／広告の有効性が下がる。ヘルプは「ほとんどの場合推奨されません」 |
| 全部固定 | 全位置を固定で埋めると、固定していないものは表示されなくなる |
| 公式が勧めるやり方 | 1つの位置に、内容の違う文を2〜3個固定する（その中で比べられる）。同じ・よく似た文を同じ位置に固定しない。大事な見出しを1〜2個だけ固定して残りは回す「ハイブリッド」 |
| AI Max との関係 | 最終ページURLの拡張でより合うURLが選ばれたとき、固定は使われない（AI Max メモ参照） |

## 3. 「広告の有効性」は何を見ているか

**Google の公表 ✅**

| 見ているもの | 中身 |
|---|---|
| アセットとキーワードの関連性 | 広告グループのキーワードが見出し・説明文に入っているか。キーワードは1つの見出しに丸ごと入っている必要がある（2つに分けると数えない） |
| 見出しの組み合わせの数 | 見出し15・説明文4に近いほど良い。似た言い回しの重複は減点 |
| サイトリンクの数 | アカウント＞キャンペーン＞広告グループの同じ枝の合計で6個以上（動的サイトリンクも数える） |
| テキストのカスタマイズ | オンなら、Google が作った文も自分の文と同等に数える |

- 見ていないもの: ランディングページや商品の質、新しいキーワードを足す価値
- 使われ方: 「広告ランク、品質スコア、オークションでの落札の決定に使用されることはありません」。配信の可否も決めない。作るとき・直すときの手引き
- 2023年の公式ガイドの補足: 評価そのものはオークションの要素ではないが、評価が見ている中身（アセットの数や関連性）は配信に影響する。評価の区分は回帰分析から作ったと説明している
- 動く指標: キーワード・アセット・構成を変えるたびに計算し直される
- 成果との関係（Google の数字）: 「低い」→「非常に高い」に上げた広告主はクリック数とコンバージョン数が平均+15%（内部データ、2025-08-15〜08-20）。△ 9921843 の英語版（2026-11-17 取得）は同じ15%を「RSA とサイトリンクの広告の有効性を『低い』→『非常に高い』に上げた場合のコンバージョン数」とし、クリック数には触れていない。何を足した効果なのかがページで揃っていない

**第三者の検証（広告の有効性が高いほど成果が良いとは限らない）**

| 誰が・いつ | 規模 | 主な結果 | 注意 |
|---|---|---|---|
| Optmyzr（Navah Hopkins、2024-09-09） | 2.2万超のアカウント、100万本超の広告 | 「平均的」の広告が CPA・コンバージョン率・ROAS で最も良かった。クリック率は評価による差がほぼない | 自社ツール利用者の観測データ。因果ではない |
| Optmyzr（Frederick Vallaeys、2026-04-06） | 約2万アカウント | 「平均的」CPA 12.43ドル・CVR 12.65%、「非常に高い」CPA 28.68ドル・CVR 4.97%。一部だけ固定した広告の成績が良い | 筆者自身が「観測データで、対照実験ではない」と明記 |
| Adalysis（Brad Geddes。Search Engine Journal 2026-11-03 の記事経由） | 5,900超のアカウント。同じ広告グループ内で評価の違う2本を比較 | 評価の高い方が表示を多く得たのは63%。クリック率が高かったのは52.5%、コンバージョン率が高かったのは45.1%。固定なしの広告に限ると、評価が上がるほどクリック率は上がる | 原典は未取得。記事の要約で確認 |

読み方（推測）: 評価は「材料が足りているか」の点検表で、成果の予測値ではない。固定を使うと評価は下がるが成果が悪いとは限らない。評価を上げるために文の質を落とす（キーワードを無理に入れる、似た見出しで15本を埋める）のは本末転倒。

## 4. アセット別レポートの読み方

**いまの仕様 ✅**（「表示回数しか出ない」「低・良・最良が付く」は古い）

- 見出しごとの評価ラベル（学習中・低・良・最良）を出していた [パフォーマンス ラベル] 列は廃止された（レスポンシブ検索広告の話。ディスプレイのアセット レポートには 2026-11-17 時点でも評価列が残っている。16 §5-4、13063616）。代わりに、アセットごとの表示回数・クリック数・費用・コンバージョン・コンバージョン値が見られる
- 注（生成文面との関係）: テキストのカスタマイズのよくある質問（16740321）は、Google が作った文面が「低いパフォーマンス」のラベルが付くと消える、と今も書いている（03 §2）。列が廃止されたので、そのラベルを画面で見て確かめることはできない。API の項目 ad_group_ad_asset_view.performance_label（BEST・GOOD・LOW・LEARNING など）は手元の API 項目一覧（v26）に残っているが、値が今も入るかは ❓（確かめ方: GAQL でアセットごとに performance_label を取り、LOW が返るかを見る）
- この詳しい数字は 2025-06-05 以降の日付だけ
- 見る場所: [広告] の表で、広告の下の [アセットの詳細を表示]（広告単位）。[アセット] ページ（キャンペーン単位）。「提供者」列が「Google AI」のものはテキストのカスタマイズが作った文

| 読むときの決まり（Google の公表） | 意味 |
|---|---|
| 足し算できない | 1回の表示に見出しが3本出れば、3本それぞれに表示1回が付く。アセットの合計は広告の合計と合わない |
| 比率は目安 | アセット別のクリック率・単価・CPA は「傾向を示す目安としてのみ」。一緒に出た相手の影響を受ける |
| 評価の単位 | 個々のアセットではなく、広告グループやキャンペーンの単位で成果を見る |
| 入れ替えの目安 | 数週間ずっと表示回数ゼロのアセットは入れ替えを検討 |
| 順番 | まず数と種類を上限近くまで増やし、そのあとで入れ替える |

**組み合わせレポート ✅**: [アセットの詳細を表示] の [組み合わせ] タブ。出るのは表示回数と、よく出た組み合わせだけ。Google は「これを元に固定の広告を作るな」と書いている（同じ成果は保証されない）。

**以前の仕様（2023年の公式ガイド。背景として）**: 評価ラベルは、同じ広告の中のほかのアセットと比べた相対評価だった。「学習中」は材料不足の意味で、**アセットが500回超、広告が「Google 検索: 上部」で30日間に2,000回超**表示されてから見直す、とされていた。「低」は消すのではなく入れ替える（消すだけだと組み合わせが減る）。表示回数しか出なかった理由について、ガイドは「クリック率のような従来の指標では統計的な確からしさを示せないので評価ラベルを使う」と説明していた。

**少ない表示回数で良し悪しを判断してよい目安**

| 根拠 | 目安 | 種類 |
|---|---|---|
| 現行ヘルプ | 表示ゼロが数週間続いたら入れ替え候補。比率は目安どまり | Google の公表 ✅ |
| 2023年ガイド | アセット500回超 かつ 広告2,000回超（検索上部・30日） | Google の公表（ラベル廃止前の基準）✅ |

## 8. クリック率を上げるために公式が勧めていること ✅

| 勧め | 公式の言い方（要約） | 根拠として示されているもの |
|---|---|---|
| 検索語句と見出しを合わせる | 広告文の表現を、より直接的に検索語句の表現と合わせる。見出しに少なくとも1つキーワードを入れる | 広告の関連性と推定クリック率はオークションでリアルタイムに使われる。一致した語は太字になる |

| 行動を促す言葉 | ランディングページに直結する言い方を何種類か用意して比べる。「申し込む」「試す」「見つける」など。ありきたりな定型句は避ける | 理由の説明のみ |

## 9. 広告のポリシー

### 9-1. 編集基準 ✅
見出し・説明文・アセットで許可されないものの例: 記号や句読点の乱用（「!!」、目立たせるための中点やアスタリスク。★ は現行ページの例に無い ❓、飾りの記号に当たりうるので外すのが安全）、同じ語の不必要な繰り返し（同じアセット内だけでなく、広告グループ内のアセット間でも）、意味の通らない文、余分なスペース、文字数超過（全角は特に注意）、広告文への電話番号の直書き、宣伝するものの名前が分からない広告、確認済みのドメイン・名前と一致しないビジネス名。

### 9-2. 商標 ✅

| 使う場所 | Google の扱い |
|---|---|
| キーワード | 制限されない |
| 表示URLのセカンドレベルドメイン | 制限されない |
| 広告文 | 権利者が Google に申し立てると調査され、制限されうる。直接競合の商標、紛らわしい・誤解を与える使い方は制限 |
| 広告文でも制限されない場合 | (1) その商品を主に売っているページ (2) **商標に関する情報の提供が主目的のページ**（情報サイト）(3) 普通の言葉として記述的に使う場合 |
| 情報サイトの条件 | 「再販業者か情報サイトの運営者かを、広告とランディングページの中で明確にする」 |

- 仕組みは申し立て制。申し立ては国と業種の範囲で受け付けられ、制限は同じセカンドレベルドメインの全広告に続く
- 日本向けの特別な扱いは、ポリシーページには書かれていない ❓
- 制限がかかると、広告は「有効（制限付き）」、アセットは「承認済み（制限付き）」になり、[ポリシーの詳細] 列に理由が出る

### 9-3. 不実表示（「非公式」の扱いに関わる）✅
- 実際には支援を受けていないのに、ほかのブランド・組織から支援を受けているように見せることは不可
- 身元や提携関係について、誤解を招く・分かりにくくする・省くことは不可
- 「非公式」と明記することは、この2点と商標ポリシーの「情報サイトであることを明確に」に沿う。ただし明記すれば商標の制限を受けない、とは書かれていない

### 9-4. オリンピック関連の用語・マーク

**Google 側**: オリンピックだけを対象にした広告ポリシーは、取得したページの範囲では見当たらなかった ❓。一般の商標ポリシー（9-2）と不実表示（9-3）が当てはまる。

## 12. 少額・少量のアカウントでの注意

- 学習は検索の量が多いほど効く（Google の公表）。表示が月に数百回の規模では、見出し15本×説明文4本の組み合わせを試し切れない（推測）
- 広告を3本に分けると、1本あたりの表示がさらに薄くなる。Google の推奨は △（2本以上／1本以上）で、少量のうちは本数を増やすより1〜2本に寄せた方が読みやすい（推測）
- アセット別の数字は、表示500回・広告2,000回（旧基準）に届くまでは「ゼロが続くものを探す」用途に限る
- 15本を埋めるために似た文を足さない。編集基準の「重複表現」に当たりうるうえ、広告の有効性も独自性を見ている。見出しの長さについては、Optmyzr が「半角20文字未満の短い見出しの方が CPA が低い」としている（第三者の検証、2026-04。英語圏中心の観測データで、日本語に当てはまるかは不明）
- 審査中に続けて編集しない。1日に何度も直すと、審査のやり直しと学習のやり直しが重なる
- 画像アセットは開設60日・過去30日の費用、ビジネス情報は過去28日の費用が条件。配信を止めていた期間があると出なくなる
- 文のテスト（広告バリエーション）は、Google 自身が「十分な配信量が要る。影響の大きい所に絞れ」と書いている

## 13. 判断の型

1. **評価より材料**: 広告の有効性は「高い」以上なら追わない。キーワードを見出しに入れよという提案は、入れて不自然なら無視してよい（オークションには使われない）
2. **見出しの良し悪しは急がない**: 表示ゼロが数週間 → 入れ替え候補。それ以外は、広告全体で表示2,000回・その見出しで500回を超えるまで結論を出さない
3. **成果は広告グループ単位で見る**: 見出し別・広告別のクリック率は補助
4. **必ず見せたい文は固定**: 見出し1・見出し2・説明文1のどれかに。同じ位置に言い回し違いを2〜3本
5. **消すより入れ替える、いちどに1〜2本**: 変更日を控え、審査が終わるまで触らない
6. **アセットは条件を先に確認**: 出ないときは、不承認か、条件（適格性確認・費用・開設日数）か、広告ランクかの順で見る
7. **他者の名称は「どこに出るか」で分ける**: キーワード（Google 上は可）／広告文・アセット・画像（出さない）。自動で文を作る機能がオンなら、キーワードやページの語が広告文に出る経路をふさいでから足す
8. **ステータスが「制限付き」になったら**: [ポリシーの詳細] 列で理由を見る。商標なら、その語を広告文から外すのが先
9. **配信が出ないとき**: 入札を上げる前に、広告の関連性・推定クリック率・ランディングページの順で品質を直す（アセットが出ない原因も広告ランク）

## 15. この状況への当てはめ（非公式のスポーツ観戦ガイド）

- **広告3本**: 同じ広告グループなら上限いっぱい。主力でも表示153回なので、3本に割ると学習の材料が足りない（推測）。成績の悪い1本を止めて2本に寄せる案を検討
- **有効性「非常に高い」「高い」**: これ以上は追わない。見出し15本の中に言い回しだけ違うものがあれば、重複表現の整理を優先
- **見出しごとの表示1〜68回**: 良し悪しはまだ言えない（68回でクリック率の幅は約6〜22%）。主力広告の153回・19クリックも幅は約8〜19%。いまやってよいのは「数週間ゼロの見出しを入れ替える」だけ。表示1回の見出しは、一部の検索にだけ出る型かもしれないので、検索語句と合わせて見る
- **「非公式」の明記**: 見出し位置3や説明文2に置くと出ないことがある。必ず見せるなら見出し1・2か説明文1に固定し、同じ位置に言い回し違いを2本入れる。Google の商標ポリシー（情報サイトであることを広告とページで明確に）と不実表示にも沿う
- **サイトリンク6・コールアウト7・画像9**: 公式の推奨（6以上・4以上）は満たしている。画像は 1:1 と 1.91:1 の両方があるかを確認。構造化スニペット1つは値が4つ以上か、合うヘッダーをもう1つ足せるかを見る
- **ビジネスの名前とロゴが未設定**: 適格性確認が未了なら、表示URLと地球儀のアイコンで出ている。済んでいれば、サイトから自動で作られた名前・ロゴが出ているかもしれない（アセットレポートで確認）。まず適格性確認が済んでいるかを確認。名前は確認済みのドメイン名か正式名と完全一致が条件（2026-10 からの例外は再販・アフィリエイトには使えない。§6。全角12文字まで）。ロゴは自作のものにし、大会や競技団体のマークは使わない
