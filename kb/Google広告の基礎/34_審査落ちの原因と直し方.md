## 0. 先に結論（10 行）

1. 審査は**作成・編集のたびに自動で始まり**、承認済みのものも**後から再審査される**（広告・リンク先・アカウントのどれかに印が付いたとき）。再審査中（Under re-review）は配信が止まり、管理画面から異議は出せない ✅（H:1722120 英語版）
2. 審査は **AI（自動）と人の組み合わせ**。自動で落とし、判断が微妙なものを担当者に回す。広告そのものだけでなく、過去の違反歴や外部からの報告も判断材料 ✅（P:7187501 英語版）
3. 所要時間は「ほとんど 1 営業日」だが、日本語ヘルプは**デマンド ジェネレーションは 3〜5 営業日、複雑な形式は最長 7 営業日**と書く ✅（H:6327680 ja・en 一致）。15 の 7-01・05 §10 も同じ（2026-11-17 に追記済み）
4. 原因の特定は「ステータスにカーソル →『ポリシーを確認』」「表示項目に『ポリシーの詳細』を追加」「ツール > 問題を修正 > ポリシー マネージャー」の 3 つ。API なら `policy_topic_entries` の `evidences` に**引っかかった文言・URL・HTTP エラー**が入る ✅（H:9338593、API:PolicyTopicEvidence）
5. 直し方は 2 通り。**直して保存すれば自動で再審査**（再審査請求は不要）。直さずに「判定が誤り」と言うなら、ポリシー マネージャーから **"Dispute decision"**、直したうえで念押しするなら **"Made changes to comply with policy"** ✅（H:9338593）
6. 違反には重さが 3 段ある。(a) 不承認だけ、(b) **違反警告（ストライク）**: 対象 15 ポリシー。警告 1 回 → 1 回目 3 日停止 → 2 回目 7 日停止 → 3 回目でアカウント停止、(c) **悪質な違反**: 予告なしで即停止、原則二度と出稿できない ✅（P:10922738、P:7187501）
7. **審査を通すための細工が、いちばん重い違反になる。** 不承認の広告の言い換え版を量産する、別アカウント・別ドメインで同じ広告を出す、Google と利用者に違う内容を見せる（クローキング）は「広告掲載システムの回避」で即停止 ✅（P:15938075）。ただし**表記・誤字など編集基準の不承認では停止にならない**と明記 ✅
8. 日本で特に効くのは: 処方薬の名前は**広告文・LP・キーワードのどれにも使えない**（例外は医療従事者向けサイトなど）、市販薬はライセンス番号の掲載が要る、オンライン マッチングは**公安委員会への届出と Google の認定と「18禁」表示**、ギャンブルは公営のくじとスポーツベッティングのみ ✅（P:176031、P:6368711、P:9908372、P:6018017）
9. 画像への文字・図形・ロゴの重ねは**形式で扱いが違う**。**検索の画像アセットは「Not allowed」（不承認になる）**、P-MAX は重ねてよいが比率ごとに重ねなしの画像を 1 枚以上が推奨、**レスポンシブ ディスプレイ広告ではベスト プラクティスで必須ではない** ✅（P:10347108、H:9823397）。RDA で不承認になるのは「ボタンを模した絵」（誤解を招く広告のデザイン）や「読めない文字」（画像の品質）の方 ✅（P:6021546）
10. 2026 年は変更が多い: 7 月に**6 か月以上前の判定は管理画面から異議を出せなくなった**、8 月に**「広告配信の制限」がすべての Google 広告に拡大**（2028 年までに段階的に）、10 月に**ビジネス名がドメインと違ってよい条件**が追加 ✅（8 章）

### 1-1. いつ審査されるか ✅

| システム全体の優先度づけ | 安定のために審査・再審査の順番を変えたり、配信を一時的に制限したりすることがある | H:1722120 英語版 |

| 一時停止中の広告 | 有効な広告と同じく審査される | 15 の 7-04 |

### 1-2. 誰が審査するか ✅

- 自動のモデル（人の判断を学習した機械学習）がまず判定し、微妙なものは担当者・分析者に回す。広告の中身に加えて、**アカウントの情報（過去の違反歴など）、利用者や事業者からの報告、Google の調査**も使う（P:7187501 英語版）
- 2025-03 に Google が審査の説明を「AI と人の両方で評価する」と書き直した、と Search Engine Roundtable／Search Engine Land が報じている【第三者】
- 悪質な違反の判定では、広告・サイト・アカウントに加えて**第三者の情報源**も見ると書かれている（P:15938075）

### 1-6. 原因を特定する手順 ✅

1. **ステータスにカーソル**: キャンペーン > 広告（または広告グループ）で「不承認」にカーソルを合わせ、「ポリシーを確認」（Read the policy）。どのポリシーかが出る
2. **「ポリシーの詳細」列**: 表の上の「表示項目」→「表示項目を変更」→「属性」→「ポリシーの詳細」→「適用」。広告とアセットの両方の表に足せる。スマートモードではエキスパートモードに切り替える
3. **ポリシー マネージャー**: ツール > 問題を修正（Troubleshooting）> ポリシー マネージャー。「ポリシーに関する問題」タブで対象の一覧と異議の申し立て、「再審査請求の履歴」（Appeal history）タブで結果。不承認の通知メールの「ポリシーに関する問題を確認して修正」リンクからも入れる
4. **P-MAX**: アセット グループのタブでステータスにカーソル → 問題を確認、「詳細を表示」で個々のアセットのステータス列
5. **API（どの文言・どの URL かまで分かる）**: `ad_group_ad.policy_summary.policy_topic_entries`、`asset.policy_summary`、`asset_group_asset.policy_summary`、`ad_group_ad_asset_view.policy_summary`。各エントリに
   - `topic`（例: `DESTINATION_NOT_WORKING`、`ALCOHOL`。種類は予告なく増える）
   - `type`: `PROHIBITED`（出ない）／`LIMITED`（場面による）／`FULLY_LIMITED`（今のターゲティングでは全く出ない）／`AREA_OF_INTEREST_ONLY`／`DESCRIPTIVE`（関係しうるが制限しない）／`BROADENING`（逆に広がりうる）
   - `evidences`: `text_list`（**引っかかった広告内の文言**）、`destination_text_list`（**LP 内の引っかかった文言**）、`website_list`、`language_code`（判定された言語）、`destination_mismatch`、`destination_not_working`（HTTP エラーや DNS など）
   - `constraints`: `country_constraint_list`（出せない国）、`certificate_missing_in_country_list`（認定が要る国）、`certificate_domain_mismatch_in_country_list`（認定がドメインを覆っていない国）、`reseller_constraint`
6. **リンク先の確認**: Chrome DevTools でユーザー エージェントを AdsBot に変えて開き、HTTP エラーが出ないかを見る（P:6368661 が手順を案内）

- ❓ 管理画面の「ポリシーの詳細」で**どの見出し・どの画像が原因か**まで強調表示されるかは、H:6327680・H:9338593 のどちらにも書かれていない。**確かめ方**: API の `evidences.text_list` を GAQL で取り、管理画面の表示と見比べる（0 円）
- 管理画面で扱えない形式やポリシーは「不承認の広告とポリシーに関する質問」フォームから（H:9338593）

出典: H:9338593 ja／英、H:6327680 ja、H:13363141／API:PolicyTopicEntry、PolicyTopicEntryTypeEnum、PolicyTopicEvidence、PolicyTopicConstraint、手元の `ads-intel/state/api_fields/latest.json`（policy_summary を持つリソースの確認）

## 2. 不承認の理由の一覧表（最重要）

- 並びは Google のポリシーの 4 分類（禁止コンテンツ／禁止されている行為／制限付きのコンテンツと機能／編集基準と技術要件）に沿う（P:6008942 ja／英）。英語版にはこのほか **Prediction Markets（予測市場）** が制限付きに入っている
- 「ポリシー名」の日本語は**ポリシー ヘルプの見出し**。管理画面の「ポリシーの詳細」列の表記が同じかは ❓（確かめ方: 実際の不承認を 1 件開いて照合）
- 「重さ」列: **即停止**＝悪質な違反（予告なしに停止、原則再開なし）／**ストライク**＝違反警告の対象 15 ポリシー（5 章）／**通常**＝不承認。繰り返すと少なくとも 7 日前の通知のうえ停止されうる
- 「何が引っかかるか」の日本語の例は、公式の例を日本語の広告でよくある形に置き換えたもの【推測を含む】。公式が日本語の例を出しているものは「公式例」と書く
- 確かめる場所の略: 【詳細】＝ポリシーの詳細列／カーソル、【PM】＝ポリシー マネージャー、【API】＝policy_topic_entries の evidences、【LP】＝リンク先を実機・AdsBot で開く

## 4. 直し方と再審査請求

### 4-1. 手順 ✅

| 状況 | すること | 出典 |
|---|---|---|
| 広告文・アセットの違反 | 広告 > 編集 > 保存。**保存で自動的に再審査**。再審査請求は不要 | H:9338593 |
| 動画の違反 | 動画を外して保存し、直した動画を再アップロード | H:9338593 |
| リンク先の違反 | (1) URL の打ち間違いなど技術的な問題を確認 → (2) ウェブ担当と LP を直す → (3) 直せないなら、要件を満たす別のページに広告の URL を差し替える | H:9338593 |
| 判定が誤りだと思う | ツール > 問題を修正 > ポリシー マネージャー >「ポリシーに関する問題」タブ > 対象の「再審査請求」> 理由を選ぶ > 送信。または広告の一覧で選択 > 編集 >「ポリシーに関する決定に対して再審査を請求」| H:9338593 |
| 直したうえで確実に見てほしい | 同じ手順で理由に "Made changes to comply with policy" | H:9338593 |
| 「有効（制限付き）」のラベルが誤り | 同じ手順で異議 | H:9338593、H:2684542 |
| 違反警告（ストライク）による一時停止 | 違反をすべて直す → **確認フォーム（acknowledgement）**を出す。誤りだと思えば**違反警告の異議フォーム** | P:10922738 |
| アカウントの強制停止 | アカウント内の「お問い合わせ」から異議。「再審査請求中」と表示。認められなくても再申請は可。一部は**広告主の適格性確認が必須**で、本人確認に 3 回失敗すると異議を出せない | P:15938075 |
| 広告配信の制限 | 専用の異議フォーム | P:17344822 |
| 管理画面で扱えない形式・ポリシー | 「不承認の広告とポリシーに関する質問」フォーム | H:9338593 |

### 4-2. 「直して再審査」と「判定に異議」の違い

| | 直して保存 | 異議（Dispute decision）|
|---|---|---|
| 使う場面 | 原因が分かり、直せる | 違反していないと考える、ラベルが誤り |
| 回数の制限 | ❓ 保存の回数制限は書かれていない（審査中の編集は審査を遅らせる）| **1 広告 3 回まで**。3 回失敗したらサポートへ連絡するまで出せない |
| 間隔 | ― | 同じ広告・キャンペーンは **24 時間以上**あける。24 時間に多すぎると処理が止まる |
| 古い判定 | ― | **2026-07-21 から、6 か月以上前の判定は管理画面から出せない**（サポートへ）|
| 結果の見方 | ステータス列 | 「再審査請求の履歴」タブ: 状態（審査完了／進行中＝24 時間後に再確認／未審査）、結果（成功／一部成功／エラー: 再試行／失敗／重複）|
| 失敗・重複のとき | ― | 同じ請求を繰り返さず、**広告文か最終ページ URL を少し編集して保存し、再クロールさせる** |
| 乱用 | ― | 乱用と見なされると異議の処理が止まり、再開にはサポートが要る |

出典: H:9338593 ja／英、P:17251522（6 か月の制限）

### 4-3. 通らないときの次の手

1. **ポリシーの詳細と API の evidences をもう一度読む**。広告文ではなく LP の語（`destination_text_list`）が原因のことが多い（C07・L01〜L06）【推測】
2. **一度に 1 要素だけ直す**（文、画像、LP のどれか）。どれが効いたか分かるようにする（T6 8-19）
3. **認定が要るポリシーか確認**（ヘルスケア、ギャンブル、マッチング、金融の一部、政府書類、チケット、資金募集）。認定なしではどう直しても通らない
4. 3 回の異議で通らなければ**サポートに連絡**（電話・チャット・フォーム）。サポートは「直す箇所」は教えるが審査の中身は教えない、という日本の実務家の指摘がある【第三者・検索結果の要約】
5. 商標なら権利者に**使用許可**を依頼（C21）
6. どうしても通らない表現は**捨てる**。別アカウント・別ドメインで同じものを出すのは B06（即停止）

## 5. 違反の積み重ね（警告・ストライク・強制停止）

### 5-1. 3 つの重さ ✅

| 重さ | 何が起きるか | 対象 | 出典 |
|---|---|---|---|
| 不承認だけ | その広告・アセットが出ない | ほとんどのポリシー。特に**編集基準の不承認（表記・誤字）はアカウント停止の理由にならない**と明記 | P:15938075、P:6021546 |
| 繰り返しによる停止（通常）| 違反が繰り返されると停止されうる。**停止の少なくとも 7 日前に通知（at least 7 days）**（違反内容と対処法つき）| 悪質でないポリシー全般 | P:7187501 ja |
| 違反警告（ストライク）| 警告 1 回 → 1 回目: **3 日間の一時停止** → 90 日以内に同じポリシーで 2 回目: **7 日間**（最後の通告）→ さらに 90 日以内に 3 回目: **強制停止**。一時停止中も管理画面とレポートは見られる。停止中に新たな違反広告を作るとさらに 1 回 | 下の 15 ポリシー | P:10922738 |
| 悪質な違反 | **予告なしで即停止**、原則として再び出稿できない。異議は可だが「やむを得ない事情」のときだけ解除 | 許可されないビジネス手法（公人のなりすまし含む）、組織的な欺瞞行為、悪意のあるソフトウェア、広告掲載システムの回避（クローキング・複数アカウント・適格性確認の虚偽）、無許可の薬局（P:176031）| P:6020955、P:6020954、P:15938075、P:176031 |

**違反警告の対象 15 ポリシー**（P:10922738）: 不正行為を助長する商品やサービス／未承認の物質／銃・銃の部品／爆発物／その他の武器／たばこ／報酬を伴う性行為／国際結婚あっせん（mail-order brides）／**クリックベイト**／**誤解を招く広告のデザイン**／保釈保証／電話番号案内・転送・録音／信用回復／バイナリーオプション／**個人ローン**

- 日本の一般の広告主がふつうに踏みうるのは、**クリックベイト（使用前・使用後、不安をあおる文）、誤解を招く広告のデザイン（ボタン風の画像）、個人ローン**の 3 つ【推測】
- 停止の範囲: 同じ支払い方法などで**関連するアカウントも全部停止**、停止後に作ったアカウントは自動的に停止（P:7187501 ja）。代理店が管理する場合は代理店に相談のうえ異議（P:15938075）

### 5-2. 停止の前兆【公式の通知の種類＋推測】

| 前兆 | 意味 | 出典 |
|---|---|---|
| 「アカウントが〇日後に停止されます」の通知・メール | 少なくとも 7 日前に通知（通常の違反）| P:7187501 ✅ |
| 警告メール（違反警告の対象ポリシー）| 次は 3 日停止 | P:10922738 ✅ |
| 適格性確認の期限の通知 | 期限内に終えないと一部の広告が制限 | 15 の 7-23 ✅ |
| 表示回数が急に絞られるが不承認はない | 広告配信の制限（C25）の可能性 | P:17344822 ✅ |
| 同じ理由の不承認が増え続ける | 「繰り返し」として数えられうる【推測】| ― |

### 5-3. 回避と見なされる行為（やってはいけない「通し方」）✅

| 行為 | なぜ危ないか | 出典 |
|---|---|---|
| 不承認の広告の言い換え版・ドメイン違い版を量産して出し直す | 「不承認の広告・ドメイン・内容のバリエーションを作る」＝回避 | P:15938075 |

| 認定が要る商品を、認定のない複数アカウントに分けて出す | 違反の分散 | P:15938075 |

- 許される出し分け: 言語、特典、地域による調整、回線の遅い人向けの軽いページ（**宣伝する商品が全員に同じなら可**）。クリック トラッカーやリダイレクト自体は、禁止内容を隠す目的でなければ可（P:15938075）

## 6. 入稿前の確認項目（審査落ちを減らすチェックリスト）

**広告文**
- [ ] 記号の連続・飾り（！！、★、■、►、【必見】）がない。半角カナ・絵文字・機種依存文字がない（E03〜E06）
- [ ] 「FREE」「SALE」のような大文字の強調がない（E02）
- [ ] 同じ語を 1 本の中で繰り返していない。**コールアウト・サイトリンクに見出しと同じ文言がない**（E07・E08・S05）
- [ ] 1 本ずつ読んで意味が通る。「ここをクリック」「詳しくはこちら」だけの文がない。箇条書きにしていない（E10・E12・M05）
- [ ] 電話番号を文中に書いていない（E14）
- [ ] 社名か商品名が分かる（E15）
- [ ] 「必ず」「誰でも」「No.1」など、ありそうもない結果・根拠の示せない主張がない（M08。法令の観点は 31）
- [ ] 価格・割引・無料体験は、LP の同じ条件と一致し、期間と自動課金が見える（M04・M10）
- [ ] 他社の商標を広告文に使うなら、再販か情報サイトの条件を満たし、立場を明記（C19・C20）
- [ ] 処方薬の名前を広告文・キーワードに入れていない（C07）
- [ ] 「公式」「〇〇推奨」を、事実でないのに書いていない（M01・M03）

**画像・動画**
- [ ] ボタン・入力欄・通知を模した絵がない（S09・M06）
- [ ] 最小の枠で文字が読める。ぼやけ・ゆがみ・横向きがない。点滅しない（E17）
- [ ] 体の大きな変化を示す使用前・使用後、加工した体の拡大、事故・災害・逮捕の写真がない（M05）
- [ ] 権利のある素材だけ（C04）
- [ ] 動画は公開か限定公開で、冒頭か終わりにロゴと名前（S12・S13）
- [ ] 文字・図形・ロゴを重ねない、コラージュにしない（検索の画像アセットは重ねると不承認。RDA はベスト プラクティス、P-MAX は重ね可だが比率ごとに重ねなしを 1 枚以上。S10）

**LP（リンク先）**
- [ ] 表示 URL・最終 URL・モバイル URL が同じドメイン。計測のリダイレクトが同じページに着く（L02）
- [ ] スマホと PC で 200 を返す。**AdsBot を robots.txt・WAF・海外 IP 遮断で止めていない**（L01・L03・L04）
- [ ] 完成している（工事中でない）。広告の特典・商品が最初の画面で見つかる（L01・M10）
- [ ] 直接ダウンロード・メール直リンク・全画面ポップアップがない（L05）
- [ ] 独自の中身がある（中継ページでない）（L06）
- [ ] 会社名・所在地・連絡先・特商法表記・プライバシー ポリシー（M03・B10。法令は 31）
- [ ] 処方薬の名前が LP にない（クリニック）。市販薬ならライセンス番号（C07・C08）
- [ ] 金融なら住所・手数料がその場で見える（C13）
- [ ] Search Console で手動による対策・セキュリティの問題がない（B01・B09）

**アカウント情報**
- [ ] 広告主の適格性確認が完了し、ビジネス名がその名前と一致（E01、15 の 7-22〜7-26）
- [ ] 認定が要る業種なら認定済み（ヘルスケア、ギャンブル、マッチング、債務サービス、政府書類、チケット）（C05〜C23）
- [ ] 電話番号アセットの番号がサイトにテキストで載っている（L10）
- [ ] 支払い情報が正しい（停止は支払いでも起きる。P:15938075 は支払いの停止に支払い方法の確認が要る場合があると書く）

## 7. 審査落ちが多発したときの切り分け

| 症状 | 先に疑うこと | 見る場所 | 次の手 |
|---|---|---|---|
| **同じ理由が続く** | 直した箇所が原因でない（広告文を直したが、原因は LP の語・アセット間の重複）| API の `evidences.text_list` と `destination_text_list`、アセットの表の「ポリシーの詳細」| 1 要素ずつ直す。3 回の異議を使い切る前に原因を確定する |
| **突然まとめて落ちた（広告・アセット全部）** | リンク先が落ちた（サーバー停止、SSL 切れ、WAF の更新、robots.txt の変更）、ドメインへの商標の申し立て、アカウントの再審査 | `destination_not_working`（HTTP コード・最終確認日時）、通知、変更履歴 | LP を直してから 1 本だけ編集して再クロール、残りは一括で異議 |
| **LP を変えたら落ちた** | 新しい LP の語（薬剤名・「No.1」）、リダイレクトの追加、ポップアップ、表示 URL との不一致 | `destination_text_list`、`destination_mismatch` | 変更前後の差分を見る。直したら広告の URL を少し編集して再クロール（H:9338593）|
| **承認済みが後から落ちた** | 再審査（広告・LP・アカウントに印）、ポリシーの変更（8 章）、権利者の申し立て、利用者の報告 | 変更履歴（広告側の変更がないか）、ポリシーの変更履歴 | 自分の変更がなければ「判定が誤り」で異議。ポリシー変更なら表現を直す |
| **不承認はないのに表示が急減** | 広告配信の制限（C25）、「有効（制限付き）」、商標の制限 | ステータス列、アカウント内の通知 | ブランドを明確に、ドメインを見出し 1 に固定、適格性確認 |
| **新しいアカウントの最初の広告だけ長く審査中** | 新規アカウントの確認、形式の違い（DG は 3〜5 営業日）| ステータス | 2 営業日まで待ち、7 日でアセットを 1 回だけ軽く編集、1 週間でサポート |
| **アカウント全体が止まった** | 違反警告の一時停止、強制停止、支払い | 通知 | 5 章。新しいアカウントは作らない |

## 10. 少額・少量のアカウントでの注意

- **広告配信の制限（C25）が効きやすい**: 判断材料に「アカウントの成熟度」「適格性確認の状態」「ポリシー遵守の履歴」がある。新しい小さなアカウントは、適格性確認を先に終え、ブランドを明確にした広告（ドメインを見出し 1 に固定）から始める ✅（P:17344822）
- **不承認 1 本の影響が大きい**: 広告グループに RSA が 1〜2 本しかないと、1 本の不承認で配信がほぼ止まる。入稿前チェック（6 章）の価値が大きい【推測】
- **審査中に何度も直さない**: 審査のやり直しと学習のやり直しが重なる（05 §12）。直すなら原因を確定してから 1 回で
- **異議の 3 回を温存する**: 原因が分からないまま異議を出さない。まず evidences を読む
- **少額でも回避は即停止**: 規模に関係なく、言い換えの量産・アカウントの作り直しはしない
- **画像アセット・リードフォームなどには遵守の実績が条件**（15 の 2-54・2-65）。不承認の履歴は機能の解放を遅らせうる【推測】

## 11. 判断の型

1. **単位を確かめる**: 広告か、アセットか、アセット グループか、キーワードか、リンク先か、アカウントか（1-5）
2. **重さを確かめる**: 不承認だけか、ストライク対象か、悪質な違反か（5-1）。ストライク対象なら直す前にほかの広告も一斉に点検
3. **証拠を読む**: ポリシー名 → API の evidences（どの文言・どの URL・どの HTTP コード）→ constraints（どの国・どの認定）
4. **直せるか、認定が要るか、表現を捨てるか**を決める（2 章の表の「直し方」）
5. **1 要素ずつ直して保存**（自動で再審査）。判定が誤りなら異議（理由を選ぶ）
6. **24 時間待つ**。通らなければ証拠を読み直す。3 回で通らなければサポート
7. **細工はしない**: 言い換えの量産・別アカウント・出し分けは即停止（5-3）
8. 同じ理由が 2 回続いたら、入稿前チェック（6 章）にその項目を足す【推測】
