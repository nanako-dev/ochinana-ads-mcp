- 注1（P-MAX のポートフォリオ）: ヘルプ（answer/6263072、answer/6268637）と API の P-MAX の手引きは「ポートフォリオ不可」。一方、API の入札戦略の種類一覧（API ガイド: strategy-types）はコンバージョン数の最大化のポートフォリオを「検索・ショッピング・P-MAX で使える」と書く。運用では「不可」として扱う
- 注2（デマンド ジェネレーションの個別クリック単価）: キャンペーンの合計予算額の対象一覧（answer/10486938、API ガイド: budgets/overview）にはデマンド ジェネレーションの個別クリック単価が載るが、デマンド ジェネレーションのよくある質問（answer/14509385）と API のデマンド ジェネレーション手引き（demand-gen/overview）の入札戦略一覧には載らない
- 注3（動画の広告視聴単価）: 「動画キャンペーンの目標について」（answer/10197127）は動画再生回数と広告シーケンスを「上限広告視聴単価（Maximum CPV）」と書く。「動画キャンペーンを作成する」（answer/2375497）と「動画再生回数について」（answer/13982458）は動画再生回数を「目標広告視聴単価（tCPV）」、広告シーケンスを目標インプレッション単価だけと書く。CPV の記事（faq/10286469 内）は「動画再生回数と広告シーケンスで TrueView の CPV が使える」と書く
- 注4（YouTube エンゲージメント）: answer/2375497 は目標コンバージョン単価だけ、answer/10197127 は目標コンバージョン単価とコンバージョン数の最大化の両方を挙げる
- 注5（ショッピングのコンバージョン系）: ヘルプ（answer/7684216）はコンバージョン値の最大化を「検索・ショッピング・デマンド ジェネレーションだけ」と書く。目標広告費用対効果のポートフォリオは、同じ記事（answer/6268637）の中で「ショッピングでは使えない」と「入札単価の上限は検索とショッピングのポートフォリオで使える」が並んでいる。API はコンバージョン数の最大化のポートフォリオを「ショッピングで使える」と書くが、標準の対象一覧にはショッピングがない
- 注6（ディスプレイのコンバージョン値の最大化）: ヘルプ answer/7684216 は「検索・ショッピング・デマンド ジェネレーションだけ」と書くので、ディスプレイは対象外と読める。一方、目標広告費用対効果はディスプレイの条件（過去 30 日 15 件）が書かれている（answer/6268637）
- 注7（ホテル）: 目標広告費用対効果の記事（answer/6268637）は「ホテルは個別クリック単価・宿泊料金の割合・目標広告費用対効果だけ」と書く。ホテルの入札の概要（answer/9244120）と API ガイド（hotel-ads/bidding/overview）は拡張クリック単価も挙げる
