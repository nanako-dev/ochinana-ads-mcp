## 1. 仕組みの全体像

### 1-1. ひとことで ✅

- P-MAX は「目標（コンバージョン数か価値）を 1 つ決めると、Google のほぼすべての配信面に 1 つのキャンペーンで出す」目標ベースのキャンペーン。キーワードで配信先を指定せず、機械学習が誰に・どこで・どの広告を出すかを決める
- 公式の位置づけは「キーワードを使う検索キャンペーンを補うもの」。検索キャンペーンの置き換えとは書いていない

出典: support.google.com/google-ads/answer/10724817（en / ja）

### 1-2. 配信面 ✅

| 配信面 | 公式の扱い | 補足 |
|---|---|---|
| 検索（Google 検索） | 「Google チャネル」の一部 | テキスト広告、ショッピング広告（フィードありのとき） |
| YouTube | 同上 | 動画。動画がないと自動生成されることがある（7 章） |
| Discover | 同上 | |
| Gmail | 同上 | |
| マップ | 同上 | 店舗目標や住所アセットがあるとき |
| Google 検索パートナー | 別枠。優先度と予算配分を個別に決められる（2026-10-15〜順次） | 4-3 |
| Google ディスプレイ ネットワーク | 同上 | 4-3 |

- 検索・YouTube・マップ・Gmail・Discover は「Google チャネル」として 1 つにまとめられ、個別には切れない（チャネルをまたいだ最適化を保つため、と公式は説明）

出典: 10724817、18385152（チャネルの優先順位付けと予算配分について）

### 1-3. 部品 ✅

| 部品 | 日本語ヘルプの呼び名 | 何をするか | 上限など |
|---|---|---|---|
| アセット グループ | アセット グループ | 1 つのテーマや対象者に向けた素材（文・画像・ロゴ・動画）とシグナルのまとまり。AI が素材を組み合わせて各面の広告を作る | 1 キャンペーンに最大 100。キャンペーン間で共有できない（API） |
| オーディエンス シグナル | オーディエンス シグナル | 「こういう人が顧客に近い」というヒント。**絞り込みではない**（学習を導く、と公式） | 1 アセット グループに 1 つの「オーディエンス」を付ける形（API: asset_group_signal） |

### 1-4. 商品フィードあり・なしの違い ✅

| 項目 | フィードなし（リード獲得・フィードなしの販売など） | フィードあり（小売） |
|---|---|---|
| 出せる広告 | 検索のテキスト広告、ディスプレイ・YouTube・Gmail・Discover の素材組み合わせ広告 | 上に加えてショッピング広告、動的リマーケティング |
| 必須の素材 | 見出し・長い見出し・説明文・画像・ロゴ・ビジネス名など（7 章の最小数） | 素材を 1 つも付けない「フィードのみ」のアセット グループも作れる。ただし**素材を一部だけ付けると、必須素材を全部そろえる必要がある**（API。そろえないと管理画面で編集できない状態になる） |
| 着地先の制御 | ページフィード、URL の除外、URL のルール | URL の除外は可。ページフィードは不可（フィードは 1 種類だけ） |
| 最終ページ URL | 必須 | 素材を付けないアセット グループでは不要（API） |
| 注意 | | URL の除外をしても、Gmail のショッピング広告などではホームページが出ることがある（公式） |

出典: developers.google.com/google-ads/api/performance-max/asset-requirements、asset-groups、support.google.com/google-ads/answer/14337773、17091269

### 1-5. 機械学習が決めていること ✅（公式の説明の範囲）

| 決めること | 運用者が口を出せる手段 |
|---|---|

| どの配信面に出すか | 2026-10 以降、検索パートナーと GDN だけ優先度・予算配分を設定できる（4-3）。Google チャネル内の配分は決められない |
| 誰に出すか | シグナル（ヒント）、除外（年齢・性別・世帯収入〔一部〕・データの除外・地域・言語・デバイス） |

## 2. 入札

### 2-1. 使える入札戦略 ✅

| 何を最大化するか | 日本語の呼び名 | 任意の目標 |
|---|---|---|
| コンバージョン数 | コンバージョン数の最大化 | 目標コンバージョン単価（目標 CPA） |
| コンバージョン値 | コンバージョン値の最大化 | 目標広告費用対効果（目標 ROAS） |

- 使えないもの（公式の互換表）: **ポートフォリオ入札戦略、共有予算**、デバイス・地域・広告のスケジュールの**入札単価調整**（調整そのものがない）
- 2026 年に「キャンペーンの合計予算」（数日〜数週間の期間で総額を決める）が検索・ショッピング・P-MAX で使えるようになった（Google 公式ブログ、GML 2026）
- △ チャネルの優先順位付けのヘルプは「共有予算の単位でも設定できる」「共有予算は同じ種類のキャンペーン同士」と書く一方、互換表は P-MAX の共有予算を「不可」としている → 確かめ方: 自分のアカウントで P-MAX を共有予算に入れられるか試す（作成画面で止まるか）
- スマート自動入札の探索（Smart Bidding Exploration）: 目標 ROAS の許容幅を広げて新しいショッピングの検索を取りに行く機能。P-MAX（フィードあり）はベータ（GML 2026 時点）

出典: support.google.com/google-ads/answer/14924934（P-MAX の機能の互換性）、18385152、blog.google/products/ads-commerce/bidding-budgeting-google-marketing-live-2026/

### 2-2. 顧客ライフサイクルの目標 ✅

| 目標 | 選択肢 | 補足 |
|---|---|---|
| 新規顧客の獲得 | 「新規顧客に対して高い単価を設定」（推奨）／「新規顧客のみに入札」 | 「のみ」は配信量を狭める。新規か既存かは Google の自動判定＋カスタマー マッチ等で補う |

### 2-4. 予算の目安 △

- 公式（10724817）は具体的な倍率を示さず、作成画面の予算欄に「低・中・高」の 3 段階と見込み成果を出し、**「低」が最低限の推奨予算**としている
- 「目標 CPA の 3 倍／日」などの数字は Google のヘルプでは確認できなかった。「過去の単独キャンペーンの 2〜3 倍」は Microsoft 広告のヘルプの記述で、Google のものではない
- → 確かめ方: 作成画面の予算欄に出る「低」の金額を記録しておく（0 円で見られる）

## 3. 優先関係と併用

### 3-1. 検索キャンペーン・AI Max・P-MAX の優先順位 ✅

公式（2756257）の順番:

1. **検索語句と同一の完全一致キーワード**が最優先。P-MAX より先。「同一」には綴りの修正は含むが、複数形や同義語は含まない
2. 次に、検索語句と同一の**フレーズ一致・インテント マッチ（AI Max を含む）キーワード、または P-MAX の検索テーマ**。同一の検索テーマは、同一でないフレーズ一致キーワードより優先
3. 同一のものがなければ「AI による関連性の優先付け」: 検索語句の意味・各グループのキーワード・着地ページから、最も関連の高い広告グループ／アセット グループだけを候補にする
4. それでも並べば、広告ランクの高い方

- 検索テーマのない P-MAX のアセット グループ、キーワードのない AI Max 広告グループ、DSA は、アカウント内のほかの広告と広告ランクで比べられる
- 例外: 予算で制限されている、広告や LP が不承認、ターゲティングで外れる、検索量が少ない、の場合は意図どおりに出ないことがある。**Lens・AI モード・AI による概要・オートコンプリートからの検索は「同一」とみなされない**ので 3 の関連性判定に回る
- 公式（10724817）は、完全一致に設定したブランド キーワードでも、検索キャンペーンが予算で制限されている・ターゲティングが厳しいなどのとき P-MAX が出ることがある、と書いている

### 3-2. ショッピングとの関係 ✅

- 2024-10 以降、同じアカウントで同じ商品を対象にした**標準ショッピングより P-MAX が自動で優先される仕組みは廃止**。広告ランクの高い方が出る（公式 15535462、2024-10-23）
- 上の優先順位ルール（キーワードの同一性）はショッピング広告には効かない。完全一致の検索広告と並んで、ショッピング広告が出ることはある

### 3-3. 併用の公式推奨（Power Pack）✅

- Google は GML 2025 で、**P-MAX・AI Max・デマンド ジェネレーション**の 3 つを「Power Pack」と呼び、検索と YouTube をまたいだ成果のための組み合わせとして紹介した（16290177）
- 「Power Pack は Google の推奨ではない」と書く第三者もいるが、少なくとも Google 自身の発表ページで名前を出して紹介していることは確認できた
- 公式が出す効果の数字（AI Max か P-MAX の導入で同程度の ROAS でコンバージョン 15% 増、など）は Google の内部データで、条件は不明

出典: 2756257、10724817、15535462、16290177

## 4. 運用者が制御できること・できないこと

### 4-2. 世帯収入の除外（重点確認）

| 出典 | 書いてあること | 種類 |
|---|---|---|
| 作成手順ヘルプ（15864837、**英語版**） | 「ユーザー属性の除外は年齢と性別。世帯収入は**一部の広告主向けベータ**」 | ✅ Google 公表 |
| 同（**日本語版**） | 年齢と性別だけ。世帯収入の記載なし | 翻訳が遅れていると推測 |
| ユーザー属性ターゲティングのヘルプ（2580383、英語版） | P-MAX の節に世帯収入（上位 10%〜下位 50%、不明）があり、使える国 20 か国に**日本が含まれる** | ✅ Google 公表 |
| 同（日本語版） | P-MAX の節がない | |
| Google Ads API リリースノート v26.1（**2026-10-28**） | 「P-MAX で世帯収入の除外に対応」。キャンペーン単位の除外条件（negative CampaignCriterion の income_range）で作る | ✅ Google 公表 |
| Search Engine Land／PPC Land（2026-07-27〜28 報道） | Thomas Eccel 氏が欧州のアカウントで設定欄を見つけた（LinkedIn）。Google の正式発表はなし | 第三者 |

**結論**: 「P-MAX で世帯収入の除外ができるようになった」は**半分正しい**。

- 正しい点: Google 公式ヘルプ（英語）と API で、P-MAX の世帯収入の**除外**が存在する。API では 2026-10-28（v26.1）から作れる。日本は世帯収入が使える国に入っている

- ❓ 日本のアカウントの管理画面に出ているか → 確かめ方: 自分のアカウントで P-MAX の「その他の設定 → ユーザー属性の除外」を開く。出なければ API で income_range の除外を validate_only で送ってみる（エラーの種類で「未提供」か「不可」かがわかる）

### 4-3. 配信面の優先順位付け（2026-10〜）✅

- 単位: アカウント設定の「チャネルの優先順位付け」カードで、キャンペーンの種類ごとに決める。共有予算やキャンペーン単位で上書きできる。MCC からは設定できない
- P-MAX で選べる面: Google チャネル／Google 検索パートナー／Google ディスプレイ ネットワーク
- 既定: すべて「高優先度」
- 低優先度の面だけ、1 日の予算に対する配分 %（ベストエフォート）を決められる。**0% にするとその面には使わない**。余り・使いすぎは翌日に持ち越さない
- 目標 CPA・ROAS で予算に余裕がある場合は優先度は配分に影響しない（配分 % は効く）。予算が足りない場合は高優先度の面から目標内で使う
- 公式は「オプトアウトの代わりに低優先度を使える」と書く。P-MAX での完全なオプトアウトの記載はない
- 第三者（PPC Land、2026-07-28、Digiday の報道を引用）: 一部の広告主に検索パートナーと GDN を外すチェックボックスがアルファ版で出ていた。今回の優先順位付けとの関係は ❓

## 8. 小売以外での使い方と注意

### 8-1. リード獲得 ✅

- コンバージョン目標は、件数が足りる範囲で**いちばん深い段階**（有効なリード、成約）を選び、ほかは「観察用」にする
- 「問い合わせ」「リードフォーム送信」「予約」「見積もり依頼」「有効なリード」などリード用の目標を使うと、無効なリードへの保護が強くなる、と公式
- オフライン コンバージョンのインポート／拡張コンバージョン（リード）を毎日送る。値を付けて目標 ROAS に
- スパム対策: 質問項目、reCAPTCHA、サーバー側の検証。ただし項目を増やすと完了率が落ち CPA が上がる
- 推測: フォーム送信だけを目標にすると、ディスプレイや検索パートナーで「送信はされるが質の低いリード」に寄りやすい。2026-10 以降は GDN と検索パートナーを低優先度にする手段が加わった

出典: 13775965、16782203

### 8-2. 店舗目標 ✅

- 店舗目標（来店・店舗での販売）だけを追加した場合、最終ページ URL の拡張は使えない
- アップリフト テストは店舗目標で使える
- ローカル サービス広告の P-MAX（2026、API v24.2〜v26）: 1 アカウント 1 キャンペーンまで、利用規約の同意が必要、地域を全部外せない

出典: 15864837、12997711、API common-errors

## 12. 少額・少量のアカウントでの注意

- 公式は 6 週間の評価期間を求める。月の CV が少ないと、6 週間でも学習に足りない可能性が高い（推測。公式は P-MAX 固有の件数を示していない）
- アセット グループを増やすほどデータが分散する（推測）。公式は「テーマや対象者ごとに分けられる」「URL 拡張オンで素材が汎用的でないなら LP 別に分ける」と書くだけで、最適な数は示していない
- 目標 ROAS は「過去 30 日 15 件以上」が目安（リード獲得のページ）。それ未満なら目標なしの最大化から（公式の記述からの推測）
- 予算が足りないと優先度の高い面から使われる（2026-10 以降）。少額で GDN や検索パートナーに流れていないかをチャネル レポートで見る
- 公式のアップリフト テストはトラフィックを 50/50 に割るので、少量だと結論が出にくい（推測）
- フォームの CV だけで学習させると質の低いリードに寄りやすい、という第三者の指摘が多い（PPC.io などの監査記事）。公式も「いちばん深い段階を」と勧める
- 自動生成動画を避けるには、横・正方形・縦の動画を 1 本ずつ自分で入れる（公式）。少額だと YouTube 面での消化が目立つことがある（第三者の監査記事の傾向、数字は記事ごとにばらつく）
- 検索キャンペーンとの重複: 自社ブランドは完全一致の検索キャンペーンで持ち、P-MAX にはブランドの除外をかけるのが手堅い（推測。公式は両方の手段を説明しているだけ）

## 14. 判断の型

1. **計測が先**: 目標にする CV は「事業の成果に近い、件数が足りる、いちばん深い段階」か。リードならオフライン CV を毎日送れるか。できないなら P-MAX の前に計測を直す
2. **フィードの有無で設計を分ける**: 小売はフィードあり（ページフィード不可）。リード獲得はフィードなしで、着地先はページフィードか URL の除外で管理
3. **ブランドと検索の役割分担**: 自社ブランドと重要語は検索キャンペーンの完全一致で持つ。P-MAX にはブランドの除外（表記ゆれも拾う）と除外キーワード
4. **着地先の自由度を決める**: 自由に（URL 拡張オン＋検索テーマ）／一部禁止（＋URL の除外）／一覧だけ（URL 拡張オフ＋ページフィード）の 3 段階から選ぶ（公式の 16672522 の組み合わせ）
5. **配信面の自由度を決める**: 2026-10 以降、検索パートナー・GDN を低優先度にするか。少額やリード獲得では、まず低優先度＋配分 % で様子を見る（推測。公式は「オプトアウトの代わりに低優先度」と書く）
6. **素材をそろえる**: 見出し 15・説明文 5（60 字以下を 1 本）・画像 7 以上・3 向きの動画。自動生成をどこまで許すかを設定ごとに決める
7. **評価の仕方**: 6 週間は大きく触らない。チャネル レポート→検索語句→アセットの順で見る。増分を知りたいならアップリフト テスト（フィードなしのみ、と KB は書くが ❓）
8. **新機能は自分のアカウントで確かめる**: ヘルプの英語版で存在を知り、管理画面か API の validate_only で使えるかを確かめてから提案する（世帯収入の除外が典型）
