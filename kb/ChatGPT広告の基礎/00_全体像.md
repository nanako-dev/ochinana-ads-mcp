# ChatGPT の広告 00 全体像

- 確認日: 2026-11-18（OpenAI の開発者向け文書 developers.openai.com/ads と /commerce は本文を読めた。openai.com のブログ・ポリシーと help.openai.com のヘルプは自動取得を 403 で拒否されたため、**検索結果に出た抜粋だけ**で確かめた。出どころの番号 S-xx は `95_出どころ一覧.md`）
- 位置づけ: OpenAI が ChatGPT の中で出している広告の地図。何が公式に言えて何が言えないかの要約は `61_いま言えること言えないこと.md` を先に読む
- 使い方: 確認日から 30 日を過ぎていたら、出典を取り直してから使う。**この媒体は 2026 年 2 月に始まったばかりで、月に何度も仕様が変わっている**。とくに入札の名前（2026-11-09 に変更）、提供国の数、ポリシーは 2 週間で古くなりうる
- 凡例: ✅ 公式で確認 ／ △ 資料によって食い違う ／ ❓ 確認できず
- 主張の出どころの印: 〔公式〕OpenAI の開発者文書・ヘルプ・ポリシー・公式ブログ ／〔公式・抜粋〕公式ページだが本文を読めず検索結果の抜粋で確認 ／〔報道〕報道機関（公式で確かめられないもの）／〔第三者〕媒体外の解説 ／〔推測〕書き手の推測
とくに: 日本は都道府県と郵便番号で地域を指定できる／文字数は全角も 1 字で、画面の目安はタイトル 32・説明 54（開発者文書の 50・100 と違う △。超えると「切れる場合がある」警告）／会話の話題のレポートは無い
- 取得の注意: 〔公式・抜粋〕の事実は、検索エンジンが要約した文に頼っている。日付・数字・上限は、管理画面か本文で取り直すまで「仮」と扱う

## 2. アカウントの構造とキャンペーンの種類

### 2-1. 階層 ✅〔公式〕S-01

| 階層 | 何を決めるか |
|---|---|
| 広告アカウント | ブランド名（広告に出る名前）・アイコン・通貨・タイムゾーン・権限・アカウントの費用上限。**通貨・タイムゾーン・国は作成後に変えられない**（S-39 抜粋） |
| キャンペーン | 目的（表示・クリック・コンバージョン）、予算（1 日か通期）、期間、地域・端末・オーディエンスの指定と除外、計測するコンバージョン |
| 広告グループ | 入札戦略、文脈ヒント、オーディエンス別の入札の倍率、商品セット |
| 広告 | クリエイティブ、画像か商品テンプレート、リンク先 |

- 名前は 3 種類: 法人名（請求と確認用）、アカウント名（管理画面の中だけ）、ブランド名（広告に表示）。2026-09-25 から別々に変えられる。**ブランド名**を変えるとブランド審査が終わるまで配信が止まる。**法人名**を変えると事業者の審査をやり直し、配信が止まる**ことがある**（may pause）。アカウント名の変更は審査しない ✅〔公式〕S-39（本文、94#17・05§5-1）。初版の「法人名かブランド名を変えると止まる」は法人名について言い過ぎだった
- 権限: 管理者・メンバー・閲覧者。ChatGPT のワークスペースや API の組織の権限は広告の権限にならない ✅〔公式・抜粋〕S-40
- API: Advertiser API（キャンペーン・広告・フィード・計測・レポート）、Bulk API（限定プレビュー）、監査ログ。1 分 600 リクエスト／端点、全体 1,200 ✅〔公式〕S-01
- **運用の判断への効き方**: 目的とコンバージョン イベントは**作成後に変えられない**（変えるなら作り直し）✅〔公式〕S-01。Google のように「まずクリックで始めて、成果がたまったら同じキャンペーンを目標 CPA に切り替える」はできない。最初から目的別にキャンペーンを分けて作る。複製は「別の目的か、対応する別の課金方法」の新しいキャンペーンを作るときだけ使え、同じ目的のままは複製できない ✅〔公式〕S-34（本文、02§2-2）
- くわしくは 02§2（目的と課金）、05§5（3 つの名前・アイコン）、34§1-7・§6（事業者の確認、アカウントの制限）

### 2-2. キャンペーンの種類 ✅〔公式〕S-01

| 種類 | 中身 | 状態（2026-11-18） |
|---|---|---|
| 標準（チャット カード） | 静止画のクリエイティブ。表示・クリック・コンバージョンの各目的 | 提供 |
| 商品フィード | カタログから広告を組み立てる。商品カードが並ぶ形もある | 提供。ヘルプは Ads Manager の「ツール > フィード」でフィードを作る手順を書く ✅〔公式〕S-58（本文、05§8-1）。API でフィードを使うにはアカウントの許可が要る（S-01。初版はこちらの「担当チームに連絡」だけを書いていた） |

### 3-1. 目的と課金 ✅〔公式〕S-01

### 6-2. レポートの指標 ✅〔公式〕S-01

- 追記: 表示・クリック・CTR は約 15 分ごとに更新、**費用は 7〜8 時間遅れることがある**（費用 0 円の表示でも課金が無いとは限らない）。**審査のクローラーがトラッキング パラメータ付きで LP を訪れる**ことがあり、外部のアクセス解析では有料の流入に見えるが、課金されるクリックではない（help 20001207）
- 追記: 計測のつながりは、LP の URL の末尾に付く **`oppref`（OpenAI のクリックの参照）**をピクセルがファースト パーティ Cookie に保存して使う。コンバージョン API にも `oppref` を入れられる。クリックの参照が無いときは**自動の拡張マッチング（AAM）**がフォームなどの顧客情報をブラウザで SHA-256 でハッシュ化して送る。**AAM は日本以外では既定でオン、日本のアカウントでは広告主がオン・オフを選ぶ**（ピクセルの編集画面）。計測できる場合はモデル化したコンバージョンが合計に入る（help 20001409）

表示回数、クリック数、費用、CTR、CPC、CPM、コンバージョン、CPA、クリック後のコンバージョン率、購入の売上、ROAS。国・端末・プラットフォーム・商品で分けられる。時間別は約 30 日、日別は 365 日まで。成果のデータは少なくとも 1 日待つ（開発者文書）。ヘルプ 20001214・20001604 の本文では反映に 24〜48 時間 ✅〔公式〕S-45（06§12-2）

- くわしくは 06§10（イベントの品質スコア）、06§12（指標と遅れ）、06§13（GA4・Google 広告と数字が合わない理由）、26（効果測定の実務: 増分・少額での読み方）

### 6-3. アトリビューション

- ✅〔公式〕クリックの窓は 7・14・30 日（既定 30）、ビュースルーは 0 か 1 日（既定 1）。両方に当たる成果はクリックを優先。既定は「広告に触れた日」で数える。2026-09-30 の API の変更で、既定の集計が「クリック＋ビュースルー」になった（S-01）
- ✅ **決着**: 表示後の窓を **1 日**にすると、ビュースルーは「コンバージョン」の合計に**入る**（0 日なら入らない）。両方に当たる成果はクリックが優先。クリックスルーとビュースルーは別の列でも見られる。**窓の変更はレポートだけに効き、最適化・入札・課金は変わらない**。最後の接点で数える（マルチタッチではない）。成果の反映は 24〜48 時間。公式ブログは「高度なコンバージョン最適化は、選んだ目標のクリックスルーとビュースルーの両方から学ぶ」と書く。開発者文書の「計測ピクセル」の節の「ビュースルーは Conversions に含まない」は古い記述
- **運用の判断への効き方**: Google（既定 30 日、データドリブン、ビュースルーは別列）と同じ表で並べるなら、ChatGPT 側をビュースルー 0 日にそろえる
- くわしくは 06§11（アトリビューション、ビュースルーの決着）、26§4（管理画面の成果と増分の違い）

### 6-4. 広告主に渡るもの・渡らないもの ✅〔公式・抜粋〕S-11、S-30

- 渡る: 表示回数やクリック数などの**集計**だけ
- 渡らない: 会話、チャットの履歴、記憶、氏名、メール、正確な位置、IP アドレス、敏感な情報
- △ 広告を通じた会話の例外: 利用者向けヘルプ（S-30、本文）は「広告を通じて広告主にメッセージを送ると、広告主は直接送ったメッセージだけを見る」と書き、広告主向けのビジネス エージェントのヘルプ（S-49、本文）は「広告主は個々のチャットや会話の記録を受け取らない（傾向はインサイトに出る）」と書く。言い方が合わない（05§9-4）
- **運用の判断への効き方**: 「どんな会話で出たか」（Google の検索語句レポートに当たるもの）は見られない（レポートの列に会話・話題に当たるものは無い、62#7）。改善は LP 側の分析と、文脈ヒントの書き分け（広告グループを分けて比べる）で行う
- くわしくは 23§9（パーソナライズの仕組み）、05§9-4（エージェントの会話で広告主に見えるもの）

## 7. 審査とポリシー

### 7-1. 審査の層 ✅〔公式〕S-01、〔公式・抜粋〕S-39、S-46、S-48

1. 事業者の確認（法人名・登録住所・必要なら登録番号）。最大 7 営業日 ✅〔公式〕S-46（本文、94#19）。確認が済む前でも配信が始まり費用が発生しうる。支出が一定額に達すると追加の確認が求められうる（34§1-7）

3. アカウントの審査（`account_integrity_review`）
4. 広告ごとの審査（作成で審査に入る。文面を変えると再審査）

- 広告ポリシーの側の切り方では、審査は 広告主・広告クリエイティブと LP・掲載 の 3 レベルで、ほとんどは自動（LLM と分類器）✅〔公式〕S-19（34§1-1・§1-3）
