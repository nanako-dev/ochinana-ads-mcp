## 4. 日本の運用者が今やれること・やらないこと

### やれること

1. **LP のクローラー点検**（費用ゼロ）: robots.txt と WAF・CDN（Cloudflare 等）が OAI-AdsBot と OAI-SearchBot を弾いていないか確かめる。広告の審査にも、自然な商品表示・検索にも効く ✅ S-48、S-03
2. **小さなテスト出稿の準備**: 日本の法人で ads.openai.com にアカウントを作り、事業者の確認を先に済ませる（確認に時間がかかる可能性）。最低 2,500 円／日。国・通貨・タイムゾーンは作成後に変えられないので最初に決める ✅ S-32、S-34、S-39
3. **目的ごとに別キャンペーン**: まずクリック（目標 CPC）で始め、計測が安定したらコンバージョン（目標 CPA）を新しいキャンペーンとして作る〔推測〕（進め方は書き手の案。公式にあるのは「目的とコンバージョン イベントは作成後に変えられない」「複製は別の目的か別の課金のときだけ」まで ✅ S-01、S-34。00§3-2・02§2-4）
4. **計測はピクセル＋コンバージョン API**: 公式は API のほうが確実と書く。同じイベント ID で重複を除く。Google と比べる表ではビュースルー 0 日にそろえる ✅ S-01
5. **文脈ヒントを具体文で**: 「商品＋使い方＋悩み」を書き、広告グループを分けて比べる ✅ S-01
6. **クリエイティブの強化の設定を確認**: 表現の管理が要る業種はオプトアウトしてから出す ✅ S-43
7. **既存顧客の除外**: 除外のオーディエンスは人数の下限なし ✅ S-01
8. **広告以外の手**: Business Hub でビジネスの登録ができるかを確かめる（日本で可能かは要確認）。商品ページの価格・在庫・レビューを正確に保つ △ S-52、S-51

### やらないこと

1. 「AI の回答の中で自社を薦めさせる広告」として提案しない（広告は回答の下の別枠）✅ S-30、S-18
2. 日本の健康食品・クリニック・金融・士業・酒・ギャンブルの出稿計画を立てない（米国外の金融・健康は原則禁止など）✅／△ S-19、S-46
3. 日本向けに商品フィード広告を前提にしない（標準のアップロードは米国向け）✅ S-03
4. Google のキーワード設計・除外キーワードの考え方をそのまま移さない ✅ S-01
5. 上限入札（Max Bid／Max CPC）で新しく組まない。既存は 2026 年内に移す ✅ S-36
6. Instant Checkout・ACP の実装を勧める古い記事に従わない（今の公式文書は Wallet・ブラウザ・プラグインの構成）〔報道〕R-05、✅ S-03
7. 「どんな会話で出たか」を前提にした報告を約束しない ❓
